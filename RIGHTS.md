# Rights and attribution

The initial repository contained no license. A project-wide software license is
an owner decision that remains open; publication alone is not a license grant.
No third-party implementation has been vendored into this foundation.

The user-supplied research is retained as project input in
`docs/research/USER_RESEARCH.txt`, with its private document link removed. Its
historical claims describe that supplied research, not this repository's measured
performance or the work completed in this setup. Linked papers, manuals,
schematics, images, recordings, and datasets retain their respective rights.
Linking them does not grant redistribution or implementation reuse rights.

Record permission, attribution, and intended use before importing any source code,
dataset, figure, recording, impulse response, or device model. The current runtime
uses no recorded-note samples, downloaded models, or copied research source code.

Fender and Rhodes are identifying references to instruments and their respective
trademark owners. This independent project does not claim endorsement or affiliation.

Before a binary or SDK release: the owner must select a software license, verify
dependencies and data permissions, and approve the distribution identity. This is
a release prerequisite, not a blocker for developing the current original code.
