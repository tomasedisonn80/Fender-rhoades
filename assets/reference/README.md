# Authoritative editor reference

`rhodes-suitcase-reference.webp` is the original, unchanged image supplied by
the repository owner in the 24 November 2026 development request. The owner
explicitly requested that this image be committed and that the VST3 editor match
its appearance. This file supersedes any invented editor styling for this work.

The reference shows the entire instrument: black case and lid, silver control
rail, keyboard, speaker cabinet, legs and pedal against its original background.
Its aspect ratio, perspective, texture and control placement are design inputs.
The reference is not a physical measurement or proof of a particular circuit
revision, and the picture does not change the audio model's unvalidated status.

The permission recorded here is the owner's instruction to include and use this
attachment in this project. No broader license, authorship or historical origin
is asserted for the image. Existing project rights statements still apply.
