## Diagnosis

The filtered model's existing sample timing is internally consistent. In
`src/research_engine.cpp:246–264`, note-on adds an instantaneous velocity impulse
without clearing displacement. `sample()` observes the post-event state at the
current timestamp before advancing (`302–327`). `BasicAudioEngine` retains the
substep-zero FIR output (`include/rhodes/audio_engine.hpp:56–80`). The independent
sampled reference uses that same mathematical timing
(`tools/validate_filtered_audio.py:424–431`). The retained full diagnostic reports
all 2,097 Comparison A cases passing, with maximum difference
`2.631228568361621e-14 V`.

The continuous comparison is a different target: the time integral of the
piecewise smooth voltage against a finite, causal kernel (`435–448`). A note-on
causes a voltage jump because pickup voltage depends on velocity. Counting the
right-sided value at an event with a full rectangular quadrature weight creates
a leading half-step error. A retrigger while displaced changes that jump through
the nonlinear flux derivative. This explains why the largest error follows
events despite exact analytic mechanical propagation. Release/pedal change
derivatives even when voltage itself remains continuous.

The retained full matrix has 2,085 Comparison B failures and maximum discrepancy
`0.4473573821492792 V`; it is not evidence that the existing discrete FIR is
implemented incorrectly. Both its frozen discrete semantics and historical
evidence must remain intact.

## Exploratory correction experiment

Let `h=1/L` in host-frame coordinates, `K` be the unnormalized continuous kernel,
`N_d=h*sum(K(j*h))`, and `N_c=integral(K)`. At event time `e`, define
`Δv^(j)` as the right-minus-left voltage derivative with respect to host-frame
position. The Euler–Maclaurin correction through order eight is

```text
y_corrected(n) = y_discrete(n)*N_d/N_c
  - h/(2*N_c) * sum_events Δv K(n-e)
  + 1/N_c * sum_events sum_m=1..4 [ B_(2m) h^(2m)/(2m)! ]
      * sum_j=0..(2m-1) binomial(2m-1,j) Δv^(j)
        * (-1)^(2m-1-j) K^(2m-1-j)(n-e).
```

The four Bernoulli/factorial coefficients are `1/12`, `-1/720`, `1/30240`,
and `-1/1209600`. Reset starts a new filter epoch; previous corrections must
be discarded, and an event immediately after reset has zero left history.

I evaluated this offline using the existing arbitrary-time analytic reference,
independent Q64 continuous curves, and independently evaluated kernel
derivatives. The scratch prototype obtains kernel derivatives using a complex
Cauchy contour of radius one with 64 points and the entire interior
Kaiser/sinc formula. This is a diagnostic prototype, not a proposed runtime
dependency or final coefficient-generation method.

Thus half-jump or second-order correction alone is insufficient. Order eight
is a plausible bounded candidate. These 38 exploratory cases are not the full
2,097-case acceptance study, a C++ implementation test, or an alias-only bound.
Small finite-support endpoint errors remain because the truncated kernel has
nonzero endpoint values; the prototype does not analytically remove those.

## Recommended implementation path

1. Preserve direct/model-1 and current filtered/model-2 audio and identifiers.
   Add a separately identified experimental transient-corrected engine/model.
2. Expose or share an analytic voltage derivative calculation using actual
   mechanical state and synthetic constants, without resetting or approximating
   that state. For host-frame Taylor coefficients of a modal displacement,
   `q[0]=position`, `q[1]=velocity/host_rate`, and
   `q[n+2]=(-2*beta/host_rate*(n+1)*q[n+1]-(omega/host_rate)^2*q[n])/((n+1)*(n+2))`.
   Sum modal motion before the cubic flux polynomial and differentiate it.
3. Precombine the Bernoulli factors, binomial terms, and kernel derivatives into
   fixed per-factor correction kernels for eight voltage derivatives and 97
   output frames. No transcendental evaluation or allocation is needed in the
   audio callback.
4. Accumulate derivative jumps from simultaneous events, then add their combined
   response to a fixed 97-frame correction ring. Clear pending jumps and the ring
   on reset. Verify producer order, zero-length blocks, faults, and rate changes.
5. Independently regenerate/verify coefficient tables, compare a C++ probe to an
   independent discrete correction oracle, then run the complete frozen
   continuous matrix. Measure callback cost with dense events before host claims.
