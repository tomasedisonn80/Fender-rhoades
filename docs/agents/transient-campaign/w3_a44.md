## Result and boundary

The five requested standalone targets built successfully with GCC 14.2 in an
isolated Linux x86_64 Debug configuration. **All 16 selected quadrature CTests
passed under AddressSanitizer and UBSan with leak detection explicitly disabled
for that supplemental run. Leak detection remains unavailable here.** No
production, test, CMake or CI settings were changed.

The [retained observation](../../validation/quadrature-sanitizer-20261123.json)
contains both the original failure and the supplemental result, exact commands,

matched that commit before testing and remained unchanged afterward. Executable

## Commands and observed results

```sh
cmake -S . -B build/w3-a44-sanitize -DCMAKE_BUILD_TYPE=Debug \
  -DRHODES_ENABLE_SANITIZERS=ON -DCMAKE_EXPORT_COMPILE_COMMANDS=ON \
  -DBUILD_TESTING=ON -DRHODES_BUILD_VST3=OFF
cmake --build build/w3-a44-sanitize --parallel 2 --target \
  rhodes_fractional_observation_tests rhodes_quadrature_fir_tests \
  rhodes_quadrature_engine_tests rhodes_quadrature_probe rhodes_render
ASAN_OPTIONS=detect_leaks=1:halt_on_error=1 \
UBSAN_OPTIONS=halt_on_error=1:print_stacktrace=1 \
  ctest --test-dir build/w3-a44-sanitize -R '^quadrature\.' \
  --output-on-failure --no-tests=error --parallel 1
```

Configuration and build exited zero. The first CTest run exited **8**, with
**16 failures, zero passes and zero skips** in 14.83 seconds. Every test
encountered LeakSanitizer's fatal shutdown diagnostic. This is retained as a
failed observation, rather than counted as passing sanitizer coverage.

A separately compiled, non-project control reached and completed its main body,
then reproduced the failure with verbose LSan diagnostics: it could not attach
to a thread (`errno 1`) and failed to suspend threads. `/proc/self/status`
reported `TracerPid: 0`; the generic ptrace hint does not establish that the
program was actually traced. This control isolates the thread-suspension
permission failure from the quadrature implementation.

The same 16 tests were then run with:

```sh
ASAN_OPTIONS=detect_leaks=0:halt_on_error=1 \
UBSAN_OPTIONS=halt_on_error=1:print_stacktrace=1 \
  ctest --test-dir build/w3-a44-sanitize -R '^quadrature\.' \
  --output-on-failure --no-tests=error --parallel 1
```

This supplemental run exited **0: 16 passed, zero failed, zero skipped** in
18.34 seconds. It covers four fractional-observation selectors, five FIR
selectors, five engine/event/fault/allocation selectors, the quadrature CLI
fixture and stdout-failure handling. There were no address or undefined-behavior
diagnostics in these project test logs.

Two intentional fault controls, using the same supplemental environment,
confirmed active detection: a heap-buffer overflow and a signed integer overflow
each exited 1 with the expected diagnostic. All six relevant compilation units
used `-fsanitize=address,undefined -fno-omit-frame-pointer`; all five executables
linked both sanitizer runtimes.
