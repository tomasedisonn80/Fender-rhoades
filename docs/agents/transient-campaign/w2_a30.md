## Retained coverage

| Selector | Behavior checked |
| --- | --- |
| `qfir_convolution` | Phase-distinct deterministic signal over 497 active cells, then 99 zero cells; ordinary chronological long-double convolution in a different summation order; exact silent startup and expired support; positive and negative DC after settling and across wraps. |
| `qfir_impulses` | Each of six nodes at each of 96 circular insertion positions; exact branch tap sequence, initial silence, and finite tail. Branch impulse timing is not treated as proof of combined group delay. |
| `qfir_delay` | All six observations of a sinusoid at their actual fractional times; four frequencies, 480 frames each; direct centered response amplitude and a fixed 48-frame phase with no fit. The fixture also requires a distinguishable error for an incorrect 49-frame delay. |
| `qfir_rejection` | NaN, positive infinity, and negative infinity at every cell node immediately before and at a ring wrap; exact immediate and 193-cell continuation equality to an untouched copy detects partial branch writes and cursor mutation. |
| `qfir_overflow` | Finite sign-aligned extreme input exceeds the output range; repeated output reads and rejected nonfinite input preserve the fault history; explicit reset clears it and restores ordinary convolution. The range prerequisite uses a dimensionless gain check, so it does not require a wider long-double exponent range. |
