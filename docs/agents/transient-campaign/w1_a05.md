- `tools/check_docs.py` explicitly recognizes a decoded slash root before
  filesystem resolution. Windows drive-less rooted paths are rejected in the

  backslash rejection and symlink containment remain intact.

  corresponding byte hashes in the successful generated manifest.

  absolute/traversal and valid network-URL tests remain in place.
