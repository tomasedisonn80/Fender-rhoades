## Implemented

- `tools/generate_quadrature_filter.py`: original standard-library Decimal80
  six-point Gauss–Legendre rule, bounded Newton iteration with a final root
  residual guard, deterministic coefficient generation and read-only `--check`.
- `include/rhodes/quadrature_filter_coefficients.hpp`: six forward nodes, six
  weights, six 96-tap branches, normalizer and fixed-size/latency constants.

The generator loads this repository's existing original Decimal pi/sinc/I0
helpers by their sibling path. It changes neither those helpers nor the legacy
filter header. It requires no NumPy/SciPy installation. The retained primary
mathematical reference is the
[SciPy Gauss–Legendre documentation](https://docs.scipy.org/doc/scipy/reference/generated/scipy.special.roots_legendre.html);
no third-party source was copied.

Lower nodes use the nearest `2^-53` grid position, with upper nodes formed by
exact binary complements. Kernel evaluation uses those serialized nodes in
Decimal arithmetic. Both weights and normalized taps are mirrored exactly.
The complete normalizer is computed before rounding; no later binary64 tap
adjustment is made. Taps follow `w[j]*K(k+1-a[j])/N`, preserving the forward
observation convention and 48-frame kernel center. Generated bytes contain no
timestamp, absolute path or dependency version.

Namespace `rhodes::quadrature_filter` provides `node_count`, `history_frames`,
`latency_frames`, `kaiser_beta`, `cutoff_host_rate`, `normalizer`, `nodes`,
`weights`, and `coefficients`. The latter is
`std::array<std::array<double, history_frames>, node_count>`.
