## Recommended construction

Use the existing original Decimal `_pi`, `_sinc` and `_i0` utilities within an
explicit 80-digit, half-even local context. They already avoid host libm and
external numerical dependencies. Do not change the old generator's output.

Compute the three positive roots of
`P6(z)=(231z^6-315z^4+105z^2-5)/16` by Newton iteration using deterministic
Decimal seeds `0.25`, `0.65`, `0.93`. Require absolute update below `1e-72`
and final polynomial residual below `1e-70`, with a fixed 128-iteration cap.
Mirror roots, sort ascending, and map onto the unit cell:

```text
a[j] = (1+z[j])/2
w[j] = 1 / ((1-z[j]^2) * P6'(z[j])^2)
g[j][k] = w[j] * K(k+1-a[j]), k=0..95
N6 = sum(j,k,g[j][k])
c[j][k] = g[j][k]/N6
```

`K` is the unchanged 96-frame Kaiser/sinc prototype centered at 48, beta 9
and cutoff 0.47 host rate. Nodes are forward positions in the current cell;
they must not be confused with the lag nodes used in the independent reference.
Output at frame `n` is
`sum(c[j][k] * x(n-1-k+a[j]))`, using previously completed cells. Then observe
the current cell for frame `n+1`. This fixes the phase convention explicitly.

### Preserve symmetry after serialization

Nearest binary64 rounding of each exact Gauss node independently does not
produce complementary node pairs with exact binary-rational sums of one.
All three pairs failed that exact check in the focused experiment, although
ordinary floating addition rounds their sums to one.

For literal symmetric fractional positions, round each lower node to the nearest
integer multiple of `2^-53`, then construct its upper partner as the exact
complement on that grid. The maximum perturbation is bounded by `2^-54`.
Evaluate the kernel from these serialized nodes represented exactly as Decimal;
retain symmetric weights from the high-precision roots. Generate only the first
three phase rows and mirror the other rows by
`c[j][k] == c[5-j][95-k]`. Compute `N6` as twice the high-precision half-sum,
normalize before binary64 rounding, and write exact hexadecimal literals.

The paired tap locations are symmetric around 48 in the host-frame coordinate.
This establishes the intended kernel center without introducing another frame
in the ring indexing. It does not prove continuous-reference accuracy for every
possible input. The rounded node rule has small moment error and must be checked
numerically rather than described as exact symbolic Gaussian quadrature.

## Independent checks to retain

- SciPy `roots_legendre(6)` supplies independent roots/weights; tolerate absolute
  error `5e-15` for nodes, weights and every normalized tap.
- Check positive weights, strictly increasing interior nodes, moments through
  degree 11 within `5e-15`, exact node complement sums and exact tap mirror pairs.
- Require the rounded tap DC sum within `5e-15` of one. Do not rescale individual
  taps afterward merely to force a particular floating reduction order to one.
- Recompute coefficients with independent NumPy/SciPy sinc/I0 and inspect the
  full frequency response with phase positions, not an ordinary 576-sample FIR.
- Test a constant source after history fill, independent phase convolution,
  reset epochs and ring wrap. Compare actual C++ output with independent Q6 and
  Q16/Q32/Q64 continuous references over the already frozen matrix.
- A `--check` mode must be read-only and fail missing/stale output. Match the
  existing generator's atomic publication and symlink refusal. No timestamps,
  absolute paths or optional-library versions belong in generated header bytes.
