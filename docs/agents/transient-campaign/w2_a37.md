## Reviewed behavior

- `instrument_state.hpp` retains exactly 16 bytes: RHST magic, version 1,
  little-endian model bytes 6–7 and explicitly assembled binary32 payloads.
  The functional change from the campaign baseline is solely admission of tag
  3. Both omitted-argument defaults remain 1. Exact-size validation precedes
  indexed reads; signed-zero canonicalization and integer gain validation are
  unchanged. Decoding compares the caller's selected model, so adding a supported
  tag does not create automatic conversion between instruments.
- Processor and both controller readers pass their private `kStateModel`.
  Invalid streams cannot reach `StateMailbox::request_recall`. Controller recall
  decodes the entire packet, checks both parameter objects and validates gain
  before changing either value. Stream transfers remain bounded to sixteen
  positive-progress calls. Partial I/O may advance host-owned stream position;
  the atomicity promise concerns plug-in configuration and audio state.
- Processor preflight precedes mailbox consumption. Ownership/cursor rejection
  restores a consumed pending recall with `abort_block`; valid recall precedes
  offset-zero automation. Publication uses compare/exchange so a pending newer
  UI recall is not overwritten by audio-block completion. The design retains
  its documented single audio-owner and host lifecycle synchronization premise.
- Gain/sustain parameter IDs remain 0/1, gain maps normalized 0.5 to 16x, sustain
  has Off/On values and a 0.5 threshold, and CC64 maps only bus 0/channels 0–15.
  Control conversion uses the existing integer bit rules. The controller's
  only baseline code change is the shadow-avoiding `interface_id` rename.
- Static inspection found six distinct FUID word tuples. Factory registration
  uses the selected processor/controller pair; target-private variant macros
  and hidden implementation visibility remain configured. Existing model-1/2
  identities and versions are unchanged.

The inspected retained tests include literal model-3 bytes, all six ordered
cross-model pairs, exhaustive unsupported 16-bit tags, short/error stream
transfers, controller lifecycle/mapping, and pending-recall/history comparisons.
This is a coverage review, not a new execution of those suites.
