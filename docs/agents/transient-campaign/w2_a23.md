## Implementation

The new runner has its own study identity and deterministic plan hash. It keeps
the exact original 2,097 full / 36 pilot case documents, events and rate bits,
binding the original filtered plan hash and a separate case-matrix hash. The
full matrix still contains 2,534,400 frames; the pilot contains 92,160.

Q6 uses independently constructed SciPy Legendre nodes and the analytic kernel.
No production generator, serialized taps or C++ transition matrices are imported.
The existing piecewise analytic trajectories, Q16/Q32/Q64 refinement and pure
metrics operation are reused through explicit arguments. No module globals are
patched. The local A-reference slot is translated to `quadrature_q6_volts` in
retained records; historical model-2 output and evidence remain unchanged.

The parser requires model `synthetic-quadrature-audio`, six nodes,
`gauss-legendre-host-cell`, exact host-rate bits and 48-frame latency. It rejects
uniform internal-rate/oversampling claims, malformed numeric domains, booleans,
duplicate JSON keys, nonfinite samples, wrong counts and oversized JSON.

Each numerical run retains its exclusive output directory, plan/manifest,
source and binary hashes, probe input/stdout/stderr, all five raw float64 arrays,
per-case A/B/refinement metrics, event regions, failures and peak/RMS maxima.
The final source/binary recheck detects changes during execution. Failed probe
output is retained before interpretation. Exit codes distinguish numeric
failure, unresolved reference, and incomplete/operational failure.
