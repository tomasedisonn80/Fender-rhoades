# Wave 2 assignment 36 — Quadrature command-line contracts

## Scope and result

Added `tests/cpp/quadrature_cli.cmake`, a retained Q6 exporter/renderer fixture
requiring only CMake and the already-built executables. The existing direct and
filtered CLI fixtures are unchanged. Only this new fixture and this report were
written; production sources, CMake target registration, project state and Git
publication remain with the integrator.

The fixture requires absolute `PROBE`, `RENDERER` and `TEST_ROOT` arguments.
It creates a randomly named child directory under `TEST_ROOT`, retains it on
failure for inspection, and removes it after success. All external process
invocations have a 30-second timeout.

## Retained behavior

- Every successful probe invocation must report model
  `synthetic-quadrature-audio`, six nodes, observation scheme
  `gauss-legendre-host-cell`, and 48 latency frames. Uniform oversampling and
  internal-rate fields must be absent. Sample-array length must equal frames.
- Ten rate cases include the nine frozen matrix rates and 44100.5 Hz. Raw JSON
  field matching retains the exact decimal round trips immediately above 48 and
  96 kHz instead of relying on an equality comparison that might collapse two
  adjacent doubles. Each excited two-frame result has a zero first frame and a
  nonzero second frame, consistent with completed-cell output.
- Reset-before-strike reproduces the fresh trajectory; strike-before-reset is
  silent. A reset and strike at frame 64 reproduce the first 65 samples of the
  baseline exactly, covering the exporter block boundary and history clearing.
- The 4096-frame silent limit, 4096 same-offset events, 128-byte row limit,
  alternate option order, CRLF and an unterminated final row are accepted.
  Excess bytes/rows, invalid late rows, ordering/range/type violations,
  nonfinite rates, malformed frames and ambiguous options reject with empty
  stdout and the quadrature diagnostic prefix.
- The renderer names quadrature and its node count without an internal-rate
  claim. It writes exactly the requested 0.01-second duration at 32, 48 and
  192 kHz. The fixture decodes the little-endian WAV fields and examines every
  binary32 sample's exponent bits to reject NaN and infinity, retaining the
  causal zero first sample and requiring nonzero excited output.
- Rejected replacement and invalid forced replacement preserve existing bytes;
  an explicit valid forced replacement publishes a complete silent WAV. Bad
  rates, missing parents and directories reject without publication. Live and
  dangling final symlinks reject with and without force, preserving the link
  spelling returned by the host and target contents. Hosts unable to create a
  symlink report that portion as skipped. Temporary output cleanup is checked.

## Integration and limits

Register one CTest using `-DPROBE=$<TARGET_FILE:rhodes_quadrature_probe>`,
`-DRENDERER=$<TARGET_FILE:rhodes_render>`, an existing absolute build directory
for `TEST_ROOT`, and `-P tests/cpp/quadrature_cli.cmake`. The test does not require
the VST3 SDK: both executables are available in the ordinary core test build.

No production defect was found. This assignment establishes the observed Linux
CLI/container/publication behavior of the recorded binaries. It does not claim
native Windows/macOS execution, a full numerical reference comparison, an
audio-device result, measured instrument fidelity or benchmark acceptance.
