## Added fixture

`tests/cpp/vst3_quadrature_contract_test.cpp` requires the target-private
`RHODES_QUADRATURE_VST3=1` definition and rejects a filtered definition. Its
four selectors can also be run together using `all`:

| Selector | Retained contract |
|---|---|
| `qhost_identity_delay` | Literal model-3 FUID/name/version, setup-independent 48-frame latency and infinite-tail metadata, coefficient centre in physical fractional-source coordinates, host output against chronological per-node convolution |
| `qhost_foreign_recall` | Every other supported model (1 and 2), plus invalid tags 0, 4 and 65535, is rejected by processor and both controller state readers; rejection preserves a pending valid model-3 recall, moving note ownership and more than two full filter histories |
| `qhost_recall_order` | Latest pending recall remains visible to save; a final invalid event cannot consume it; accepted recall clears old history/ownership before offset-zero controls and strike; later empty/audio callbacks do not replay recall |
| `qhost_reset_tail` | Processing, activation, repeated setup and valid recall reset paths clear warmed mechanics and delayed history while retaining the required state/identity; a later strike matches a fresh recalled instance |

All large processors, plans, queues, histories and copied engine snapshots are
heap-owned outside processing. State packets are constructed as literal RHST
v1 bytes rather than through the production encoder. Positive short reads use
1-, 3- and 16-byte chunks from a nonzero stream offset. These checks supplement
the existing shared suites; exhaustive unsupported-tag codec coverage remains
in `instrument_model_state_test.cpp`.

The timing fixture does not use `QuadratureEngine` or `QuadratureFir` as an
output oracle. It independently retains chronological cells, evaluates an
ordinary long-double convolution, and compares the full 256-frame host block
without fitted gain, phase or shift. It exercises sustain at frames 46/128,
strikes at 0/63 and releases at 47/95 for keys 0, 40 and 72 at 32, 48 and
192 kHz in both sample formats. Its source observations and checked-in taps are
shared ingredients; the separate analytic observation and independent
coefficient/reference fixtures establish those ingredients' numerical bounds.
The coefficient first moment uses `age + 1 - node`, explicitly checking the
48-frame centre. The first output after reset/strike must be zero and the
second must be nonzero; this is a causal completed-cell convention, not a
claim that output stays silent for 48 frames.

## Handoff and limits

Root should register the four selectors in a quadrature-only executable linked
like the existing host contract targets and include that executable in the
aggregate host-check target. The fixture requires only C++20 and the existing
SDK dependencies. It does not test a real DAW, certify native Windows/macOS
execution, measure callback deadlines, or establish physical Rhodes fidelity.
No production defect was observed by this assignment.
