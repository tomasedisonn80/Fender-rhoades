# W2 A31 — Retained quadrature engine contract tests

Assignment 31/100, wave 2. This bounded RT-001/HOST-001 test assignment read the
operating contract, README, roadmap, canonical/generated state, frozen quadrature
contract, A22 implementation report, wrapper, FIR, event processor and related
legacy tests. The parent owns integration and canonical task leases. No
production, CMake, canonical-state or Git changes were made by this worker.

## Added fixture

Added `tests/cpp/quadrature_engine_test.cpp`, with these five independently
selectable fixtures and an `all` selector:

| Selector | Retained checks |
| --- | --- |
| `qengine_events` | Completed-cell output timing, exact host-boundary mechanical state, persistent retrigger/release/pedal/all-notes-off behavior, reset clearing, equal-offset reset/strike producer order |
| `qengine_partitions` | Bitwise output and exact mechanical state across full, one-frame and mixed partitions, including empty blocks and event-boundary splits |
| `qengine_prepare` | Rejected host rates, candidate core/plan failures, retained metadata/history/controls/plan, empty wrapper calls, successful prepare/reset clearing and reset reuse of the plan |
| `qengine_faults` | Missing/nonfinite observations at every node, false/nonfinite boundary advances, nonfinite FIR sums, valid-prefix retention, failed-sample/suffix silence, reset-required event fence and explicit recovery |
| `qengine_allocations` | Calibrated ordinary/array C++ allocation interception around full-keyboard, retrigger, release/pedal, empty and reset audio calls |

All large engine, processor and observation-plan fixtures are heap-owned outside
the audio guards. The fake engine substitutes deterministic observation and
advance faults without changing production code. Its counters check that no
later node or boundary advance executes after the first failure.

The event oracle stores complete cells chronologically and performs an ordinary
long-double sum; it does not use the production ring or wrapper. It shares the
generated coefficients and fractional observation API, which have separate
independent oracle fixtures. It therefore tests wrapper scheduling and state
preservation, not independent coefficient generation or physical accuracy.

All five fixtures passed. Actual observations:

- Nine exact rates: 32,000; 44,100; 48,000; the next representable value above
  48,000; 64,000; 88,200; 96,000; the next representable value above 96,000; and
  192,000 Hz.
- 2,889 event/oracle frames with maximum absolute convolution discrepancy
  `3.89737e-17 V`, below the fixture's `2e-14 V` bound. Every key/mode boundary
  displacement, velocity and total mechanical energy matched the original
  host-rate core exactly after every frame. Reset/strike and strike/reset both
  emitted zero at their shared boundary and produced distinct subsequent
  waveform and mechanical state.
- 36 partition/rate combinations produced identical samples and final states.
- 81 warmed invalid-rate transactions preserved future samples exactly. Two
  injected candidate failures separately covered core and plan preparation.
  Successful preparation and explicit reset cleared histories and mechanics;
  reset did not call observation-plan preparation.
- 84 node/advance fault cases each passed directly and through the event
  processor. All six observation nodes, four output offsets (0, 1, 17, 63),
  missing/NaN/infinite observations, and false/NaN/infinite advances were
  exercised. A finite maximum-valued source overflowed the filter at frame 49;
  the wrapper discarded the nonfinite provisional output without observing or
  advancing that cell. All failures latched the event fence, refused queued
  reset and invalid-prepare recovery, and recovered after external reset.
- 81 guarded audio calls observed zero ordinary/array C++ allocations. Direct
  replacement-operator calls first calibrated both intercepted allocation forms.

`git diff --check -- tests/cpp/quadrature_engine_test.cpp` also returned success.
