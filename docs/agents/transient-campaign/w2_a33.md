## Retained checks

`coexist DIRECT_BUNDLE FILTERED_BUNDLE QUADRATURE_BUNDLE` loads all three actual
production bundles concurrently. It executes all six physical loading orders,
with both float32 and float64 callbacks at 48,000 and 192,000 Hz: **24 sessions**.
Every session verifies:

- Six unique, frozen processor/controller FUIDs; distinct factories; exact
  class names and versions 0.1.0/0.2.0/0.3.0.
- State models 1/2/3 inside the unchanged 16-byte RHST v1 envelope, latency
  0/48/48 frames, infinite asymptotic tail, instrument buses and public control
  defaults.
- Pairwise distinct rendered strike traces, identical mono-derived stereo
  channels, finite values and accurate silence flags. Each model's trace must
  be exactly equal across all six loading orders.
- All six ordered foreign-model recalls using packets actually saved from the
  peer modules. Each rejection occurs while a valid own-model half-gain/sustain
  recall is pending. Processor and controller snapshots must remain unchanged;
  the following callback must clear the preceding note/tail; the next strike
  must equal exactly half the same model's default-gain trace. This detects
  loss of the pending recall as well as replacement of its settings.
- Reset and strike isolation while every peer receives callbacks, independent
  active/silent states, and complete interface release before module unload.

`duplicate_guard` takes the same three paths. It deliberately repeats each
bundle in each of the three possible pairs of slots and requires identity
collision detection: **nine negative loading scenarios**.
