## Contract trace

- **Timing:** `QuadratureFir::output` reads completed cells before the wrapper
  observes the current cell. Its newest values are at `n-1+a[j]`, paired with
  taps at `1-a[j]`. The next write occurs after the core advances. The combined
  fractional-coordinate kernel therefore retains its declared 48-frame center;
  a zero first output is not a promise of 48 initially silent samples. Retained
  sinusoid and chronological-convolution fixtures distinguish a 49-frame error.
- **Observation:** Both damping regimes are prepared in a temporary plan and
  published only after validation. `observe` checks node and exact positive
  host-rate equality, reads current held/sustain state, computes local q/v
  without writes, combines modes before nonlinear conversion, and supplies all
  73 sources to the existing loaded harp. Reset reuses the plan.
- **Events and failures:** Producer order is preserved at each boundary;
  retrigger, release and pedal changes retain histories. Hard reset clears them.
  FIR cells are fully validated before ring mutation. Output is published only
  after every observation, boundary advance and cell push succeeds. Failure
  preserves the valid prefix and zeros the failed frame/suffix. The raw wrapper
  documents caller-managed reset; its host-facing event processor enforces the
  reset fence. No rollback of partially advanced mechanics is claimed.
- **Compatibility:** A fresh static comparison removed only the two added
  methods and their includes from `research_engine.cpp`; the remaining entire
  file exactly matched campaign baseline `60be432`. `audio_engine.hpp`,
  `fir_decimator.hpp`, `audio_filter_coefficients.hpp` and `event_processor.hpp`
  also matched byte-for-byte. Baseline diffs preserve both old FUID pairs,
  names, versions, model defaults and latency values. This source evidence does
  not replace the planned final rendered-fingerprint comparison.
- **Identity:** Probe, renderer and benchmark branches correctly describe
  quadrature nodes and host-cell observations. They do not attach a fabricated
  uniform oversampling factor or internal rate to model 3. Host latency,
  saved-state tag and private variant selection agree.
