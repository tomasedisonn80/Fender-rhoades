## Implementation

The existing bounded probe source now supports a second executable compiled
with `RHODES_QUADRATURE_PROBE=1`. It uses `QuadratureEngine`, retains the shared
argument/input preflight and ordered dispatcher, and constructs its larger
engine on the heap only after every row is validated. The default executable
keeps its original engine, help, error prefix and JSON branch.

The new probe reports schema 1, model `synthetic-quadrature-audio`, the exact
binary64 host rate, six quadrature nodes, observation scheme
`gauss-legendre-host-cell`, and 48-frame latency. It preserves frame/event
counts, unscaled double-precision loaded volts, startup and reset behavior.
It emits no uniform internal-rate or oversampling fields. Invalid input and
stdout failures retain exit code 2 with the new executable's own prefix.

The renderer accepts `--audio-path quadrature` and reports six observations per
host cell, host rate and 48-frame latency. The default remains direct; direct
and filtered success metadata retain their original text. Existing integer
WAV rates, gain, release timing, requested frame count, float32 conversion and
transactional publication code are reused without modification.
