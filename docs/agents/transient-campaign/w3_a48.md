# Wave 3 assignment 48 — Frozen callback measurement protocol

## Scope and result

Prepared a prospective `RT-001` protocol in
[QUADRATURE_BENCHMARK_20261123.md](../../specs/QUADRATURE_BENCHMARK_20261123.md)
and its [machine-readable plan](../../validation/quadrature-benchmark-plan-20261123.json).
No formal timing measurement, benchmark process, rebuild or performance
acceptance was run by this assignment. The existing root exploratory observation
is explicitly outside the formal campaign.

The plan has 12 profiles, all three variants and two counterbalanced rounds:
**72 processes, 40,128 measured callbacks, 2,136 warmup callbacks, 3,846,144
measured host frames and 338,304 warmup frames**. Coverage includes 0/1/73 keys,
held/pedal/gain schedules, 32/64-bit output, 48/192 kHz, one/32/64/256/8192-frame
blocks, and dense controls at high rate and maximum block size. Ordinary profiles
use 512 measured/32 warmup calls; one-frame profiles use 1024/32; the maximum
block profile uses 32/4.

Round one rotates the three variant orders across profiles. Round two reverses
both profile order and each profile's variant order. Each variant occupies each
position eight times. The JSON contains every concrete argv and 216 distinct
stdout/stderr/execution filenames, plus expected frames, note/parameter counts,
owners, latency and variant identity.

A Linux launcher selects the lowest permitted logical CPU and verifies that
all children are pinned to it before execution. It does not alter global
settings. Failure to establish this binding ends the attempt explicitly. The
benchmark's raw metadata remains intact; an external manifest records launcher
policy, compiler/flags, source/binary hashes, SDK pins, hardware, cgroups, clock,
priority/power availability and competing work. All source/binary inputs must
remain stable through capture. Results require a durable raw archive, including
failures, with no outlier removal, automatic retry or timing pass threshold.

All 36 same-variant repeat pairs require fingerprint/accounting comparison.
Statistics and strict nominal-period misses are recomputed from raw durations;
both rounds remain separate. Device underruns, causal speedups, worst-case
execution time, long-tail behavior, allocation policy and fidelity remain outside
these prospective timing claims.
