## Added coverage

Eight focused tests inspect the emitted binary64 header independently of the
generator's returned arrays. They cover:

- Q6 moments of degrees zero through eleven on `[0,1]`, positive weights and
  interior ordered nodes; moment tolerance `4e-16`.
- Exact rational complementary binary64 node pairs, mirrored weights/taps,
  six-by-96 dimensions, finite coefficients, DC within `5e-15`, and the
  physical-lag first moment at 48 frames within `1e-13`.
- A separate SciPy `roots_legendre(6)` and NumPy sinc/I0 kernel calculation:
  nodes/weights within `2e-15`, normalized taps and normalizer within `5e-15`.
  The oracle does not reuse production roots, serialized nodes or Decimal math.
- Byte-identical committed-header generation despite a caller's low Decimal
  precision, altered rounding and inexact-operation trap.
- Generation and default-path checking from another working directory under
  `python -S`, without site packages.
- Read-only stale/missing checks that retain bytes, inode, modification time and
  directory inventory.
- Rejection of live/dangling symlink destinations without altering either link
  or target, and rejection of missing parents/existing output directories.

NumPy/SciPy remain optional offline test dependencies: their independent test
skips explicitly if absent. Symlink tests similarly report a host limitation
if link creation is unavailable. All eight tests executed here without skips.
