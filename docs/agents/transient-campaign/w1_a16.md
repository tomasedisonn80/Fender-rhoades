# W1 A16 — Model-3 codec and state-test patch plan

Assignment 16/100; bounded HOST-001 source review. Reviewed the existing
model-1/model-2 codec and tests during the working tree based on published
`5aac654f8569aaa782e7bce58e82b3213b57da23`. Only this report was written.

## Minimal production change

In `include/rhodes/instrument_state.hpp`, extend `state_detail::valid_model`
from `{1,2}` to `{1,2,3}` and update the wire-format comment. Preserve the
16-byte size, RHST magic, wire version 1, little-endian tag bytes 6–7, gain/pedal
bit validation, signed-zero canonicalization, and both default arguments `= 1`.
The codec must still compare the packet's model with the explicitly expected
model. Admitting 3 does not mean accepting any supported tag on a default read.

`plugins/vst3/state_stream.cpp` already forwards its explicit expected model and
rejects unsupported arguments before any stream operation; it needs no algorithm
change for tag 3. Keep stream-header defaults at model 1. The mailbox stores only
validated controls, so adding a model field there is unnecessary and would expand
the compatibility surface.

## Concrete test edits

In `tests/cpp/instrument_model_state_test.cpp`:

1. Keep both existing literal golden arrays unchanged. Add a separate literal
   model-3 golden: `52 48 53 54 01 00 03 00 00 00 00 3f 00 00 80 3f`.
   Extend the independent `models` array to `{1,2,3}` and use an explicit golden
   array/switch instead of every `model == 1 ? model1 : model2` selection.
2. Retain `model1_golden` and `model2_roundtrip` selectors. Factor the existing
   11-gain-pattern/sustain roundtrip body into an explicit-model helper, keep
   model-2 invocation and its literal check, and add `model3_roundtrip` with
   a literal golden check. Register that selector in root CMake as well.
3. Replace `3U - model` in both `cross_model_rejection` and `stream_rejection`
   with an inner loop over the independent literal supported set, skipping only
   `other == model`. This covers all six ordered pairs. The current four gains
   and two pedal values give 48 codec cross-rejection payload cases. Retain
   input-byte immutability and same-model success after rejection.
4. Explicitly reject model-3 bytes through the omitted/default decoder and
   omitted/default stream reader, alongside the existing model-2 checks.
   Keep the default writer's exact model-1 golden assertion.
5. In both exhaustive unsupported-tag loops, skip exactly `1`, `2`, `3`; count
   and assert **65,533** rejected tags. Do not use production `valid_model` to
   select the expected domain. Keep the `uint32_t` loop variable, avoiding
   wraparound at 65,535. For each unsupported tag, retain matching unsupported
   packet/argument rejection, rejection against every supported expectation,
   and valid-packet rejection under the unsupported expectation. High-byte tags
   such as `0x0101`, `0x0102`, `0x0103` remain included.
6. Extend malformed payloads, exact/truncated/extended lengths, unaligned guards,
   chunk sizes 1–16, and partial-transfer faults to model 3 by the shared model
   loop. Preserve stream no-I/O assertions for unsupported arguments. Separate
   cross-model packets from the five existing malformed-packet cases so adding
   two foreign tags does not silently drop malformed gain/pedal coverage.

## Preserve the default-model property suite

`tests/cpp/state_property_test.cpp` intentionally tests omitted model arguments:
its literal model-1 header, independent binary32 domain, 19,474 input-pattern
count, and **2,040 rejected one-byte header mutations** should stay unchanged.
Mutating the default packet's tag to 2 or 3 must still reject. Broadening that
suite's acceptance predicate merely because 3 is supported explicitly would
erase an important backwards-compatibility check. The shared model test's new
model-3 gain/pedal and malformed cases cover this additive change without
triplicating the entire default-domain corpus.
