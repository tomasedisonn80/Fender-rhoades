## Project-specific deduction

The following is an original application of quadrature and convolution, not a
claim that a source above prescribes this implementation. For Gauss nodes and
weights mapped to `(0,1)`, define six fixed coefficient branches

```text
h[j,k] = w[j] K(k + delta[j]) / N6,  j = 0..5, k = 0..95
N6 = sum(j,k) w[j] K(k + delta[j])
y[n] = sum(j,k) h[j,k] x(n - k - delta[j])
```

The newest observations are inside the completed cell `[n-1,n)`, so output at
`n` uses previously observed data. The current cell is then projected from the
existing mechanical boundary state for use at the next frame. Because the
declared event model places all events at integer frame boundaries, no node
samples an isolated strike endpoint. A reset also clears the convolution
history; other events preserve it. An API accepting fractional-frame events
would require a new partitioning design.

Six 96-entry histories permit a fixed 576-term convolution per frame. This is
an operation count for the proposed sum, not measured CPU usage. Precomputing
nodal transition matrices removes their transcendental evaluations from the
callback; that remains a code-review and runtime-verification obligation.

Q6's polynomial exactness is degree 11, but the actual integrand is not such a
polynomial. Retain independent Q16/Q32/Q64 refinement and the existing absolute
voltage gates. Also test 48-frame timing, kernel normalization, startup, ring
wrap, same-offset event order, reset, and mechanical boundary-state equivalence.
Numerical improvement cannot establish instrument fidelity or audibility.
