# W1-A005 — Predeclared synthetic contact fixtures and tolerances

**Date:** 2026-11-23. **Assignment:** bounded design review for `PHY-002`.
**Status:** proposed inputs and acceptance budgets, to be reviewed and frozen by
the integrator before implementation. No contact solver or acceptance test was
run in this assignment. None of these constants is a specimen measurement.

## Scope and basis

This proposal follows [the contact contract](../../specs/CONTACT_REFERENCE.md)
and [the solver contract](../../specs/REFERENCE_SOLVERS.md). It covers an offline
two-mode reference with a finite-mass hammer and a prescribed compliant damper.
It does not establish a mechanical action model, measured half-pedal response,
real-time cost, or instrument fidelity. The existing implementation inspected was
the analytic modal/impulse surrogate in `include/rhodes/research_engine.hpp` and
`src/research_engine.cpp`; the proposed results below are derived from equations,
not fitted to that implementation.

Use SI units throughout. Modal coordinates are metres with dimensionless shape
coefficients. With diagonal modal matrices, `K_j=m_j omega_j^2` and
`C_j=2 m_j beta_j`. The hammer compression is
`delta_h=x_h-b_h^T q-g_h`; generalized force is `+b_h F_h` and hammer force is
`-F_h`. All unforced fixtures omit gravity, preload, magnetic reaction and
electrical feedback explicitly. Zero is their assembled uncompressed equilibrium.

For either contact, evaluate positive compression only:

`F=max(0, delta^p (k+c delta_dot))`, `U=k delta^(p+1)/(p+1)`.

The unclipped loss rate is `c delta^p delta_dot^2`; when the raw force is
nonpositive at positive compression, the loss rate is
`-k delta^p delta_dot`, which is nonnegative on that branch. Keep geometric
contact, force clamping, and separation as separate states.

## 1. Exact conservative free impact

Use two API modes, with the second decoupled and initially zero. The active mode
is a free mass: `m_1=0.002 kg`, `omega_1=beta_1=0`, `b_h=(1,0)`.
The unused second mode has `m_2=0.001 kg`, `f_2=650 Hz`, `beta_2=0`, and zero
displacement/velocity. A zero-frequency free mass must be supported by the
offline reference or by an explicitly separate free-mass fixture; the current
runtime oscillator's positive-frequency guard is not this reference's domain.

Set `m_h=0.008 kg`, `p=1`, `k_h=20000 N/m`, `c_h=0 N s/m^2`, `g_h=0 m`,
`x_h=q_1=0 m`, `v_h=1 m/s`, and `v_1=0 m/s`. Disable the damper. Run to
`0.002 s`. Onset is at zero; separation must happen once and precede the final
observation. Define `mu=m_h m_1/(m_h+m_1)`, `Omega=sqrt(k_h/mu)`, and
`V=0.8 m/s`. During contact:

`delta=sin(Omega t)/Omega`,
`x_h=V t+0.2 delta`, `q_1=V t-0.8 delta`,
`v_h=V+0.2 cos(Omega t)`, `v_1=V-0.8 cos(Omega t)`.

After `t_s=pi/Omega`, propagate the separating masses freely. This piecewise
closed form is the independent trajectory oracle.

| Observable | Analytic value |
|---|---:|
| Reduced mass | `0.0016 kg` |
| Relative angular frequency | `3535.533905932738 rad/s` |
| Separation time | `0.0008885765876316731 s` |
| Maximum compression | `0.0002828427124746190 m` |
| Maximum force | `5.65685424949238 N` |
| Contact impulse | `0.0032 N s` |
| Hammer velocity after separation | `0.6 m/s` |
| Resonator velocity after separation | `1.6 m/s` |
| Relative separation velocity | `-1 m/s` |
| Conserved momentum | `0.008 kg m/s` |
| Conserved total energy | `0.004 J` |

The hammer continues forward in this mass ratio. Calling its absolute velocity
negative would be an incorrect rebound expectation; rebound is relative motion.

## 2. Damped impact and an independently forced clamp

For the damped impact, retain fixture 1 and set `c_h=40000 N s/m^2`. With
`a=c_h/k_h=2 s/m`, define `Phi(w)=a w-ln(1+a w)`. The separating relative
velocity is the unique root in `(-1/a,0)` of `Phi(w_out)=Phi(1 m/s)`.
This follows by integrating `mu w dw/d(delta)=-delta(k_h+c_h w)`.
The return velocity and compression therefore have independent scalar oracles
even when contact time is obtained by an independently refined integration.

| Observable | Derived value |
|---|---:|
| Relative separation velocity | `-0.4107196860610394 m/s` |
| Maximum compression | `0.0001898828808852331 m` |
| Contact impulse | `0.002257151497697663 N s` |
| Hammer separation velocity | `0.7178560627877921 m/s` |
| Resonator separation velocity | `1.1285757488488315 m/s` |
| Dissipated energy | `0.000665047471585537 J` |

The compression formula is
`delta_max^2=2 mu k_h Phi(1 m/s)/c_h^2`; the loss is
`D=mu ((1 m/s)^2-w_out^2)/2`. An ordinary free impact need not enter the clamp:
do not claim clamp coverage merely from a large damping coefficient.

For exact clamp coverage, use free masses with `delta_0=0.0001 m`,
`v_h=-1 m/s`, `v_1=0 m/s`, the same `k_h,c_h`, and zero modal loss. Set
`x_h=delta_0`, `q_1=0`. The raw factor is `k_h+c_h delta_dot=-20000 N/m`,
so `F=0 N` while `delta=delta_0-(1 m/s)t` until separation at `0.0001 s`.
Run to `0.0002 s`. Hammer and resonator velocities remain constant, impulse is
exactly zero, and accumulated clamp loss is exactly `0.0001 J`. Initial total
energy is `0.0041 J`; final kinetic energy is `0.004 J`. The incorrect
unclipped formula would accumulate `0.0002 J`, exposing a specific ledger error.

system. A separately assembled matrix exponential plus bracketed branch roots

This separately exercises arbitrary positive time increments without contact.

## 4. Coordinate rescaling by `(2,-3)`

Repeat the supported, moving-damper, and retrigger cases with
`S=diag(2,-3)`, `q'=S q`, `v'=S v`. Transform every observation and force
participation by `S^-1`, and every modal mass/stiffness/damping coefficient by
`1/s_j^2`. Frequencies and `beta_j` remain unchanged. In particular:

`m'=(0.0005,0.001/9) kg`, `b_h'=(0.5,-0.35/3)`,
`b_d'=(0.5,1/12)`, `a_p'=(0.5,-0.2/3)`.

Compare reconstructed physical motion, contact gaps, force, impulse, energy,
work, event sequence and pickup voltage. For the voltage diagnostic use the
same synthetic linkage law `lambda(x)=0.4 x+800 x^2+400000 x^3` in both runs,
with coefficients in `Wb/m`, `Wb/m^2`, and `Wb/m^3`; evaluate
`e=-(0.4+1600 x+1200000 x^2) x_dot` after summing modal motion. This is only a
coordinate-invariance diagnostic, with no electrical-loading or calibration claim.

## 5. Relaunch, phase and event order

Construct two supported snapshots with identical
`q=(0.00008,-0.00002) m`, velocities respectively `(0.2,-0.1)` and
`(-0.2,0.1) m/s`, compression `delta_h=0.00005 m`, and hammer velocity
`-0.3 m/s`. Set `c_h=40000 N s/m^2`. A velocity-only relaunch sets hammer
velocity to `1 m/s`, preserving all positions and both modal velocities exactly.
The event work is `0.5 m_h (1^2-(-0.3)^2)=0.00364 J`; no contact potential
changes at the event. The two new relative speeds are `0.835` and `1.165 m/s`,
and immediate contact forces must be `2.67` and `3.33 N`, respectively. These
values detect a modal reset or confusion between launch speed and impact speed.

Also relaunch an actually evolved supported trajectory at `0.0037 s`, recording
the complete before/after state and kinetic-energy work. Release/key-lift events
must likewise preserve modal state. No hammer teleport is included in these
fixtures; any future position-setting action needs its own potential-work entry.

For exact event ordering, use fixture 1 and relaunch at `t_s-0.000001 s`,
`t_s`, and `t_s+0.000001 s`. First integrate the old dynamics to the external
event time, then apply the velocity event, then recompute geometric and clamp
state. At zero compression, positive relative velocity is onset; negative
relative velocity is separation; zero relative velocity is a grazing candidate.
At positive compression, zero raw force is a clamp boundary, not separation.
Record one chronological event row for each change, with no state-reset shortcut.

## 6. Compliant damper, equilibrium and moving-pedal work

Define a prescribed surface position `ell(t)` in metres and compression
`delta_d=b_d^T q-ell(t)`, with relative speed
`delta_dot_d=b_d^T v-ell_dot(t)`. The modal force is `-b_d F_d`.
Use `p_d=1`, `k_d=12000 N/m`, `c_d=30000 N s/m^2`; park the hammer at
`-0.002 m` with zero velocity. The external power delivered to the modeled
system is **`P_pedal=-F_d ell_dot`**. Its sign follows from this declared gap
and force convention. Count signed work, including energy removed on withdrawal.

For a fixed, preloaded surface, set `ell=-0.00005 m`. With
`H=b_d^T K^-1 b_d`, the equilibrium is
`delta_*=-ell/(1+k_d H)`, `F_*=k_d delta_*`,
`q_*=-K^-1 b_d F_*`, `v_*=0`. This provides an independent assembled
equilibrium. Check zero acceleration and constancy, then perturb `q_1` by
`+0.000001 m` and `-0.000001 m` in separate runs. Total modal plus contact
energy must decrease by the recorded loss within the budget. Tine energy alone
is insufficient because preload stores contact energy.

For moving travel, start at `q=v=0` and prescribe
`ell(t)=0.00015+0.00025 cos(2 pi t/0.012) m` for `0<=t<=0.024 s`.
This is continuous pedal geometry with clearance varying from `0.0004` to
`-0.0001 m`. Compare engagement, separation and any recontact against an
independent method, retaining modal state throughout. Check
`E(t)-E(0)+D(t)-integral(P_pedal dt)=0` within tolerance.

Separately start from the preload equilibrium and prescribe
`ell(t)=ell(0)+(0.02 m/s)t` and `ell(t)=ell(0)-(0.02 m/s)t`, each for
`0.0001 s`. These short withdraw/advance runs have opposite initial work signs
while the contact stays compressed initially, directly testing the signed port.
All prescribed-motion breakpoints are external events, not displacement resets.

## 7. Grazing, nonlinear extension and declared coverage

Use the active `200 Hz` mode without modal damping, amplitude `A=0.0001 m`,
and stationary hammer `x_h=-A`, with analytic free motion
`q(t)=-A cos(2 pi 200 (t-t_*))`, `t_*=0.0010073 s`. Set the second mode
to zero and `b_h=(1,0)`; use the conservative hammer law. The unperturbed case
is tangent with exactly zero impulse. Perturb hammer position by
`-0.00000001 m` for a miss and `+0.00000001 m` for a short contact. The
unforced geometrical contact-window estimate is about `0.0000225 s` in the
positive case; the actual coupled trajectory must be independently refined.
Include a `0.00006 s` outer call containing the turning point, whose endpoints
alone can miss both roots. Do not merge the miss, tangent, and contact outcomes.
For these cases require event-bracket gap uncertainty below `1e-12 m`, and
short-contact impulse discrepancy below `1e-11 N s` plus `0.005` relative.
Ambiguous classification or a missed positive impulse is inconclusive/failing,
even when the general absolute impulse budget would mask it.

The primary freeze supports `p=1` only. If arbitrary exponents are implemented,
add `p=1.5` with `k_h=4/(0.0002^1.5) N/m^1.5` and
`c_h=2 k_h s/m` before claiming that domain, using independent-method refinement.
This matches `4 N` elastic force at `0.0002 m` compression without inventing
material data. Exponents below one are outside this proposal. Do not claim
continuous parameter-range validation from these discrete fixture points.

Arbitrary-dt means physical seconds independent of an audio sample-rate ceiling.
Exercise outer increments `0.000017`, `0.000031`, `0.000007`, `0.000103`,
and `0.0000025 s`, plus the grazing call, and truncate the last call to the
same final physical time. Internal subdivision is allowed and must be recorded.
Declare the tested call domain and reject nonfinite/nonpositive increments
atomically; no claim of accuracy for every positive finite step follows.

## 8. Frozen error budgets and refinement procedure

For each observable use `abs(candidate-reference) <= A+R abs(reference)` at
matched physical times. Use the same units on both sides. Refinement comparisons
may use the finer value as reference; no waveform time shift is allowed.

| Observable | Absolute budget A | Relative budget R |
|---|---:|---:|
| Physical/modal displacement, gap | `1e-8 m` | `1e-4` |
| Velocity, including relative rebound | `1e-5 m/s` | `1e-4` |
| Contact force/peak force | `1e-4 N` | `2e-4` |
| Integrated contact impulse | `1e-8 N s` | `1e-4` |
| Onset/separation/clamp time | `1e-7 s` | `1e-4` of elapsed fixture time |
| Free-mass momentum | `5e-9 kg m/s` | `1e-6` |
| Independent analytic force-law residual | `1e-10 N` | `1e-10` |

These are numerical engineering budgets chosen before implementation. The main
impact lasts about `889 microseconds`, so the timing budget resolves roughly
one part in five thousand of that contact; force and impulse budgets constrain
the delivered excitation. The displacement floor is small compared with the
`100–300 micrometre` fixture compression. Absolute terms remain meaningful at
zero force, zero rebound or zero waveform crossings. They do not describe
measurement uncertainty, audibility, or hardware repeatability.

Separated and clipped force must be exactly zero under the declared law, with
no attractive force. Event-only state preservation is exact equality for stored
modal state. These semantic checks are not relaxed by trajectory tolerances.

Use fixed energy scales, never a denominator derived from candidate residuals:

| Fixture family | E_ref |
|---|---:|
| Free conservative/damped impact; supported impact | `0.004 J` |
| Forced clamp | `0.0041 J` |
| Relaunch/phase | `0.005 J` |
| Fixed damper equilibrium/perturbations | `0.00001 J` |
| Moving damper | `0.0001 J` |
| Separated oscillator and grazing | `0.0001 J` |

Require `max(abs(R_n)) <= 2e-9 J+5e-5 E_ref` and
`sum(abs(r_n)) <= 4e-9 J+2e-4 E_ref`, where
`r_n=E_(n+1)-E_n+D_n-W_n` and `R_n=sum(r_n)`. Apply the cumulative bound to
fixed-linkage unexplained energy growth as well. Also compare accumulated
physical loss and signed work with the independent oracle to the cumulative
energy budget; a balanced but incorrect loss/work pair must not pass. Report
instantaneous power residual separately; near events it is not a substitute for
the interval ledger. For every synthetic launch, check event work to
`1e-12 J+1e-10 abs(W_reference)`.

Coordinate invariance is a tighter structural check: use absolute floors
`1e-11 m`, `1e-8 m/s`, `1e-7 N`, `1e-10 N s`, `1e-10 J`, `1e-7 V`,
and `1e-9 s` for corresponding physical quantities, each plus `1e-8` relative.
Event order must agree exactly. If coordinate-dependent adaptive error scaling
changes steps, compare at common times and document it; do not widen the bounds.

1. Run maximum internal steps `h=20e-6`, `h/2=10e-6`, `h/4=5e-6`, and
   `h/8=2.5e-6 s`. Compare waveform samples on the common `20e-6 s` grid,
   event values, impulse, rebound and independently located peak compression
   and force. Use the analytic or independent oracle for the finest run too.
2. Require the last two successive differences below each budget and decreasing
   (proposed criterion: final difference at most `0.8` times the preceding
   difference when resolvable). Report nonsmooth order loss; unexplained plateaus
   or unresolved grazing do not establish convergence. Further refinement may
   establish a pass, but silently increasing tolerance may not.
3. For a nonlinear solver, scale equation residuals with declared fixture scales
   `X=1e-3 m`, `V=1 m/s`, `F=10 N`, then tighten dimensionless solve tolerance
   `tau=1e-8,1e-9,1e-10` at the finest step. Report the actual formulation,
   iteration limits and residuals. An explicit method reports this refinement
   as inapplicable and still performs independent-method and event refinement.
4. Tighten event bracket width `eta=1e-8,5e-9,2.5e-9 s` at the finest step,
   with the grazing gap limit also enforced. Both solver and event tightenings
   must alter observables by less than one tenth of their respective budget.
5. Record finite iteration/subdivision caps, minimum progress and every failure.
   Exhaustion must restore the complete last accepted state and ledger before
   bounded retry, or return explicit failure. An unconverged accepted step fails.
