# A065 — Contact domain and rollback boundaries

## Scope and implementation

Added `tests/cpp/contact_domain_test.cpp`, exercising public offline-reference
operations against explicit domain tables. Production code, numerical tolerances,
acceptance budgets, CMake and canonical state remain unchanged.

The tests cover 22 configuration fields, ten floating settings, seven work/history
caps and seven state fields. Each floating table tests both admitted endpoints,
one-ULP outsiders, NaN and both infinities. Separate cases enforce exactly `p=1`,
including disabled laws, dependent minimum/maximum steps and multiple simultaneous
invalid fields.

Every rejection against a populated reference checks configuration, settings,
mechanics, observations, ledgers, diagnostics and both histories, then compares
valid continuation against an untouched control. This also exercises hidden
adaptive-step and compensated-sum state. Additional cases cover signed relaunch
endpoints and kinetic work, exact stored-time completion, all uninitialized
operations, valid but infeasible minimum-step settings, and persistent event and
interval caps reached by earlier successful calls.

Trajectory checks cover invalid enums, globally invalid sinusoidal envelopes
whose current sample looks valid, one-ULP position discontinuity, continuous
velocity changes, and a linear face leaving its allowed domain. Pure face and
observation failures preserve caller output.
