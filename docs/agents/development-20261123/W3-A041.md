## Change

Each oscillator retains two fixed transition matrices. A repeated active decay
returns immediately; selecting the alternate changes a boolean slot and decay
metadata, without copying matrices. No stored pointer can refer into another
oscillator after copying. A third supported decay uses the original coefficient
calculation and replaces the alternate only after successful validation. Invalid
updates preserve both entries and mechanics; reconfiguration clears the cache.

Engine preparation warms both synthetic loss regimes before publishing the new
keys. Note/pedal processing therefore selects prepared coefficients. Repeated
identical pedal values return immediately. Positions, velocities, energy,
equations, constants and floating-point flags are unchanged. This remains a
switched-loss surrogate, not physical contact. Arbitrary uncached decay values
still incur coefficient calculation; no general constant-time primitive claim
is made.
