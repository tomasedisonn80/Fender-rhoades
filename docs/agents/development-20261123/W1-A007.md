## 2. Contact geometry, reciprocal force, and power

Use a fixed positive normal pointing from the resonator toward the damper.
Let `z` denote unshifted modal displacement, `v = zdot`, `b` the dimensionless
damper observation vector, and `g(t)` the prescribed face position in metres.
Positive `gdot` retracts the damper. With dimensionless mode shapes:

\[
\delta=b^Tz-g(t),\qquad \dot\delta=b^Tv-\dot g(t).
\]

Positive compression has force magnitude `F >= 0`. The generalized force on
the resonator is **`-b F`**; the face receives `+F`. Use the same signed `b` in
both equations, including negative mode projections. For symmetric positive
definite `M,K`, positive semidefinite `C`, constant preload/gravity force `f0`,
and any other applied force `f(t)`:

\[
M\ddot z+Cv+Kz=f_0+f(t)-bF.
\]

The grounded support generally exchanges momentum. A supported-mode fixture
must test work reciprocity rather than assert free-body momentum conservation.

Take the specified candidate law, with finite `k > 0`, `c >= 0`, `p > 0`:

\[
A=k\delta^p,\quad U={k\over p+1}\delta^{p+1},\quad
F=\max(0,(k+c\dot\delta)\delta^p)\quad(\delta>0).
\]

For `delta <= 0`, define `A = U = F = 0` without evaluating a fractional power
of a negative argument. Units are `k: N/m^p`, `c: N s/m^(p+1)` and `U: J`.
Maintain geometric compression and the force branch as separate diagnostics.
At positive compression, clamping force to zero does **not** erase `U`.

| Branch | Force | Physical contact loss rate `Ddot` |
|---|---|---|
| Separated, `delta <= 0` | `0` | `0` |
| Compressed, `k + c delta_dot > 0` | `(k + c delta_dot) delta^p` | `c delta^p delta_dot^2` |
| Compressed, `k + c delta_dot <= 0` | `0` | `-k delta^p delta_dot` |

The clipped branch is possible only when `c > 0` and
`delta_dot <= -k/c < 0`; therefore its loss is nonnegative. At the branch
boundary the two loss formulas agree. The compact identity is
`Ddot = (F - A) delta_dot`, evaluated using the branch expressions above to
avoid cancellation. No separate clipped branch occurs for `c = 0`.

For

\[
E={1\over2}v^TMv+{1\over2}z^TKz-f_0^Tz+U,
\]

direct differentiation gives

\[
\boxed{\dot E+v^TCv+\dot D=f^Tv-F\dot g.}
\]

Thus the prescribed-face actuator supplies **`Pact = -F gdot`** to the modeled
system. Engagement can add energy; withdrawal can remove it. For a fixed face
and no excitation, total stored-plus-constant-load-potential energy cannot
increase. Tine energy alone can grow while compressed-contact energy falls.
Never replace signed actuator work by its absolute value or clamp it positive.

## 3. Finite preload and assembled resting equilibrium

At a fixed resting gap `gbar`, solve the equilibrium before the first strike.
For a single damper, arbitrary `b` reduces the static solve to one scalar:

\[
z_{free}=K^{-1}f_0,\quad
\alpha=b^TK^{-1}b\ge0,\quad d=b^Tz_{free}-\bar g.
\]

If `d <= 0`, use `zbar = zfree`, `Fbar = 0`, and signed compression `d`.
For `d > 0`, find the unique positive solution

\[
\bar\delta+\alpha k\bar\delta^p=d,\quad
\bar F=k\bar\delta^p,\quad
\bar z=z_{free}-K^{-1}b\bar F.
\]

The scalar left side is strictly increasing. For the first supported synthetic
case, **choose `p = 1`**, yielding `delta_bar = d/(1 + alpha k)` exactly.
Alternatively, choose a clearly synthetic finite preload `Fbar > 0`, then set
`gbar = b^T zfree - alpha Fbar - (Fbar/k)^(1/p)`. This is an explicit fixture
construction, not a measured preload estimate. Stiffness must include the
declared support constraints; a singular free-body `K` needs a separate
constrained equilibrium treatment.

Expose modal displacement from the assembled point as `q = z - zbar`:

\[
\delta=\bar\delta+b^Tq-(g-\bar g),\qquad
M\ddot q+C\dot q+Kq=f(t)-b(F-\bar F).
\]

For a preloaded equilibrium, use the corresponding energy relative to its
initial value:

\[
\mathcal E={1\over2}\dot q^TM\dot q+{1\over2}q^TKq
+U(\delta)-U(\bar\delta)-\bar F b^Tq.
\]

The **linear preload term must remain**. Omitting it while using the shifted
equations gives incorrect energy accounting. At fixed `g = gbar`, convexity of
`U` makes this relative energy nonnegative and zero at rest. With moving `g`,
its reference offset may make it negative; the signed energy difference and
work identity still hold. Record resting compression, force, modal offset,
configuration, and static force residual. Do not re-solve or zero the moving
resonator on note release, pedal motion, or retrigger.

## 4. Continuous pedal/key motion and coordinate invariance

A minimal prescribed linkage is
`g(t) = gbar + Lp s(t) + Lk a(t)`, where `s,a` are continuous dimensionless
pedal/key-lift coordinates and the signed lengths are explicit synthetic
geometry. More generally, use `g = G(s,a)` and
`gdot = G_s sdot + G_a adot`. The two signed actuator efforts are
`Q_s = -F G_s` and `Q_a = -F G_a`; their powers add to `-F gdot`.
For dimensionless coordinates these efforts have units of joules.

Prescribe position and velocity consistently from the same trajectory. Smooth
cubic ramps with zero endpoint velocities are a simple first choice. A digital
note or pedal event changes a trajectory target while preserving its current
position and velocity. Finite travel then naturally permits partial contact,
separation, and recontact. Continuous position with piecewise finite velocity
keeps modal position/velocity continuous. Reject instantaneous gap jumps in
the initial supported domain; such jumps would require explicit storage/work
event accounting. This ideal prescribed linkage omits linkage inertia,
hysteresis, and felt memory and makes no measured half-pedal claim.

Under a nonsingular diagonal rescaling `q' = S q`, transform
`b' = S^-T b`, `M' = S^-T M S^-1`, and likewise `K,C`; transform generalized
forces by `S^-T`. Gap, compression, normal force, stored energy, dissipation,
and actuator work remain unchanged. Include `S = diag(2,-3)` to exercise sign
as well as magnitude. Pickup observations must transform by the same rule if
voltage is included. Several damper contacts extend by summing their projected
forces, storage, losses, and work; their equilibrium is then a coupled convex
static problem rather than the single scalar solve above.

## 5. Minimal implementation and decisive tests

Reuse the hammer reference solver and its accepted-step ledger. Add a pure
damper evaluator taking `(q,v,g,gdot)` and returning compression/rate, force,
elastic storage, branch loss, and actuator power. A prescribed memoryless
compliance needs no arbitrary contact-reset state. Keep branch/event labels
for diagnostics. Initially support finite `p = 1`, fixed `b,k,c,M,K,C`, and a
bounded smooth gap trajectory. Validate parameters and overflow limits before
integration; reject invalid initialization. This avoids assuming a finite
Newton derivative for `0 < p < 1`.

| Proposed fixture | Independent result or gate |
|---|---|
| Resting finite preload | Scalar equilibrium above; zero velocity and force residual; no startup pulse. Test positive and negative small perturbations. |
| Fixed gap, no forcing | `Delta E + integral(v^T C v + Ddot) = 0` within the frozen numerical budget, including separation and clipped release. |
| Always-compressed `p=1,c=0` | Exact linear dynamics use `K + k b b^T`. One mode has `omega^2 = (K + k b^2)/m`; choose perturbation small enough to remain compressed. |
| Fully separated | Exactly zero contact force; agreement with the existing analytic free-mode solution, expressed with the correct equilibrium offset. |
| Moving gap with fixed resonator | Constraint does zero work because velocity is zero. For `c=0`, `Delta U = -integral F dg`; a closed trajectory returns the energy. |
| Fast withdrawal in positive compression | `F=0`, actuator power is zero, and stored contact energy falls at `Ddot=-A delta_dot`; this detects the common wrong clipped-loss formula. |
| Partial travel and opposite-phase retrigger | Preserve all modal state; log contact/clamp roots independently; include hammer launch work and both linkage ports in one ledger. |
| Signed rescaling `(2,-3)` | Identical local motion, force, energy, loss, work, and any correctly transformed pickup output. |
| Grazing and two roots inside one step | Interior root checks/subdivision; a tangent contact must not be inferred solely from endpoint sign changes. |

At each accepted interval record
`r_n = E_(n+1)-E_n + D_background,n + D_contact,n - W_act,n - W_other,n`.
Report both maximum absolute cumulative residual and sum of absolute interval
residuals. Integrate power using the actual accepted trajectory; endpoint work
alone is insufficient. Roll back the complete state, trajectory state, and
ledger on a rejected step.

Before acceptance tests are implemented, the integrator must freeze the
synthetic matrices, projections, contact constants, preload, travel
trajectories, finite operating bounds, absolute/relative observable budgets,
and positive reference scales. Choose these as documented numerical fixtures,
without treating existing surrogate decay coefficients as felt measurements.
Use separate step, nonlinear-solve, and event refinements, plus an independent
integration method, exactly as required by REFERENCE_SOLVERS. A low residual
does not establish accurate event times, impulse, rebound, or waveform.
