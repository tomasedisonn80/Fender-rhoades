## Interpretation and handoff

These are offline `EventProcessor::process` observations, including preflight
and event application. Preparation, scheduling/hashing, initial conditions,
warmup, inspection and serialization are excluded. MIDI ownership, state
mailboxes, VST3 calls, devices and wake-up jitter are unmeasured. Outlier causes
were not identified. Maxima are not worst-case bounds; zero misses in some rows
is not a real-time guarantee. The pedal storm is a concrete unresolved cost case.
Source inspection shows 56,064 modal transition updates per 256-pedal callback;
profile or optimize that path while preserving state, then compare controlled
runs. Numerical error, aliasing and full RT-001 acceptance remain open.
