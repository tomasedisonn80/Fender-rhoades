# A069 — Independent VST3 benchmark audit

Added `tests/cpp/vst3_benchmark_json.cmake` for callback/event/parameter/retrigger/
ownership/frame counts, formats/workloads, silent/ringing output, warmup-reset
fingerprints and JSON escaping. Quantiles and nominal overruns are independently
recomputed from raw observations, without timing thresholds.

```sh
cmake -DBENCHMARK="$PWD/build/vst3/rhodes_vst3_benchmark" \
  -P tests/cpp/vst3_benchmark_json.cmake
```

The test passed **22 JSON cases, 23 invalid-input cases and help**, including
1/8192-frame boundaries and repeated strikes. Three scratch wrappers corrupted
the median, frame cursor or warmup fingerprint; each was rejected.
No benchmark implementation defect was observed.
