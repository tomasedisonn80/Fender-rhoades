## Implemented and observed

Added `tests/cpp/vst3_automation_contract_test.cpp`. Its independent oracle uses
`std::map` to retain the last anchor at each offset, native binary32 quantization
under nearest rounding, long-double barycentric interpolation, and a plain
`ResearchEngine` with a separate identified-note ownership map. It does not call
the processor's interpolation or production control-conversion helpers.

Shared exact mechanical/snapshot checks are additional. Both float32/float64
run at 32/48/192 kHz. Three deterministic seeds produce 32-block trajectories
with varied lengths and duplicate anchors. Other cases cover parameter-queue
permutations, same-sample note order, zero-frame/empty queues, boundary anchors,
and 192 rejected late reads/values/orderings, with and without pending recall.
Rejected calls preserve configuration, ownership, mechanics and subsequent
valid playback. Caller-storage sentinels remain intact.

Audio comparison allows `4*epsilon32` or `64*epsilon64` times
`max(1e-8,abs(expected))`; mechanical states compare exactly. A copied processor
deliberately retaining the first duplicate anchor instead of the last fails
`automation_model` with exit 1. No production defect was observed.
