# W3-A053 — Control values independent of host flush settings

2026-11-23. Bounded HOST-001 repair of A051's reproduced control-path defects.
Preflight project validation, generated-state consistency and work-selection
checks passed. Changed only the seven source/test files listed below and this
report; no CMake, canonical-state or Git writes.

## Implementation

Added `rhodes::control` constexpr helpers: `valid_normalized(float/double)`,
`is_zero(float/double)`, `is_boolean(double)`, `quantize(double)` and `widen(float)`.
Domains and conversions use integer IEEE-754 representations. Quantization is
binary64-to-binary32 round-to-nearest, ties-to-even, including subnormals and
normal-boundary carries; widening is exact. Invalid inputs return no value,
and actual signed zeros canonicalize to positive zero. Storage is fixed;
production helpers do not allocate or modify the floating-point environment.

Core notes, event payloads and note ownership now distinguish actual zero from
positive subnormals and reject negative subnormals. The VST adapter validates
SDK binary32 velocities before widening. Controller edits/recall/save,
automation collection and live gain publication use the same conversions.
Existing transition caches, controller lifecycle guards, state format and DSP
arithmetic remain intact.

## Actual verification

Linux x86_64, GCC 14.2, strict Release:

```sh
c++ -std=c++20 -O2 -DNDEBUG -Wall -Wextra -Wpedantic -Wconversion -Wshadow -Werror -Iinclude tests/cpp/control_value_test.cpp -o build/a053/control_value_tests
build/a053/control_value_tests all
```

All four retained selectors passed: `domains` (229,546 checks), `quantize`
(319,589), `widen` (200,253), and `rounding_modes` (3,705,600). Native casts under
explicit nearest/gradual-underflow defaults supply independent conversion
oracles. Coverage includes every normalized binary64 exponent, adjacent-float
midpoints and their neighbors, subnormal normalization boundaries, malformed
values, and all 16 supported rounding/FTZ/DAZ combinations. Helpers preserved
control/status bits and raised no FP exceptions in environment probes.

Rebuilt A051's original audit against repaired sources: **0/29 mismatches** in
each of gradual, FTZ, DAZ and combined modes. Strict direct builds and all **56
existing core/event/note/state/cache selectors** plus **12 VST host selectors**
passed, including allocation-guarded processing. A055 independently confirmed
the repaired core and real VST float/double paths in all four flush modes.
