# W3-A060 — Release state-protocol fixture diagnosis

## Scope and finding

Inspected the four `state_fp.*` failures from the integrated GCC 14.2 Linux
x86-64 Release build. The first rejected pedal packet encoded gain `0.5` and
pedal `+0`; both fields are valid. The failure reproduces without MXCSR changes,
mailbox operations, or preceding gain probes.

An 11-line reproducer in `build/a060/minimal.cpp` passes at `-O0`, `-O1`, and `-O2`,
but fails at `-O3`. Generated assembly omits initialization of the unnamed packet
passed to the noninlined decoder wrapper. Diagnostic `-O3 -fno-ipa-modref` passes;
disabling tree DSE, lifetime DSE, tree SRA, or strict aliasing separately does not.
This establishes a compiler/code-shape dependency, not a specific upstream GCC
bug identity. No production codec defect was established.

## Repair

Changed only `tests/cpp/state_fp_environment_test.cpp`: retain the pedal packet
in a named `const` object, matching the existing gain probe, and assert that
decoding preserves its bytes. Keep the noninlined boundaries, runtime inputs,
integer acceptance oracle, all domains, and actual FP-control changes. Production
code and build/optimization flags are unchanged.

## Actual verification

Direct builds use `c++`, `-DNDEBUG -std=c++20 -Wall -Wextra -Wpedantic
-Wconversion -Wshadow -Werror -Iinclude`, with each of `-O0`, `-O2`, and `-O3`.
All twelve baseline/FTZ/DAZ/combined runs exit **0**, each executing **9,531**
always-active checks, with zero FP status flags and exact MXCSR restoration.
The same repaired fixture against the pre-A050 codec still fails: baseline on
FP status flags and DAZ on lost gain bits. Thus the original regression remains
detectable. Commands, exits, binary hashes, variants, and assembly are retained
in `build/a060`; no alternate compiler or platform was available for validation.

Project preflights, documentation integrity, and owned-file whitespace checks
pass. No CMake, canonical-state, or Git changes. Root should rebuild the integrated
Release target and rerun the failed selectors before publication.

## Retained minimal reproducer

Compile with `c++ -O3 -std=c++20 -Iinclude repro.cpp -o repro`; exit **1**
reproduces rejection of a valid packet. Substitute `-O2`: exit **0**.

```cpp
#include "rhodes/instrument_state.hpp"
#include <array>
#include <cstdint>
using Bytes=std::array<std::uint8_t,16>;
Bytes packet(std::uint32_t gain,std::uint32_t pedal) {
 Bytes b{'R','H','S','T',1,0,1,0};
 for(std::size_t i=0;i<4;++i){b[8+i]=static_cast<std::uint8_t>(gain%256U); b[12+i]=static_cast<std::uint8_t>(pedal%256U); gain/=256U;pedal/=256U;}
 return b;
}
__attribute__((noinline)) auto decode(const Bytes& b){return rhodes::decode_instrument_state(b);}
int main(){volatile std::uint32_t bits=0; return decode(packet(0x3f000000U,bits)).has_value()?0:1;}
```
