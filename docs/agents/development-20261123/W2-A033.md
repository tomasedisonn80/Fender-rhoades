## Delivered

The Python 3.11 standard-library runner imports only frozen fixture/axis metadata
from the independent auditor. It does not call an oracle. Four maximum steps,
three event tolerances and three local-tolerance scales produce eight distinct
configurations per fixture, with shared configurations labeled for every
applicable axis: **208 planned runs across 26 fixtures**. Repeatable `--fixture`
selection, `--plan`, executable/output paths and per-process timeout are exposed.

Execution is serial. Raw stdout/stderr survive nonzero exits, malformed JSON and
timeouts. Generation checks validate the schema, requested settings, successful
completion, finite sample fields and complete frozen duration. Incremental
manifests retain commands, outcomes, executable hashes before/after, frozen-input
metadata hash, source hashes and raw-output hashes. The combined candidate file
is written only after every requested run succeeds; its independent audit
command is recorded but never automatically executed.

Existing directories require explicit `--force`. Force overwrites only named
outputs, preserves unrelated files and invalidates an old managed aggregate
before beginning. Managed symlinks/nonregular files are refused. No directory is
recursively deleted.
