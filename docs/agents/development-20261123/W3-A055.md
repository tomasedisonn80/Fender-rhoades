# W3-A055 — Independent core and VST flush-mode regressions

2026-11-23. Bounded HOST-001 verification of A053's control-value repair.
Owned changes are `tests/cpp/control_fp_environment_test.cpp`,
`tests/cpp/vst3_fp_environment_test.cpp`, and this report. Implementation, CMake,
canonical project state and Git were not modified.

## Retained behavior

Actual ResearchEngine, EventProcessor and NoteTracker calls check negative
subnormal rejection, preserved mechanics and future damping, positive tiny
holder retention, and late malformed note-off, sustain, all-off and reset
payload rejection before any earlier event executes. Exact signed-zero releases
remain accepted. Rejected blocks must silence every sample and preserve cursors.

The SDK host fixture exercises both float and double audio, note-on/off velocity
validation, automation rejection, controller set/get and state round trips,
zero-frame flushes, and recall followed by an empty-input audio block. Tiny gain
expectations are independent fixed IEEE-754 words: binary64 input
`37a16c262777579c`, binary32 `000116c2`, exact widened binary64
`37a16c2000000000`. State packets are assembled and checked directly; no new
production conversion helper supplies an oracle.

## Actual verification

Linux x86_64, GCC 14.2; all four independent source builds used C++20, `-O2
-DNDEBUG -Wall -Wextra -Wpedantic -Wconversion -Wshadow -Werror`. Complete
commands, exits and log paths are in `build/a055/commands.json`.

Against A051's frozen pre-repair snapshot, both baselines passed. Core DAZ/both
failed all four behavioral groups; host FTZ failed five groups and DAZ/both
failed all eleven. Against the consistent eighteen-file A053-ready snapshot,
all eight individual executions passed: **20,812 explicit core checks** and
**513 explicit host checks** per mode, plus host mechanical snapshot checks.
Every mode restored the original MXCSR exactly; requested control writes were
checked. The snapshot still matched working sources after execution.

Documentation integrity and assigned-file whitespace checks passed.
