Queue counts precede reads; sorted offsets and duplicate replacement bound
staging. Dispatch merge and render cursors only advance, so their inner loops
cannot restart earlier work. All scratch and candidate ownership use fixed
arrays/value copies. Preparation warms both loss regimes; the audio owner's
note, pedal and reset operations select those coefficients without recalculating
transcendentals. No plugin-owned callback heap allocation, locking, logging or
I/O was found in the reviewed path. Construction and stream callbacks are
separate boundaries.

One audio owner is required. Lifecycle changes synchronize with it; UI state
callbacks use the atomic mailbox and independently owned streams. Begin,
publication and abort each attempt at most one CAS, with no retry loop; a
process invocation takes either publication or abort. A049/A081 provide
separate executed threading evidence; this review did not repeat TSAN.

## Rejection boundary and criterion interpretation

`silence_outputs` traverses the host-declared output buses, channels and samples,
including oversized rejected buffers. Its work is proportional to those declared
dimensions, **not capped by the accepted 1×2×8192 domain**. Storage must actually
be accessible as declared. The [frozen host contract](../../specs/HOST_PROTOTYPE_20261123.md)
explicitly excludes a uniform bound for arbitrary malformed caller storage.
Thus this supports HOST-001/C02's bounded accepted audio processing within that
declared contract; it does not prove a uniform full-callback bound over arbitrary
raw SDK input. Foreign parameter/event getters may also allocate or block.
