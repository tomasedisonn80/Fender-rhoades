# W1-A019 — Fixed-storage MIDI note ownership

Date: 2026-11-23. Scope: HOST-001 ownership helper implementing W1-A010;
no host, SDK, audio-processing, sustain, or measured-fidelity claim.

## Changes

- `include/rhodes/note_tracker.hpp`: header-only `NoteTracker` with 256 fixed
  holders and 73 per-key counts. `MidiNote` carries on/channel/pitch/note ID/
  velocity. `apply()` returns `NoteResult`: `NoteStatus` (`ok`, `invalid_input`,
  `capacity_exceeded`) and optional `NoteChange` (`EventType`, key, value).
  Successful positive ons always strike; identified duplicates do not add
  holders. Exactly ID -1 is anonymous. Identified conflicts reject atomically;
  release occurs only when the final holder leaves. Valid nonkeyboard pitches
  are ignored after general validation. Zero-velocity ons release.
- `reset()`, `held_count()`, `active_count()`, and `release_channel()` support
  adapter integration. Channel release returns `NoteReleaseResult` with status,
  fixed `keys[73]`, and count; keys are unique and ascending. Invalid channels
  leave ownership unchanged. Reset clears ownership only. Out-of-range key
  queries return zero. Value copying supports transactional block preflight.
- `tests/cpp/note_tracker_test.cpp`: six always-on fixtures, including Release
  builds. Coverage includes keyboard/channel boundaries, invalid velocities,
  outside-range pitches, exact and negative IDs, anonymous/identified isolation,
  cross-channel overlap, unmatched offs, zero velocity, identity conflict,
  256/257-holder boundaries, duplicate-at-capacity, release/reuse, channel release
  of all 73 keys, reset, and copy independence.
