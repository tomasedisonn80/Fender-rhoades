# A082 — Preserve historical runtime observations

**Result: the A038/A041 raw-data preservation gap is closed.** The new
[self-contained archive](../../validation/runtime-historical-raw-20261123.json)
retains all sixteen original timing JSON files byte-for-byte: twelve A038 runs
with 1,000 samples each and four A041 runs with 500 samples each. No benchmark,
renderer, compiler or trajectory harness was rerun. Project validation,
generated-state and work-selection preflights passed.

## Preservation and verification

The 402,059-byte archive contains **25 exact UTF-8 payloads**: sixteen raw files,
the two immutable historical manifests, two immutable reports, both original
timing wrappers, the trajectory harness and its old/new recorded outputs. Each
entry retains its original path, role, byte count and SHA-256. Paths describe
provenance; verification neither executes those wrappers nor overwrites their
original locations. The archive embeds a standard-library-only verifier and its
SHA-256, source bindings, limitations and reconstruction instructions.

Actual commands were `python3 -S build/a082/preserve.py` and
`python3 -S build/a082/verify.py
docs/validation/runtime-historical-raw-20261123.json`. The latter passed **1,368
checks**, independently recomputing all 16 full-run and 64 quarter-window
summaries from **14,000 durations**. Counts, nearest-rank p50/p95/p99, maxima,
nominal block periods and misses match exactly. Mean comparisons use
`math.fsum` with relative tolerance `1e-12` and absolute tolerance `1e-10 µs`
because the original C++ accumulates serially. These are arithmetic-audit
tolerances, not new runtime acceptance budgets.

Seven historical source-file hashes match their Git objects: four baseline
inputs at `0ba50d836532113c2ff53c044e38a53734007444`, and three cache-change
inputs at `a92ea359124e5d7abe6c3105033bf7dbd3fa8d1c`. Both preserved report
hashes match their completed campaign entries. Separate reconstruction checks
confirmed all 25 UTF-8 payloads recover their original bytes and replayed results
equal the archive's recorded audit. Extracting only the archive and embedded
verifier into `build/a082/isolated`, then running `python3 -S verify.py
historical.json`, also passed; original scratch inputs are unnecessary for replay.

## Scope and handoff

The A041 pairs retain identical workload descriptions, schedule hashes,
sum-of-squares checksums, peaks and integrity/status fields. All four recorded
combined output/final-state digests match between old and new harness outputs
and the published report. This checks preserved observations; DSP traces and
their digests were not newly recomputed.

These timings cover `EventProcessor::process`, including preflight, event
dispatch and rendering. They exclude MIDI ownership, state mailboxes, VST3,
DAWs and audio devices. A069's actual adapter callback measurements use a
different boundary. Original unrecorded fields and uncontrolled scheduling/power
conditions remain explicit. No worst-case guarantee, independent domain-wide
error bound, antialiasing acceptance or physical fidelity follows from this
preservation work.
