## Corrections

The ordinary RK4 controller now also constrains the step-doubling defect in each
enabled physical contact gap. Its local absolute scale is `0.002` times the
configured event-gap resolution, in addition to the existing mass-weighted
mechanical and integrated-quantity tolerances. Root localization cannot correct
accumulated integration phase error; this additional accuracy control resolves
the previously excessive positive gap at the analytic separation/action time.
Accepted mechanics still use two RK4 half-steps. No position is projected, no
root bracket is invented, and neither the frozen budgets nor configured root
resolution is widened. This local estimate does not certify global error over
all possible trajectories; independent refinement remains necessary.

A separate analytic path now handles a documented force-free domain: an
undamped modal system, disabled damper, stationary hammer, and at most one
nonzero oscillating mode in the hammer projection. Projected zero-frequency
modes must be stationary. The constant offset plus projected harmonic amplitude
must be nonpositive in `long double`; a positive envelope is never rounded down
to establish separation. Coordinates are evaluated from a retained initial
anchor using the exact harmonic formulas, avoiding numerical amplitude drift.
The force, background loss, and impulse remain identically zero; an observation
that contradicts the certificate returns typed failure instead of suppressing
its force. External actions recompute or disable the certificate.

Within this domain, a nonpositive envelope whose amplitude and clearance agree
at public double precision is classified as a grazing maximum. The derivative
root has a real replayed bracket, and its actual sampled gap uncertainty must
still meet the existing limit. Misses and positive short contacts remain
separate. Unsupported or unresolved tangencies retain explicit failure. The
anchor/certificate participate in the existing whole-call copy/rollback.
`WorkCounters::analytic_free_evaluations` exposes use of this path; comments now
distinguish analytic evaluations from numerical RK4 substeps.
