# A074 — Independent VST3 note ownership model

The retained fixture uses a `std::map` of channel/identified-note owners and a
`std::multiset` of anonymous channel/pitch owners. These derive physical actions
for a separate `ResearchEngine`; production `NoteTracker` only supplies observed
counts. Audio, modal state, energy, configuration, ownership and cursor compare exactly;
rejection also checks future trajectories for damping changes.
