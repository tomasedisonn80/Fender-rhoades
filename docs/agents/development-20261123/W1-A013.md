## Measurement boundary

Preserve schema-v1 `ResearchEngine::process` results as `process_only`.
Add `full_events`: timestamp immediately around
`EventProcessor::process(output, events)`, including prevalidation, event dispatch,
control updates, and sample processing. Preallocate output, event arrays, and timing
storage; generate schedules, consume output, validate results, sort, and serialize
outside timestamps. The adapter currently invokes the engine once per sample;
therefore its extra duration cannot be attributed solely to event handling.

## Minimal deterministic workloads

| ID | Schedule |
|---|---|
| silence | Zero events, reset initial state; retain all 73 slots/branches. |
| chord73 | Keys 0–72, intensity 0.7, simultaneous strikes approximately every 0.5 seconds, preserving state. |
| retrigger256 | Exactly 256 events/block: 128 off/on pairs cycling all 73 keys; same-offset and distributed-offset variants. |
| pedal256 | Exactly 256 alternating sustain events/block, starting with a released 73-key chord; same-offset and distributed variants. |
| tails | One 73-key strike; separate held, sustained-release, and pedal-up release trajectories; 120 simulated seconds without further events, resets, or retriggers. |

For storm event index `i`, use offset zero or `floor(i*N/256)` and sequence `i`.
Report late-tail windows separately; extend the current block-count cap where
necessary. Record actual subnormal-state observations; duration alone proves none.
Exercise 4096-frame and 256-event boundaries separately; rejection correctness
belongs in tests.

Start at 48 kHz with 64/128/512 frames, plus 96/192 kHz at 128 frames.
Use 32 warmup blocks, reset once before each measured trajectory, at least
10,000 ordinary blocks, and three independent runs with alternating comparison
order. Compare identical initial states and schedules. Sub-block process-only
replays require segmented calls and explicit timer-count disclosure; retain their
own label. Never subtract independently computed quantiles as “event cost.”

Deadline is `1e6*N/sample_rate`; misses mean strictly greater. Preserve raw timings.
Run allocation traps separately across full calls, including controls, maximum-event,
rejection, reset, and fault paths. Cover scalar/array/aligned/nothrow C++ allocation
and document C-allocator interception gaps; exclude setup/reporting. Traps neither
prove lock freedom nor justify host/device guarantees. RT-001 numerical and
antialiasing gates remain outstanding.
