## Scope and observed gaps

Independently exercised A061's auditor through direct APIs and **21 actual CLI
runs**, using hand-derived conservative endpoints and one retained `event_at`
candidate. Both valid baselines remain incomplete with zero failures. No solver,
budget, production code, state, CMake or Git changes were made.

Three remaining input-integrity gaps were reproduced:

1. **Legacy normalization:** `q0_m` or `v0_m_per_s = 10**400` raises uncaught
   `OverflowError`; the CLI exits 1 with a traceback and no JSON. Canonical
   vector components reject the same integer correctly. Legacy `False` silently
   becomes `0.0`, yielding zero failures, while canonical `False` rejects.
2. **Failure consistency:** a run with `failure_code=5` and `success=true` or
   omitted `success` yields zero failures. A relaunch snapshot with
   `success=false` or `failure_code=5` is likewise not flagged.
3. **Action evidence:** replacing a valid `event_at` snapshot list with `[]` or
   duplicating it yields zero failures, with only extrema marked missing.
   Negative snapshot time, incorrect requested/final hammer velocity, and forged
   snapshot work also go unchecked. Presence alone does not establish action
   coverage or consistency with the declared relaunch.

None achieved overall acceptance: the independent-extrema gate remains incomplete.
The original refinement failures and physical acceptance limits are unchanged.
