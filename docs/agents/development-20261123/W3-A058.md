# A058 — Linux VST3 bundle inspection

Scope: read-only inspection of the existing Linux bundle, copied into
`build/a058/RhodesResearch.vst3` before subsequent builds. This binary predates
A053 control repairs; packaging observations do not validate those repairs,
other operating systems, commercial DAWs, or release readiness.

## Observations

- `file`, `readelf -h/-d/-V`, `nm -D --defined-only`, and `ldd` succeeded.
  The stripped 327112-byte ELF64 x86-64 module exports `GetPluginFactory`,
  `ModuleEntry`, and `ModuleExit`; all four direct dependencies resolve locally:
  `libstdc++.so.6`, `libm.so.6`, `libgcc_s.so.1`, and `libc.so.6`.
- SDK `moduleinfotool -create -version 0.1.0 -path <snapshot> -output <file>`
  and `-validate -path <snapshot>` both exited zero. Regenerated metadata is
  byte-identical to bundled metadata. Both class UIDs, names, categories,
  version `0.1.0`, SDK version `3.8.1`, and instrument subcategories match
  [IDs](../../../plugins/vst3/plugin_ids.hpp) and
  [factory](../../../plugins/vst3/factory.cpp).
- All five SDK checkouts match the [documented pins](../../DEPENDENCIES.md),
  with tracked contents clean. Bundled license bytes equal all five source
  licenses; the notice index equals its project source.

## Actionable packaging limits

The module requires `GLIBC_2.38` (`__isoc23_sscanf`) and `GLIBCXX_3.4.29`.
Select and test an explicit Linux runtime baseline before distribution.

There are **137 defined dynamic exports**, including **120 Rhodes-named
symbols**. Parent core/module compile flags omit hidden visibility; the SDK
sets visibility defaults within its subdirectory. Explicit target visibility
properties should reduce accidental exported interfaces, followed by symbol,
factory, and validator checks. No observed loading failure is claimed.
