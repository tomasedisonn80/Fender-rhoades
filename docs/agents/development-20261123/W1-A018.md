## Proposed default limits

Every scalar must be finite; endpoints below are inclusive unless stated otherwise.

| Quantity | Allowed range |
|---|---|
| Modal/hammer mass | `[1e-6,1] kg` |
| Contact exponent | Exactly `1` |

| Modal frequency / decay beta | `[0,20000] Hz` / `[0,1e5] s^-1` |

| Modal/hammer/face position, clearance | `[-1,1] m` |
| Modal/hammer/face velocity, relaunch velocity | `[-1000,1000] m/s` |

Zero frequency and decay permit free masses; zero/negative projections permit decoupling and coordinate reversal. These limits include A005's rescaling. Validate `t+dt<=1000` and representable progress before mutation. Support constant, linear and sinusoidal faces with matched analytical velocity and certified whole-interval position/velocity bounds; reject unsupported trajectories.

Per call: 100000 total trials, 1200000 RHS evaluations including replay, 64 consecutive rejections, 64 bisections per root, subdivision depth 32, 100000 event rows. Check every trial stage against state bounds before products; validate derived forces, energies, powers, errors and accumulators before publication. Use maximum scaled error, avoiding overflow-prone squared norms. Bounds control arithmetic size, not accuracy or convergence.

## Failure and transaction contract

- `invalid_input`: nonfinite/out-of-range public input, unsupported trajectory/exponent, invalid settings or nonprogressing requested time.
- `budget_exhausted`: any declared resource cap reached before completion.
- `numerical_failure`: valid inputs produce nonfinite arithmetic, unresolved event classification, or accuracy/domain failure at minimum step. Oversized trial states may first reject and halve within budget.

Stage the entire call. Failure restores mechanics, time, all ledger channels, compensation, adaptive-controller history, event classifications/cursors/brackets/counters, and staged outputs. Return attempted-work diagnostics separately; persistent diagnostics remain unchanged. Success requires the complete requested interval.
