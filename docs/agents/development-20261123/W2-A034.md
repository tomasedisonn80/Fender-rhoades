## Delivered checks

The CMake script runs ten short cases covering all seven workloads, simultaneous
and distributed event storms, a 101-observation silence case, and a one-observation
case with empty quarter windows. It checks typed JSON fields, complete/status
counts, timing length, machine-label quote/backslash/space round trips, excluded
warmup/initialization accounting, exact event totals and silence output.

It independently validates each reported nearest-rank quantile by counting raw
observations below/at the reported value. Maximum and nominal-deadline misses
are recomputed for the whole run and all four chronological windows. Means must
lie within observed extrema and equal the observation for singleton windows.
No floating-point duration is truncated into CMake's integer arithmetic.

Seventeen malformed CLI cases must exit 2, produce no stdout, and emit the
expected diagnostic prefix. These include count/rate/key limits, missing or
malformed values, unsupported policies, and a control character in the label.
