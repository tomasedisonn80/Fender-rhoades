# A072 — Public headers and optional dependency boundary

## Observed checks

Linux x86-64, GCC 14.2.0, CMake 4.4.5. `g++` and `c++` resolve to the
same compiler; no `clang++` was available on PATH.

All six public headers compiled independently, plus four aggregate include orders
(sorted, reversed, and rotations by two/four): **10/10 passed**. The aggregate
correctly rejected C++17. Exact syntax-check flags were:

```sh
g++ -std=c++20 -O3 -DNDEBUG -Wall -Wextra -Wpedantic -Wconversion -Wshadow -Werror -Ibuild/a072/snapshot/include -fsyntax-only INPUT.cpp
```

Four minimal consumers compiled and ran: core/event/note operations linked against
`librhodes_core.a`; contact initialization/advance against `librhodes_contact.a`;
state codec/mailbox and control conversion required neither archive. Runtime
checks observed eight-bit bytes, four/eight-byte float/double, and always-lock-free
64-bit atomics.

A frozen snapshot configured and built all four ordinary executables with:

```sh
cmake -S build/a072/snapshot -B build/a072/default -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=OFF -DRHODES_BUILD_VST3=OFF -DRHODES_VST3_SDK_ROOT=/nonexistent/a072-sdk -DCMAKE_EXPORT_COMPILE_COMMANDS=ON
cmake --build build/a072/default --parallel 2
cmake -U RHODES_BUILD_VST3 -S build/a072/snapshot -B build/a072/default
```

Removing the explicit option regenerated its default as `OFF`. Six compile units
contained no SDK source/include paths; no VST3 targets or SDK build directory
appeared. All four `--help` calls passed. `readelf -d` listed only `libstdc++`,
`libm`, `libgcc_s`, and `libc`. The new host benchmark remains inside the optional
SDK include.

## Inspected assumptions and limits

Public targets propagate C++20. Integer control conversion asserts IEEE binary32/
binary64; state storage requires lock-free 64-bit atomics and encodes explicit
little-endian bytes. This does not establish a stable cross-compiler C++ ABI.
Non-x86 source branches retain baseline FP checks and return 77 for unavailable
flush modes; CTest marks these skipped. These branches, Windows, macOS, other
compilers, and non-x86 hardware were **not executed**. No portability defect was
observed in the tested scope.

All eighteen snapshot inputs remained unchanged. Commands, diagnostics, consumers,
and binary hashes are in `build/a072`. No production, CMake, Git or state edits.
Next: run the declared native CI platform matrix. Ownership released.
