## Changes

Optional configuration now verifies the root SDK commit and all four documented
submodule revisions. Each component must have its own Git checkout marker, so an
uninitialized submodule cannot accidentally resolve the enclosing repository.
Failure names the component and expected/observed revision.

Tracked working contents are compared against the pinned commit, including
staged edits affecting those contents. Modified or unreadable tracked contents
reject configuration. Untracked build output and unused optional submodules
remain allowed. This enforces the inspected dependency identity without changing
or resetting the supplied SDK; experiments can use another checkout. Required
gitlinks are checked separately from tracked-file differences.

The macOS guide now matches CI: Unix Makefiles, deployment target 11.0, and
native architecture. Inspection of the pinned `SMTG_PlatformToolset.cmake` and
`SMTG_CodeSign.cmake` confirmed Xcode-specific fast-math and signing behavior;
the previous interchangeable-Xcode recommendation was removed.
