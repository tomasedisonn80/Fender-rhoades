## Reproduced finding — duplicate controller initialization

**P2, unsupported-lifecycle hardening:** `plugins/vst3/controller.cpp:14–23`
relies on the SDK initialization guard. The pinned
`public.sdk/source/vst/vstcomponentbase.cpp` guards only a nonnull `hostContext`.
Consequently two `initialize(nullptr)` calls both succeed. The second appends
duplicate parameter IDs and replaces the ID lookup with fresh defaults.

A strict, SDK-linked diagnostic created the real controller, initialized it,
set normalized gain to `0.25`, initialized again, then terminated/reinitialized:

```text
first=0 count=2 set=0 gain_before=0.25 second=0 count_after=4 gain_after=0.5
terminate=0 restart=0 restart_count=2
```

Compilation and reproduction assertions passed, exit 0. This is an invalid-call
robustness defect, not evidence of corruption during a conforming host lifecycle.
Add an explicit controller initialization flag, reject duplicate initialization
without mutation, clear the flag on termination, and retain a regression. The
processor already implements the corresponding guard.

## Reviewed boundaries

- `processor.cpp:319–337` completes syntax, ownership and dispatch-capacity
  validation before mechanics or live ownership change. Failed post-consumption
  preflight restores the recall token only if no newer UI recall replaced it.
- The mailbox pending bit prevents an old audio publication from overwriting a
  newer recall, including an identical-valued recall; the single audio owner is
  essential to that argument.
- Array writes follow bounded counts and validated offsets. Active null channels
  reject; inactive null channels are intentionally allowed. Rejection clearing
  trusts host-declared storage dimensions and scales with invalid buffer size,
  as documented; it cannot validate an allocation's hidden extent.
- Rendering pre-silences output and preserves its successful prefix on arithmetic
  failure. Conversion checks and reset latching are present. Concrete processor
  arithmetic faults were not injected in this review.
- Stream reads validate exact remaining size; bounded positive short transfers
  terminate. Invalid chunks do not publish configuration.

No additional concrete defect was found in these reviewed paths. This is a
bounded source audit, not exhaustive concurrency, fuzzing or DAW certification.
The existing host suite and SDK validator were not redundantly rerun.
