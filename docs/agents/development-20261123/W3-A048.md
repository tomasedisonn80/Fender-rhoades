## Reproduced defect and handoff

**P2 — state validation/canonicalization depends on DAZ.** For each of three
positive subnormal gains, encoding, decoding and both mailbox publication paths
replace its bits with zero. Three negative subnormal gains become accepted;
recall/publication overwrite prior valid state with zero. Six positive/negative
subnormal pedal payloads become accepted as `Off`, despite the exact-zero/one
format. For example, gain `0x80000001` and pedal `0x00000001` reject normally but
are accepted with DAZ. Signed zeros, normal values and NaN/Inf cases otherwise
matched this bounded oracle.

Floating comparisons in `valid_instrument_state`, `gain_bits` and decode explain
the observed changes. The portable state contract declares no DAZ exception.
Use integer IEEE-754 bit predicates for gain/pedal domains and signed-zero
canonicalization, then retain these mode regressions. This audit does not test
host automation conversion, arbitrary rounding modes, DAWs or non-x86 behavior.
