# W1-A011 — Portable experimental VST3 state

2026-11-23; design proposal for synthetic ResearchEngine configuration; no
mechanical checkpoint.

## Proposed v1 bytes

Exactly **16 octets**; integers and IEEE-754 binary32 bit patterns are
little-endian. Encode/decode with integer shifts and `bit_cast`, never native
struct layout; require eight-bit bytes and IEC-559 four-byte floats.

| Offset | Bytes | Meaning |
|---|---|---|
| 0 | 4 | ASCII `RHST` (`52 48 53 54`) |
| 4 | 2 | Unsigned version, exactly `1` |
| 6 | 2 | Unsigned model, exactly `1`: synthetic ResearchEngine |
| 8 | 4 | Normalized monitoring gain, finite `[0,1]` |
| 12 | 4 | Normalized sustain, exactly `0` or `1` |

Canonicalize signed zero to +0; quantize live gain to binary32. Reject malformed input.
Freeze gain mapping and parameter IDs with v1; changed semantics require a new
version. No padding, native booleans, timestamps, optional fields, or tails.
Golden gain=0.5/sustain=1:

`52 48 53 54 01 00 01 00 00 00 00 3f 00 00 80 3f`

## Stream and commit contract

Use one decoder for processor `setState` and controller `setComponentState`.
Reject null streams. Require successful `tell`, seek-to-end, and seek-back;
require exactly 16 remaining bytes from the supplied starting position. Reject
unseekable streams explicitly. Read into a local 16-byte array, accepting positive
short transfers through at most 16 reads; reject errors, zero progress, or invalid
counts. Check magic, version, model, finiteness, and domains before publication.
Truncation, trailing bytes, or invalid fields leave configuration, ringing,
ownership, and pending recall untouched. Stream position need not be preserved
on failure. Writes use the same bounded transfer policy; partial writes return
failure, never success. The host owns destination chunk sizing/truncation.

Successful recall resets mechanics, cursor/fault latch, all note holders/IDs, and
automation interpolation history; then installs gain and sustain. No stale release
may affect a newly owned note. Saving never resets playback.

## Thread ownership

State methods execute on the UI thread even during processing. Require lock-free
`atomic<uint64_t>`: bits 0–31 hold gain, bit 32 sustain, bit 33 pending recall;
others zero. UI publishes with release-store; saving acquire-loads once. Recalls
coalesce, latest wins before consumption. At block/flush boundary, audio loads
once and `acq_rel` CAS-clears pending **before** applying recall, then processes host events.
A failed CAS defers recall. Audio CAS-publishes final automation against the
cleared token, or original nonpending token; failure preserves newer recall.
Never publish after failed boundary CAS. Clearing pending first prevents losing
an identical mid-block recall. Only audio mutates mechanics; no streams, locks,
allocation, or retry loops there. Inactive lifecycle synchronization permits
direct installation.

`pluginterfaces/vst/ivsteditcontroller.h`, and `public.sdk/source/vst/utility/memoryibstream.h`:

pending recall save; concurrent automation/recall; identical mid-block recall;
coalescing and failed CAS preservation.
