# A064 — Actual VST3 callback benchmark

Implemented `apps/vst3_benchmark.cpp`, schema 1, calling the real
`RhodesProcessor::process` with fixed host interfaces and stereo buffers. Large
owners and timing storage are allocated before processing. Both binary32 and
binary64 audio are supported.

`held` retains note ownership, `gain` adds one alternating gain point per sample,
and `pedal` releases the struck keys and flips sustain every sample while they
ring. Every workload retriggers selected keys at block zero and approximately
every 0.5 seconds. Defaults: 1000 blocks, 128 frames, 48 kHz, 73 keys, 32 warmup
blocks, `held`, 64-bit. All CLI quantities have finite bounds.

Warmup is followed by lifecycle reset and an untimed zero-frame gain/pedal flush.
The timer encloses only the actual callback, including SDK getters, validation,
ownership, automation, processor output clearing, rendering and mailbox
publication. Scheduling, NaN sentinels, checks, hashes and serialization are
excluded. JSON retains every duration, nearest-rank median/p95/p99, maximum,
nominal deadline misses, status/getter counts, frame cursor, ownership, finite
stereo/silence checks, squared-output checksum and output fingerprint. Unknown hardware,
flags and source metadata remain explicit.
