# A066 — Exhaustive bounded state-stream transfers

## Change and result

Added `tests/cpp/vst3_stream_contract_test.cpp`. Independent raw-byte packets cover
all sixteen legal chunk sizes and every reachable failure-call position. Four
failure kinds exercise the helpers and actual processor/controller callbacks:
error returns, zero progress, negative counts, and overreported counts.

Failed recalls preserve ringing mechanics, ownership, live configuration, and an
already queued recall. A subsequent audio boundary consumes that original reset.
Successful retries retain exact subnormal gain bits. Failed saves preserve
configuration while permitting a correct partial destination prefix; retries
rewind explicitly, and caller prefix/tail guards remain intact. Signed-zero
canonicalization, three nonzero offsets, all remaining lengths 0–32 except 16,
seek/tell failures, all header bytes, and malformed gain/pedal fields are covered.
