# A083 — Reject nonfinite oracle refinement comparisons

## Finding and repair

Independent fault injection found a false-pass mechanism in the final oracle
self-check. Python's built-in `max` can ignore a NaN following a finite value.
The auditor reduced 1,001 sampled Radau differences with that function, so an
interior nonfinite state could disappear from the reported maximum.

With actual NumPy/SciPy solvers, wrapping the coarse `preload_plus` oracle's
`state(t)` to copy its result and replace the last ledger coordinate with NaN
when `0.49 * duration < t < 0.51 * duration` reproduced the problem. Both normal
and optimized original execution reported `pass` and the unchanged finite
maximum, `3.3416086737958484e-14`.

With integrator authorization, the fix first requires every sampled reduced
difference to be finite, then applies the existing maximum and `1e-10` gate.
All equations, sample times, existing tolerances and candidate acceptance gates
remain unchanged. The other self-check reductions use NumPy maxima, which
propagate NaN into comparisons that already reject it.

## Retained and actual verification

Eight new standard-library tests run **48 CLI subprocess probes** across normal,
`-O` and `-OO`. Controlled backend placeholders keep comparison expressions
active while challenging position, velocity, quadrature loss, positive compression,
and refinement. Nonfinite refinement cases cover first, middle and final samples,
including the last ledger coordinate and structured output files. These tests
exercise validation flow, not independent numerical accuracy.

Linux x86-64, Python 3.12.14, NumPy 2.3.5 and SciPy 1.17.0:

| Experiment | Observed result |
|---|---|
| New standard-library suite with `-S` | 8/8 passed |
| Real numerical backends with wrong position, velocity, loss, compliance or refinement | All five rejected with the intended guard |
| Real interior-NaN injection after repair | Rejected under normal, `-O`, and `-OO` |
| Original source with fake middle/final NaN | Six false passes across the three optimization modes |
| Healthy repaired numerical self-check, normal and `-O` | Both passed; output byte-identical to A076 |

Commands:

```sh
python3 -S -m unittest discover -s tests/python -p 'test_contact_matrix_self_check.py' -v
python3 build/a083/verify.py
```

Scratch verification retains the real injection harness, original source, exact
commands, outputs and hashes. The new tests are included by ordinary discovery.
