## Independent reference and scope

The oracle generates Kaiser/sinc coefficients directly in long double, using an
independent I0 power series and unit-DC normalization. It reads neither the
serialized coefficient arrays nor `AudioFir` history/output. A separate raw
`ResearchEngine` runs at each explicitly expected internal rate; ordinary
chronological sample storage and full long-double convolution select exactly
internal index `L*n`. No gain, phase, or onset alignment is fitted. The frozen
absolute gate remains **1e-12 V**. At checkpoints, every key/mode q/v and total
mechanical energy must equal the raw core at the same end-of-call physical time.
