# Wave 1, assignment 019 — continuation campaign validation

Actual task name: `/root/w1_019_campaign_validation`.

## Delivered

Added the standard-library-only, read-only checker
`tools/validate_continuation_campaign.py` and focused regressions in
`tests/python/test_continuation_campaign.py`. This report is the third assigned
changed path.

The checker reads only the continuation ledger and its declared reports. It
requires the exact schema, a full 40-digit hexadecimal baseline commit ID,
unique integer IDs from 1 through 100, the corresponding wave and actual-task
name prefix, unique task names, and each assignment's exact report path. Running
records require a null report hash. Completed records require a regular report
whose current SHA256 matches the stored digest. Symlinks, traversal, duplicate
JSON keys, nonfinite JSON numbers, and booleans used as integer fields are
rejected. Each later wave requires all 20 assignments in every earlier wave to
be completed. `--require-complete` requires all 100 completed reports.

There are no registration, synchronization, or index-writing commands. Historical
campaign tools and ledgers, canonical project state, and Git were not modified.

## Boundary and handoff

This checks consistency of declared records and report bytes. It does not attest
agent execution, independently establish launch chronology, verify the baseline
object against Git, accept the scientific work described by reports, or claim
physical fidelity. Generated-index checking is intentionally outside this small
validator.
