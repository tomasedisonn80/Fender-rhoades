not an exhaustive allocation-free or real-time-deadline claim.

## Changes and checks

- Derive `ScalarEngine` from `HostEventProcessor::engine()` so independent note
  schedules and gain expectations drive the selected direct or filtered model.
  Add 96 kHz to scalar-output coverage; float and double checks now include
  32, 48, 96 and 192 kHz. The filtered numerical kernel still requires its
  separate direct-convolution oracle; this suite tests adapter behavior.
- Pass `kStateModel` explicitly for variant state construction, stream helpers,
  pending saves, recalls and controller roundtrips. The stream fixture retains
  independent golden bytes and malformed payload/transfer/seek checks. Additional
  checks verify that shared helper and fixture-loader defaults still select
  model 1 in either executable and that a stream from the other model rejects.
- In the dense-automation selector, inject a host read failure at the last
  sustain point after all 8192 gain points and 8192 sustain reads. Verify the
  actual read counts, complete declared-output silence, untouched trailing
  guards, unchanged ownership/configuration/mechanics and equal subsequent
  engine output. The continuation check also exercises retained FIR history.
  This is late input-preflight rejection, not an injected arithmetic fault.
- Run the allocation fixture for float and double outputs at 48, 96 and 192 kHz,
  exercising all three filtered-rate branches. Each combination makes sixteen
  repeated note/automation callbacks, one malformed-input callback, one
  bufferless parameter flush and one pending-recall boundary callback.
  Construction and stream I/O remain outside the measured process interval.
- Move calibration before each selector so its counter result does not rely on
  another test process having run first. Runtime checks remain active in Release.

## Limits and handoff

The probe intercepts the eight global C++ allocation forms on the invoking
thread during these actual process calls. It does not intercept arbitrary
`malloc`/`realloc`, measure locking or I/O, cover unexecuted branches, validate
another host, or establish Windows/macOS/device behavior. The scalar oracle
shares the selected physical/filter engine and independently checks adapter
scheduling, ownership and gain; it is not independent evidence of FIR accuracy
or measured instrument fidelity. SDK module validation and broader integration
tests were outside this assignment.

The integrator may review/register this report and retain both twelve-selector
suites in the integration gates. No additional source change is pending for
this bounded assignment.
