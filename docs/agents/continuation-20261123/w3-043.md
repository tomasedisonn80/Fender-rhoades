Command: `rhodes_audio_probe --sample-rate Hz --frames N`, with physical event
rows on stdin: `offset type key value`. Both options are required, in either
order. Finite binary64 rates cover 32000..192000 Hz; frames cover 1..4096.
At most 4096 rows and 128 bytes per row excluding newline are accepted.
Blank rows reject; empty stdin is silence. CRLF, bounded surrounding whitespace,
and a final unterminated row are supported. Numeric overflow/underflow,
nonfinite values, extra fields, unknown/repeated options, and unknown types
reject. Integer parsing rejects signs other than ordinary unsigned digits.

`on` accepts physical keys 0..72 and normalized intensity 0..1; zero releases.
`off` requires value zero. Global events require key zero: `sustain` takes 0/1,
and `all_off`/`reset` require value zero. Offsets must be nondecreasing and less
than N; equal-offset rows retain producer order before the indicated sample.

Entire argument/stdin preflight completes before engine construction. Rendering
uses fixed arrays and 64-frame outer blocks, with direct physical-event dispatch
before each host sample. It therefore accepts all 4096 rows at one offset
without the host EventProcessor's 256-events-per-call limit. The engine advances
at most 4096 host frames / 16384 internal frames per invocation. Accepted stdin
is at most 528384 bytes; the first over-limit byte/row rejects immediately.

Successful stdout is one JSON object with `schema_version`, synthetic `model`
and `scope`, `sample_rate_hz`, `internal_sample_rate_hz`, `oversampling_factor`,
`latency_frames`, `frames`, `event_count`, and `samples_volts`. Values use classic
locale and 17 significant digits; samples remain binary64 loaded volts. The
causal 48-frame FIR delay remains. There is no monitoring gain, normalization,
time shift, float32 conversion, WAV container, or application file write.
Input/render failure exits 2 with a stderr diagnostic and no JSON output.
