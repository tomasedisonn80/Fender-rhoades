## Mathematical and protocol audit

- `modal_solution` implements the specified arbitrary-time underdamped q/v
  equations. `KeyTrajectory` propagates to each event using the preceding loss,
  preserves q/v on releases and pedal changes, adds the specified velocity
  impulse on nonzero strikes, and treats zero-intensity strikes as release.
  Processing all same-offset events in producer order before choosing the next
  beta is equivalent here because no time elapses between those events.
- Held keys or sustain select free loss; `all_off` releases keys while sustain
  remains effective. Reset clears q/v, held and sustain before later same-offset
  events. Per-key event filtering preserves all global events and local order.
- Modal observation is summed before the cubic flux derivative. Each key's
  nonlinear voltage is then weighted by `(12000/12019)/4` for keys 0..3 or
  `(12000/12019)/3` otherwise. Silent pickups therefore remain represented by
  the complete network loading. Chord reuse sums local voltages, without
  introducing cross-key nonlinear products.
- A independently generates `96L+1` Kaiser/sinc taps, normalizes their DC sum,
  uses ordinary causal convolution, and reads internal index `L*n`. Zero
  prehistory and fresh convolution epochs at resets preserve the full 48-frame
  delay, startup samples and reset transients. There is no fitted alignment.
- B uses exactly 96 unit cells and separate orders 16/32/64. With
  `g_a[m]=V((m-delta[a])/F)`, the convolution evaluates
  `V((n-j-delta[a])/F)`, matching the specified integral. Values before each
  reset epoch are zeroed. The same quadrature weights form each DC normalizer;
  a separately adaptive scalar integral also audits those normalizers.
- All nine exact binary64 rates and the 4/2/1 branch choices are retained.
  Metadata checks compare exact float hex identities, so the two nextafter
  cases cannot silently become the closed rate boundaries.
- Both peak and RMS refinement limits must pass before B is scored. Unresolved
  B retains `inconclusive: reference not resolved` and no engine-score metrics.
  A uses 1e-12 V; resolved B uses 1e-4 V peak and 1e-5 V RMS. Full-record errors,
  signed mean, maximum frame/time, inclusive `[event,event+96]` windows, their
  union and its complement are retained without trimming startup/reset data.
- Probe input/stdout/stderr and compressed binary64 arrays are retained before
  assessment. Probe nonfinites reject; per-key nonfinite references reject.
  NaN metrics cannot pass the comparisons; nonfinite JSON metrics cannot be
  serialized as a completed row (`allow_nan=False`). Operational errors yield
  an incomplete run, and raw output already captured remains present. Output
  directories and files are exclusive, comparison failures do not stop later cases,
  and the source/binary snapshot is checked again at the end.
