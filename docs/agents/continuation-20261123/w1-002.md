## Recommendation

Add an **optional `AudioEngine` containing the unchanged `ResearchEngine` and a
bounded causal FIR decimator**. Keep the legacy path/default until independent
filter, transient, host-latency and callback-budget gates pass. This is useful
numerical infrastructure, not evidence of improved measured fidelity or audible
quality. Do not integrate the offline contact solver into this callback scope.

The existing oscillator advances by the exact constant-damping transition; its
remaining finite-precision error is distinct from sampling error. `sample()` sums
all local modes before evaluating `-(a1+2*a2*x+3*a3*x*x)*v`, with no antialias
filter. The linear resistive harp permits one filter **after** the complete harp
sum; retaining all pickup impedances and nonlinear modal cross terms is essential.
No interpolation of already aliased host-rate voltage can repair this omission.

The current symbolic audit gives a highest held carrier of **42,798.841859 Hz**.
Possible folded carriers occur on 18/12/11 keys at 32/44.1/48 kHz. Clearing those
carriers does not bound strike, retrigger or damping-switch sidebands. The retained
key-72 test predicts a 1.3413 nV fold at 19,467.438761 Hz. Its early-window residual
is only 0.578 nV RMS, below the conservative 1.381 nV export-rounding envelope;
its fitted line is supporting evidence, not a certified error bound. The much
larger onset difference includes zero-extension/filter-edge effects.

## Wrapper contract

| Host rate | Internal factor | Internal range |
| --- | --- | --- |
| 32–48 kHz, inclusive | 4 | 128–192 kHz |
| >48–96 kHz, inclusive | 2 | >96–192 kHz |
| >96–192 kHz | 1 | >96–192 kHz |

This honors the existing internal 192 kHz maximum. Freeze factors at `prepare`;
rate changes already reset the old engine. Preparation must remain atomic on
rejection. Keep host rate and internal rate as separate fields/accessors.

Use the existing `BasicEventProcessor` facade: validate host offsets/count/order
first, dispatch each event once at internal index `L*n`, then consume exactly
`L` internal samples per host sample. Return the filtered value at **substep 0**,
while consuming subsequent substeps for history/state. Returning substep `L-1`
would introduce a fractional-sample alignment error. The host cursor remains in
host frames. Exposed modal states represent the same physical timestamp after
each frame; they need not be bit-identical to native-rate repeated transitions.

Candidate filter lengths `N=64*L+1` give 257/129/65 taps and exactly **32 host
samples** of linear-phase delay. Keep that delay at factor 1 as well, using the
same declared filtered-output contract. Treat lengths as candidates: at 32 kHz,
the highest linear mode (14.266 kHz) is close to Nyquist (16 kHz), so passband
flatness, transition width and rejection must be measured before freezing taps.
Precompute coefficients outside processing; fixed ring storage, no allocation,
locking, transcendental design or unbounded loops in callbacks. Filter history
persists across blocks, retriggers and releases. Explicit reset clears mechanics,
history and phase; failures retain the existing reset-required semantics.

Initial development should expose this through dedicated tests/render/benchmark
paths only. If host quality selection follows, make it nonautomatable and change
it only while inactive, with host latency renegotiation. A persisted quality
field requires state version 2; version-1 recall explicitly selects legacy mode,
preserving existing preset behavior. Do not silently reinterpret version-1 state.

## Alternatives and cost

Deleting above-Nyquist exponential carriers is insufficient: decaying envelopes
and event boundaries are broadband. Exact continuous-time filtering of the 83
polynomial monomials is possible research, but needs event-segment history,
transient/filter-state matching and cancellation analysis. Ordinary scalar ADAA
cannot simply replace this voltage law: voltage depends jointly on displacement
and velocity. Even the exact interval-average voltage
`-[lambda(x[n])-lambda(x[n-1])]/T` is only a box filter; the observed 28.533 kHz
carrier receives approximately 5.813 dB attenuation at 48 kHz.

Continuous-time convolution/ADAA is a credible later optimization [1]; it also
introduces filtering and delay. Oversampling is simpler to validate first.
Expect roughly `L` times core sample work plus FIR work, not a measured timing
promise. Decimation-only polyphase/symmetric evaluation avoids calculating unused
outputs [2]. Benchmark complete event and VST3 callbacks, especially 73-key,
64-frame event storms; historical native-rate timings cannot approve this path.

## Independent acceptance work

1. Generate double-precision references from closed-form modal trajectories,
   independent polynomial expansion and analytic event segmentation. Refine
   reference rate/filter support independently; avoid float-WAV rounding floors.
2. Verify measured FIR gain/phase/stopband and impulse latency at every factor and
   either side of 48/96 kHz. Use analytical single/multitone line coefficients,
   including cross terms, without fitting away gain or time offsets.
3. Cover all 73 keys, declared intensity/retrigger envelope, pedal/release,
   onset/tails, chords, partition invariance, faults, reset, and rejected blocks.
   Compare mechanical states separately from delayed electrical output.
4. Predeclare absolute/relative passband, folded-line and transient tolerances;
   report measured CPU distribution, allocations and nominal deadline misses.
