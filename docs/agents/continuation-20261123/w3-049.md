## Result

Added [vst3_dual_module_test.cpp](../../../tests/cpp/vst3_dual_module_test.cpp).
The retained test uses the pinned SDK's `VST3::Hosting::Module` API and links only
SDK hosting support. It neither links the Rhodes core nor compiles a processor or
controller implementation into the host. This strengthens the temporary
[W1-020 loader](w1-020.md), which did not process audio.

Standalone execution on Linux x86_64 with GCC 14.2.0 passed **6,418 checks and
24 actual loaded-module callbacks**. Two complete simultaneous-load lifecycles
run float32 at 48 kHz and float64 at 96 kHz, each with 128-frame blocks. After
terminating/releasing the first pair and destroying the SDK module handles, the
second pair loads in reverse order. This probes load-order symbol interference.

The regression checks:

- Distinct live factories, four distinct frozen class IDs, both versions,
  processor-to-controller identity, and creation/initialization of both pairs.
- `IAudioProcessor` queried from the **same initialized `IComponent` instance**;
  the former temporary test created a separate uninitialized audio instance.
- Exact instrument bus counts, supported setup, 0/48 latency and infinite tail.
- Actual 16-byte RHST version-1 states with model tags 1/2, agreement between
  each processor and controller, and transactional cross-model rejection.
- Interleaved silence, strike, continuation, release and reset callbacks;
  finite samples, identical stereo channels and correct silence flags.
- Independence: striking direct leaves filtered silent; resetting direct leaves
  filtered ringing; both independent reset paths return to exact silence.
- Successful stop, deactivate and terminate callbacks; interface release before
  SDK module destruction; no remaining shared module owners before destruction.

`duplicate_guard` passed **3 checks**, specifically catching the same bundle's
factory alias. Independently invoking the ordinary coexist mode with the direct
bundle in both argument positions returned **1** with `two bundle handles alias
one factory`. Thus a duplicated bundle cannot satisfy the positive test.
