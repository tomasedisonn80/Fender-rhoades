## Delivered API and behavior

Implemented the committed
[peak diagnostic decision](../../specs/CONTACT_PEAK_DIAGNOSTICS_20261123.md),
informed by [W1-009](w1-009.md). `Settings::locate_peak_candidates` defaults to
false. `Diagnostics` contains four fixed `PeakCandidate` records:

| Member | Value unit |
| --- | --- |
| `located_hammer_compression` | m |
| `located_hammer_force` | N |
| `located_damper_compression` | m |
| `located_damper_force` | N |

Each record stores `value`, `time_s`, `bracket_begin_s`, `bracket_end_s`, and
`PeakOrigin`: `disabled`, `sample`, `stationary_candidate`, `action_before`, or
`action_after`. Disabled contacts/features retain disabled records. Enabled
all-zero results retain an explicit initial sample. Sample/action brackets are
degenerate. Strictly greater values replace prior candidates; an equal value at
the identical time can upgrade a sample's provenance to a root or action side.

The separate collector replays each accepted interval's five quarter-grid
points and all root-refinement points from one fixed interval anchor, using the
existing two-half-step replay (including its pre-existing certified zero-force
analytic branch). It also includes actual accepted endpoints and both sides of
external actions. It never changes the accepted endpoint mechanics or the
existing event scan/refiner. Extra diagnostic evaluations do not feed the
legacy sampled maxima or maximum power-residual diagnostic.

Compression candidates use zero relative velocity with positive compression.
Positive-force candidates use `w*(k+c*w)+c*delta*a`, with hammer acceleration
minus projected modal acceleration, or projected damper modal acceleration minus
prescribed face acceleration. Force brackets require positive compression and
positive raw force factor; an inactive midpoint interrupts that stationary-root
search while retaining sampled values. Zero derivative plateaus do not enumerate
roots. Candidate values include the final root bracket's endpoints and midpoint,
with the selected value's own time inside the reported bracket.

New work consumes the existing trial, RHS, root-iteration, and minimum-progress
budgets. Searches have fixed quarter segmentation and bounded root loops, with
no new root-history allocation. Nonfinite or out-of-domain derived values fail
with the existing typed arithmetic failure. A failed optional collection returns
through the existing whole-call transaction, preserving all prior mechanics,
ledger, event/interval histories, and old/new diagnostics.
