## Independent adapter expectations

The scalar oracle drives `AudioEngine` directly, schedules host-offset events
without using `BasicEventProcessor`, tracks note ownership with a separate map
instead of `NoteTracker`, and evaluates gain with long-double barycentric
interpolation instead of the processor's interpolation expression. Native
normal-control float casts supply the expected endpoint quantization; this
suite does not independently test hostile floating-point environments.

For every accepted nonzero call, the suite compares both output channels,
silence flags, all modal displacement/velocity states, mechanical energy,
frame cursor, ownership count, current controls and published controls. It
also checks that samples after the declared frame count remain untouched.
Output tolerances are four float or 64 double machine epsilons times
`max(1e-8, abs(expected))`; exact zero-gain samples and stereo equality are
checked separately. Filter coefficients/convolution correctness remain the
separate core numerical tests' responsibility: this oracle shares
`AudioEngine`, but independently checks the VST3 event/control adaptation.

| Selector | Verified behavior | Scalar-checked samples |
| --- | --- | ---: |
| `scalar_output` | 32/64-bit processing at 32, 48, 88.2, 96 and 192 kHz; sample-offset notes, overlapping holders, retrigger, release, sustain ties, gain ramps, duplicate endpoints and tails | 3,450 |
| `rate_contract` | Constant 48-frame reported latency before setup and at eight rate/boundary cases; factors 4/2/1 and exact internal rates, including the next representable rates above 48 and 96 kHz | 0 |
| `state_contract` | Model-2 processor and controller saves/recalls; 16-byte/tag inspection; one-byte transfers; prefix position; model-1 rejection preserving controller controls, processor current state, pending recall and subsequent output | 558 |
| `reset_and_flush` | Both precisions at every factor; stop, inactive, setup and recall resets remove FIR history; recall commits on a zero-frame flush; repeated empty and parameter flushes consume no samples; fresh note phase after reset | 7,602 |
| `rejected_calls` | Both precisions at every factor; bad rate/NaN/block bound/sample format setup preserves history; invalid late gain, note offset, failed event read and input bus count reject bounded blocks transactionally; complete supported output silencing and 256-frame future agreement | 13,392 |

The model-1 rejection cases use explicit model-1 serialized state, and the
model-1 reader independently refuses saved model-2 chunks. Actual simultaneous
loading of the two plug-in modules and original-variant controller behavior
are outside this file's scope.
