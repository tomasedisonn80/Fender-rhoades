## Changes

Changed only `tools/validate_contact_reference.py`, added
`tests/python/test_contact_selection.py`, and wrote this report.

Frozen step, event, local and coordinate comparisons now select explicit slots
using fixture, maximum step, event tolerance, output grid, relative tolerance,
and all four emitted absolute tolerances. Matching uses fixed relative
`1e-12` and zero absolute tolerance. Missing optional settings remain incomplete;
invalid, ambiguous or undeclared settings fail. A tighter local run cannot
replace the baseline step/event/coordinate run.

The actual runner and archived 208-run manifest specify local scales
`1, 0.1, 0.01`. Those values are preserved. The assignment's initial
`0.25/0.0625` wording was corrected by the integrator after this verification.
Neither those alternate scales nor arbitrary `0.8/0.6` scales satisfy the
frozen axis. STEP_LEVELS, EVENT_LEVELS, observable budgets, numerical tolerances,
128-ulp resolution calculation and final-decrease criterion remain unchanged.

Canonical scientific content includes every run field except the source path.
Conflicting same-slot hashes fail before refinement comparisons, independent of
input order. Identical copies deduplicate for selection, retaining copy counts,
sorted source paths and scientific-content SHA-256 hashes in a new `selection`
report field. CSV grouping preserves the entire settings tuple and keeps local
controls at run level; distinct local runs no longer merge their sample rows.
