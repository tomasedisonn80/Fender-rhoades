## Implementable contract

`BasicEventProcessor<AudioEngine>`. Suggested additions to its mirrored engine API:

```cpp
bool prepare(double host_hz) noexcept;
void reset() noexcept;
bool process(std::span<double> output_volts) noexcept;
double sample_rate_hz() const noexcept;          // host rate
double internal_sample_rate_hz() const noexcept;
unsigned oversampling_factor() const noexcept;
static constexpr std::size_t latency_frames() noexcept { return 48; }
```

Mirror note/pedal operations and const modal-state/energy accessors. Do not expose
a mutable core that could bypass history/fault handling. Construction should give
a valid, silent 48-kHz host configuration, matching existing default usability.

Validate finite host rate in [32000,192000] before multiplication. Select L=4 at
≤48000, L=2 at ≤96000, otherwise L=1. Prepare candidate core, coefficients and
metadata completely before publishing; rejection preserves mechanics, history,
rates, cursor and fault status. Successful preparation resets everything.
Preparation is audio-owner-exclusive, outside processing; “atomic” means failure
atomicity, not concurrent thread safety.

Use W1-005's normalized beta-9 taps, cutoff 0.47 host rate, N=96L+1: 385/193/97
taps and 48-frame delay, including L=1. Fixed storage supports at most 385 samples
and taps; consume exactly L≤4 core samples and evaluate one FIR output per host
frame. No allocations, locks or coefficient design during processing.

## Hidden indexing and lifecycle hazards

At host frame n, events execute once before internal sample nL. Insert that sample,
compute `y[n]=sum(h[j]*x[nL-j])`, retain the result locally, then consume and store
substeps 1…L−1. Publish only after all L succeed. Histories for negative indices
are zero; no pre-roll, skipping taps, or normalization by populated taps.

**N modulo L equals 1:** deriving decimation phase from the ring index makes phase
slip whenever the ring wraps. Use the frame's explicit substep index; wrap history
by its declared capacity and associate h[0] with the newest sample. Filtering
after inserting all L samples silently selects the wrong timestamp unless the
substep-0 position is retained correctly.

After a successful frame, mechanics are at (n+1)/host_rate; electrical output has
48-frame group delay. Startup can be nonzero immediately because h[0] is nonzero;
latency does not promise 48 leading zeros. Preserve history on release/retrigger.
Hard reset clears mechanics, pedal, history, phase and fault latch.

Any core/FIR arithmetic failure zeros the entire failed host sample and remaining
output, even when substep 0 succeeded; retain preceding samples and partial state,
latch failure and require explicit reset/successful prepare. `BasicEventProcessor`
counts only completed host frames. Its in-stream reset preserves the host cursor
and cannot clear an already latched fault: fault rejection precedes dispatch.
Invalid blocks are preflighted before mutation, output zeroed; empty blocks do
not advance. Direct invalid note calls also leave history/state unchanged.
