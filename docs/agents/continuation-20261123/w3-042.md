## Implemented reference

Each key has independent analytic, constant-loss modal segments. Events propagate
the preceding state to the exact host-frame boundary before applying operations
in producer order. Strikes add velocity while retaining displacement and existing
velocity. Release, zero-intensity strike, sustain and all-notes-off preserve
motion and select the appropriate loss regime. A hard reset clears mechanics,
held flags, sustain and both reference filter histories. A same-offset strike
after reset remains active; a strike before reset is erased.

Arbitrary-time displacement and velocity use worker 025's closed forms, without
calling the production oscillator, importing its transition matrices, importing
the production coefficient generator or reading serialized coefficients into the
reference. Modal observations are summed **within each key** before the cubic
flux derivative. The resulting local voltages receive the complete loaded-harp
weights `12000/12019` times `1/4` or `1/3`. Chords reuse these independently
computed per-key voltages through the linear electrical sum. This introduces no
cross-key pickup products and does not remove silent electrical branches.

Comparison A samples the analytic source at exactly `L*n` and the intervening
internal times. A separate NumPy Kaiser/sinc calculation constructs `96L+1`
unit-DC taps. Ordinary causal convolution is evaluated separately inside every
reset epoch and retained at substep zero. Its maximum absolute error gate remains
**1e-12 V**.

Comparison B evaluates separate Gauss-Legendre orders **16, 32 and 64 inside each
of the 96 unit host-frame cells**. It implements `g_a[m]=V((m-delta_a)/F)` and
96-tap causal convolutions for each quadrature node. Zero prehistory and reset
history truncation are explicit. No uniformly oversampled reference engine is
prepared at an unsupported rate. The finite kernel retains its **48-frame
delay**, including every startup/reset sample, without fitted gain, phase,
onset, time shift or half-sample correction.

Both Q16→Q32 and Q32→Q64 must meet peak **1e-9 V** and RMS **1e-10 V**. If either
fails, B is recorded as `inconclusive: reference not resolved`, its engine
comparison metrics remain null, and all raw arrays and refinement metrics remain
available. Resolved B uses the unchanged exploratory peak **1e-4 V** and RMS
**1e-5 V** limits. The unit tests also inject a failure that passes the peak limit
but fails RMS, confirming that each limit is enforced separately.

The three independent DC sums are also compared to a separate adaptive scalar
integral evaluated cell by cell:

| Normalizer | Observed value |
| --- | ---: |
| Q16 | 1.0000040920699909 |
| Q32 | 1.000004092069991 |
| Q64 | 1.000004092069991 |
| Separate adaptive cell integration | 1.000004092069991 |

The largest pairwise difference above is `2.220446049250313e-16`; the sum of the
adaptive routine's reported absolute error estimates is
`2.547775947000941e-14`. These are numerical observations, not a formal integral
error proof. No new normalizer threshold was introduced after observing them.

Coordinated probe protocol: `rhodes_audio_probe --sample-rate F --frames N`,
with ordered stdin rows `offset type key value`. Types are `on`, `off`,
`sustain`, `all_off`, and `reset`. Globals use key zero and occur once per script
operation. The full-keyboard chord has **736 events**, not repeated sustain/reset
operations per key. Worker 043's probe dispatches physical events directly before
the corresponding sample, in 64-frame outer slices; it is not constrained by the
event processor's per-block event limit. The Python tool verifies exact rate,
factor, internal rate, latency, frame/event counts, model identity and finite
round-trippable voltage values from its JSON response.

Each numerical run requires a new output directory and an existing parent.
Existing directories, files and final symlinks are refused; files are published
exclusively. Output includes:

- `plan.json`, with complete inputs, parameters, limits and its deterministic hash;
- `manifest.json`, with source and probe-binary hashes, library/platform versions,
  precision and independent normalizer comparisons;
- `cases.jsonl`, a machine-readable per-case table with complete event inputs,
  their hashes, separate A/B/refinement statuses and metrics;
- Exact probe stdin, stdout and stderr bytes for each case;
- Per-case NPZ archives containing production, independent same-rate, independent
  internal-source and Q16/Q32/Q64 loaded-voltage arrays, plus both file hashes and
  canonical little-endian float64 array hashes;
- `summary.json`, recording completed counts, failures/inconclusive case IDs,
  operational errors and whether source/binary bytes changed during the run.

Metrics include raw output/reference peaks, maximum error and its exact host
frame/time, signed error there, RMS and signed mean. Each distinct event offset
has its inclusive causal `[event,event+96]` window with all corresponding event
indices retained. The union and its complement are reported separately, while
full-record metrics remain intact. Unresolved B is not scored in these regions.
Invalid probe output, nonzero probe failures, partial runs and failed reference
arrays have dedicated retention tests. Source/binary identities are recorded;
the tool does not independently attest the provenance of the compiled binary.
