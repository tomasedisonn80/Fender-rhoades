## Finding and evidence boundary

The current three-mode cubic pickup has **no frozen sinusoidal carrier above
42,798.841989567 Hz** over all 73 keys. Every supported filtered branch has an
internal Nyquist above that value. This establishes a limited algebraic carrier
bound, not a bound on transient alias voltage. Causal damping, instantaneous
strikes, damping switches and explicit resets do not produce strictly bandlimited
signals. A finite FIR cannot undo components already folded during internal
sampling.

[W1-011](w1-011.md) establishes coefficient/response observations.
[W1-016](w1-016.md) compares the wrapper with a raw core at the **same internal
rate**, followed by independent convolution; its maximum observed discrepancy

implementation evidence, but both streams contain the same internal sampling

## Exhaustive frozen carrier calculation

From [the core](../../../src/research_engine.cpp) and
[its public constants](../../../include/rhodes/research_engine.hpp), key
`k=0..72` has nominal fundamental

`f[k] = 440 * 2^((k - 41)/12)` Hz,

with modal ratios `r=(1, 2.73, 5.41)`. Local observation is
`x=q1+0.3*q2+0.08*q3`, and pickup voltage is
`V=-(0.4+1600*x+1200000*x*x)*xdot`. Thus its total degree in modal sinusoidal
factors is at most three; differentiating the cubic flux does not add a fourth
factor. Multiplication adds signed frequencies. For arbitrary frozen modal
amplitudes/phases, enumerate

`abs(k1*r1+k2*r2+k3*r3)*f[k]`, where `1 <= |k1|+|k2|+|k3| <= 3`.

The following 31 positive ratio values exhaust the candidate families. Degree
three also repeats degree-one frequencies through cancelling factor pairs;
the table lists each new family once. Constant terms of an undamped flux have
zero voltage after differentiation. Particular amplitudes/phases can cancel
individual candidates, so this is a support bound, not a power prediction.

| Degree adding the family | Positive frequency divided by f[k] |
| --- | --- |
| 1 | 1, 2.73, 5.41 |
| 2 | 1.73, 2, 2.68, 3.73, 4.41, 5.46, 6.41, 8.14, 10.82 |
| 3 | 0.05, 0.73, 1.68, 3, 3.41, 3.68, 4.46, 4.73, 6.46, 7.14, 7.41, 8.09, 8.19, 9.14, 9.82, 10.87, 11.82, 13.55, 16.23 |

The small cubic difference is `abs(2*2.73-5.41)=0.05`, not an omitted
subharmonic. To reproduce the enumeration exactly for the nominal decimal

## What this bound leaves open

1. **Damping and observation intervals.** A segment is a sum of decaying complex
   exponentials, not everlasting sinusoids. Products carry envelopes with sums
   of decay constants, up to 21/s freely or 135/s damped for the third-mode cubic
   term. Causal onset, segment boundaries and any finite observation window
   give spectra extending beyond the carrier centers. Quadratic zero-carrier
   flux terms can now have nonzero voltage because their envelopes decay.
   FFT leakage from a chosen observation window must not be mislabeled aliasing.
2. **Impulses and retriggers.** A strike preserves q and adds
   `0.06*u*(1,0.45,0.2)` m/s to modal velocities. Thus
   `Delta Vpickup = -(0.4+1600*x+1200000*x*x)*0.06906*u`.
   This is a voltage step, not bandlimited excitation. At rest and u=1, the
   pickup jump is -0.027624 V. The loaded single-key jump is
   -0.006895082785589484 V for keys 0..3 and -0.009193443714119311 V otherwise;
   a simultaneous full-keyboard strike gives -0.6619279474165904 V. These follow
   from the exact nominal load factor `12000/12019` and the 1/4 or 1/3 branch
   weights. Retrigger steps depend on the moving x. A normalized strike limit
   alone does not specify an accumulated-energy/event-density domain for every
   possible call sequence.
3. **Switches.** Note release and pedal changes preserve q/v but immediately
   change acceleration through beta. Pickup voltage remains continuous at
   such a switch, while its derivative can jump. Explicit reset clears both
   mechanics and FIR history; that deliberate output discontinuity requires
   separate accounting. Successful prepare replaces rate/factor/state/history.
   There is no live pickup-coefficient control in AudioEngine; future geometry,
   load, coefficient or external gain automation needs its own scope.
4. **Finite FIR.** Its history spans 96 host frames, with 48-frame group delay.
   Startup, reset and the entire 96-frame response after each event belong in
   the voltage comparison. Finite stopband rejection is not zero; once an
   above-internal-Nyquist component folds into the passband it cannot be removed
   by this downstream FIR. End-of-record FFT padding must not add an artificial
   source cutoff or circular convolution.

The public primary paper by Parker, Zavalishin and Le Bivic,
[DAFx 2016, *Reducing the Aliasing of Nonlinear Waveshaping Using Continuous-Time
Convolution*](https://dafx.de/paper-archive/2016/dafxpapers/20-DAFx-16_paper_41-PN.pdf),
was checked on 2026-11-23. It motivates filtering the continuous nonlinear
output before sampling. No paper source code was copied. The calculations and
experiment below are derived directly from this repository's equations; they
do not propose blindly applying an antiderivative method to `x*xdot`.

### Independent source and two comparisons

Implement an offline scalar/vectorized reference from the documented equations,
without using ResearchEngine, its transition matrices, AudioFir, or serialized
filter coefficients. At each event retain the reference q/v, apply impulses and
loss changes in producer order, then evaluate each constant-loss segment at
arbitrary time tau using

`q(tau)=exp(-beta*tau)*(q0*cos(wd*tau)+(v0+beta*q0)*sin(wd*tau)/wd)`

`v(tau)=exp(-beta*tau)*(v0*cos(wd*tau)-(beta*v0+w0*w0*q0)*sin(wd*tau)/wd)`.

Sum observation-weighted modes, evaluate the polynomial derivative, then apply
the loaded-harp weights above. Do not call `ResearchEngine.prepare` at an
unsupported reference rate; independent arbitrary-time evaluation needs no
such rate. Record constants, source hashes, precision and library versions.

**Comparison A:** sample that independent source at production internal times,
independently generate the documented FIR, and perform ordinary convolution at
internal index `L*n`. Compare to AudioEngine using the existing **1e-12 V**
absolute wrapper gate, with any failure reported separately. This checks that
the independent trajectory and production implementation actually agree on the
same sampled problem; passing A cannot establish transient antialiasing.

**Comparison B:** integrate the continuous source against the continuous
prototype corresponding to the same finite Kaiser/sinc design. In host-frame
units define, for `0<=s<=96`,

`kappa(s)=0.94*sinc(0.94*(s-48))*I0(9*sqrt(1-((s-48)/48)^2))/I0(9)`

where `sinc(z)=sin(pi*z)/(pi*z)` and `C=integral_0^96 kappa(s) ds`. The target is

`y_ct[n]=(1/C)*integral_0^96 kappa(s)*V((n-s)/F) ds`.

This target has unit DC gain, the same finite support and **48 host frames of
delay**. It is not an ideal brickwall filter. B measures total continuous-
prototype voltage discrepancy, including internal sampling/transient error and
the discrete FIR's approximation to that prototype. Do not label its entire
residual a separately isolated alias voltage or a measured instrument error.

Use Gauss-Legendre quadrature of orders **16, 32, 64 separately within every
unit interval `[j,j+1]`, j=0..95**. Every event occurs on a host-frame boundary,
so all voltage jumps/switches lie on integration boundaries, never hidden inside
one quadrature cell. For unit-interval nodes delta[a] and weights w[a], this is
implementable as 96-tap convolutions:

`g_a[m]=V((m-delta[a])/F)`

`y_Q[n]=sum_a sum_j w[a]*kappa(j+delta[a])*g_a[n-j] / C_Q`.

Use direct vectorized convolution or zero-padded FFT convolution; no enormous
uniform high-rate reference stream is needed. Compute `C_Q` with the same
quadrature order. Zero source history before time zero. At reset, start a new
segment with zero reference filter history, matching the specified hard reset.
Do not include pre-reset source history in post-reset integration. Evaluate
events before samples at the event timestamp. No fitted gain, time shift,
onset alignment, phase adjustment, or extra half-sample correction is allowed.

**Recommendation:** implement this diagnostic before selecting higher factors,
