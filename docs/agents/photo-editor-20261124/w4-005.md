## Result and boundary

**PASS for complete offline processing of all three current VST3 variants in
REAPER 7.86, with no functioning audio device.** Each neutral project rendered
exactly 72,000 stereo frames at 48 kHz (1.5 seconds), contained nonzero decoded
samples, and exited REAPER with status 0. The WAV container lengths, frame
counts, data lengths, sample finiteness and actual loaded module paths were
checked; file presence and startup were not used as the success criterion.

**PASS for the separate bounded host-automation comparison.** A constant
Expression envelope at 0.5 halved each variant's samples within 0.5 PCM24 LSB.
Combined altered panel automation changed the signal and produced unequal
stereo channels in every variant.

**Unresolved static save/recall boundary, preserved as six failed comparisons.**
Setting parameters and saving immediately within one ReaScript invocation while
the device was closed saved differing controller and processor-state packets.
The requested controls survived host readback after reload, but these six saved
projects rendered the neutral audio. The automation results do not turn those
static comparisons into passes. No production code was changed, and there is
no broad REAPER state-recall or control qualification claim.

Each project has one unarmed, unity-gain, centered stereo track containing its
own VST3 instrument and a 1.5-second MIDI item. The two channel-1 events are:

| --- | ---: | ---: | ---: |
| 60 | 100 | 0.125 s | 0.750 s |
| 67 | 88 | 0.875 s | 1.250 s |

The Lua creator checked the two-note count and zero CC/text events. Render
settings are master mix, custom bounds 0–1.5 seconds, 48 kHz, two channels, no
added tail, disabled dither and disabled normalization/postprocessing. The
host-produced RPP contains `RENDER_1X 0 0`, `RENDER_RANGE 0 0 1.5 0 0`,
`RENDER_FMT 0 2 48000`, and `SAMPLERATE 48000 1 0`. The supported `evaw` sink
selection produced **signed 24-bit little-endian PCM WAV**, verified by decoding
the resulting RIFF/fmt/data structure. This is not a float-WAV claim.

All runs had an 85-second runner deadline, with at most three further seconds
allowed for cleanup. The maximum observed launch was the retained failed
attempt at 85.147129 seconds. Successful CLI renders took 0.861994–1.308343
seconds including process startup. These times are observations from this
environment, not performance acceptance limits.

`saved-plugin-state-inspection.json` and `decoded-state-packets.json` retain the

remains neutral v1 (16 bytes), while the second is the requested Expression v2

`RhodesController::getState` serializes current controller values. Attribution
of the first/second saved packets to component/controller follows the saved
VST3 ordering and this source behavior; no host-call tracing was performed.

A second script reloaded all nine original projects without saving them and
recorded all six relevant controls immediately and after 250 ms. All 18

readout. It does not prove that parameter queues reached the processor before
the original save.
