## Behavior

Added persistent parameter IDs Bass=3, Treble=4, Intensity=5, Speed=6, Vibrato=7.
The parameter count is 24. The first nineteen enumeration entries retain their
previous order, including the sixteen All Notes Off commands; the five panel
parameters are appended afterward. Existing class UIDs, model IDs, old parameter
IDs, names/versions, and latency constants were left unchanged.

The controller accepts finite normalized panel values only. Bass, Treble,
Intensity, and Speed are quantized to canonical binary32 normalized values using
the existing portable control helpers. Vibrato is a switch with the same 0.5
threshold as Sustain. All five expose host automation. Default Bass/Treble/Speed
are 0.5, Intensity is zero, and Vibrato is off.

`read_plugin_state_stream` accepts exactly 16, 20, or 40 remaining bytes, with
matching wire version and immutable model. `write_plugin_state_stream` uses the
adaptive encoded view from PluginState. Both retain bounded short-transfer
handling and reject malformed/zero-progress/error transfers. The old
`read_state_stream` and `write_state_stream` implementation bodies remain
unchanged; in particular the legacy reader still rejects forty-byte packets.

Controller recall validates the entire PluginState and every persistent parameter
object before applying its eight values on the controller/UI thread. Invalid
recall changes no persistent controls. Legacy v1/v2 recall resets all panel values
to neutral defaults in the same operation. Controller saving includes all eight
persistent values and excludes transient command parameters. Neutral panel state
still exports exact v1/v2 bytes, according to Expression.

New text conversion uses the existing portable decimal helper, strict bounded
ASCII input, and case-sensitive optional suffixes. Bass/Treble map -12..+12 dB;
Speed maps 0.5..12 Hz. **Intensity displays 0..1 x, equivalent to 0..100%**, as
authorized by the integrator to retain the existing decimal helper's bounded
domain without changing it. Vibrato accepts exactly `On` or `Off`.
EQ/Speed physical text uses ordinary binary64 affine display precision. Extremely
small normalized changes near an affine endpoint can display the same physical
value; their canonical binary32 values remain intact in parameter/state storage.
No exact subnormal round-trip guarantee is claimed for affine physical text.
All old text conversion branches remain intact.
