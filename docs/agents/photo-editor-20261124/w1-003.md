## Exact-photo preservation hazards

1. **Repainting or regeneration changes the requested object.** Keep the original source bytes and render its decoded bitmap directly. Do not reconstruct the wood, grille, labels, cables, keys, highlights, or shadows. Do not crop to the keyboard or stretch to a wide plug-in banner.
2. **One transform must govern painting and hit testing.** Fit the source with `s = min(viewWidth / 1536, viewHeight / 1152)`, using centered letterbox offsets. Convert pointer positions by the exact inverse transform. Include logical-pixel/device-pixel conversion once; mismatched HiDPI transforms cause convincing-looking but misplaced hotspots.
3. **Small controls must remain individually addressable.** At a 1024×768 logical editor the 40-pixel knobs become about 27 pixels wide; the visible Treble/Bass tracks become about 69×13 pixels and are separated vertically by only about 20 pixels. Invisible padded targets may improve usability, but overlapping target precedence must be explicit.
4. **The photographed pointers already encode arbitrary positions.** Rotating whole knob crops would rotate the baked illumination and surrounding label pixels. Moving slider crops exposes stale background. Preserve the default photo; report the actual value through a temporary tooltip/status readout and a minimal active indicator if needed. Never claim a fixed photographed pointer follows automation when it does not.
5. **Source fidelity and state feedback are distinct.** The idle rendering can match the photo exactly. Hover/focus/note feedback can be transient overlays within the hit geometry, returning to the untouched source afterward. Avoid persistent generic panels, replacement keys, thick colored buttons, or decorative UI that obscures the instrument.
6. **The image is evidence only of the requested visual.** The depicted cabinet, Treble/Bass sliders, and tremolo controls do not identify a physical specimen, circuit revision, calibration or historical response. Retain the repository's unvalidated physical-fidelity boundary.
