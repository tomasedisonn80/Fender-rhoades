## Test design details

The v3 byte fixture contains distinct instrument and panel values:
gain 0.25, sustain on, Expression 0.75, Bass 0.125, Treble 0.875, Intensity 0.5,
Speed 0.25 and Vibrato on. A second literal packet changes **every field**.
Malformed-recall cases corrupt this second packet while the first remains the
current state. This catches partial application of earlier valid fields when a
later field is invalid; an invalid packet whose valid fields already equal the
current controls would miss that behavior. Rejection checks compare all 24 live
parameters and the complete saved configuration.

The stream group uses positive transfer limits 1, 2, 3, 7, 16 and 40 and checks
the exact number of calls needed to transfer the 40-byte packet. Error results,
zero progress, negative counts and overreported counts are injected at calls
1, 20 and 40 with one-byte transfers, and rejection must stop at that call.
Read extent checks cover every remaining size from 0 through 64 except the
three accepted sizes. Controller recall additionally rejects all truncated v3
packets of sizes 0 through 39, including misleading 16/20-byte v3 headers.

Metadata and text preserve the implemented physical units: Bass/Treble
−12..+12 dB, Intensity 0..1 x, Speed 0.5..12 Hz, and exact `Off`/`On` Vibrato
labels. Binary32 persistence is checked separately from physical display
round trips. The fixture does not claim that affine EQ/Hz text distinguishes
every normalized subnormal near a physical endpoint.
