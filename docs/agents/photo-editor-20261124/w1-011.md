## Public API and integration contract

`rhodes::FrontPanelEffects` constructs at 48 kHz and exposes:

```cpp
bool prepare(double sample_rate_hz) noexcept;
void reset(FrontPanelState state = {}) noexcept;
StereoSample process(double input, FrontPanelState state) noexcept;
double sample_rate_hz() const noexcept;
std::uint32_t smoothing_frames() const noexcept;
bool requires_reset() const noexcept;
static constexpr std::size_t latency_frames() noexcept; // 0
```

`rhodes::StereoSample` contains `double left` and `double right`.

Preparation accepts the existing engine domain, **32,000 through 192,000 Hz**,
including fractional rates. Success resets to default controls. Rejected rates
leave rate, coefficients, history, ramps, phase and fault state unchanged.
Reset applies a valid panel state immediately and resets phase/history. Invalid
controls supplied to reset latch a visible failure.

The header specifies the full synthetic recipe. It does not identify or
calibrate a Peterson/Janus circuit. Cascaded first-order shelves use bilinear
low-pass splits at 200 and 2500 Hz. Normalized tone controls map to -12 through
+12 dB; midpoint is exact unity. Bass obtains the requested endpoint at DC,
treble at Nyquist. The frequencies name the low-pass split, not a
gain-independent midpoint of each shelf transition.

Effective modulation depth is zero when disabled, otherwise Intensity. Speed
maps linearly to 0.5 through 12 Hz. Opposed left/right amplitude gains are
`1 - depth*(1 ± sin(phase))/2`. This is amplitude modulation despite the panel's
Vibrato label. Mono averaging therefore has constant gain `1-depth/2`, with no
cyclic modulation. Phase runs during bypass and starts at zero after reset.

Gain, effective depth and speed have independent finite linear ramps lasting
`ceil(0.010*fs)` samples. A changed target starts from the current value; its
first increment occurs on the changed sample. The last sample snaps to the
target. Changing another control does not restart an existing ramp. Disable
and zero-intensity transitions ramp to exact bypass in the same interval.

At settled neutral tone and zero effective depth, both channels return the
input bits directly, including signed zero and finite extreme values. Neutral
shelf histories are cleared, so a newly enabled shelf starts its state from
zero while gain ramps. The filter has immediate feedthrough, no lookahead,
and no added frame latency.

Nonfinite input, invalid controls or nonfinite processing arithmetic produce
NaN in **both** channels and latch `requires_reset()`. Even a later neutral
panel cannot hide this failure. Valid reset or successful prepare recovers.
The integrator must route these failures through the existing processor fault
path. The effect does not clip or silently substitute zero.

All object state is fixed storage (208 bytes in the observed GCC build).
Processing has a constant operation bound; it does not allocate, wait, lock,
or perform I/O. `sin` is used for active modulation, `pow` only on tone target
changes, and `tan` only at prepare. This is not a measured deadline claim.

## Numerical provenance

choices are explicitly synthetic development design choices. Bilinear mapping
and frequency prewarping were checked against the primary

incorporated. The independent test evaluates complex frequency-domain shelf
ratios after prewarping; it does not copy the implementation recurrence or
