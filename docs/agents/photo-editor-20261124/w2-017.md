## Native focus-loss regression

The runner established native child focus, held the left pointer button on
Volume, moved upward, then called `XSetInputFocus` on REAPER's actual main window
while keeping the button held. It subsequently moved another 18 source-image
pixels upward before release. The separate key probe held the photographed
MIDI-60 key and performed the same focus transfer. No fabricated `FocusOut`,
XEmbed deactivation message, or direct plug-in focus callback was injected.

Both probes observed native child `6291457` `FocusOut` with `mode=0`, `detail=3`,
plus floating parent `4194379` `FocusOut` and main `4194356` `FocusIn`.

| Volume after additional held/unfocused motion | `0.800000011920929` — unchanged |
| Volume held image versus after focus loss | 13,894 RGB pixels differ; highlight and popup clear |
| Volume after loss versus idle | Identical, all 786,432 pixels |

to `0.9000000357627869` after the same held Volume movement and retained both

and observes the intended cancellation.
