# A036 — Sustain, release, and explicit reset

**Inspected behavior.** The [API](../../../include/rhodes/research_engine.hpp),
[implementation](../../../src/research_engine.cpp), and
[numerical contract](../../NUMERICS.md) agree: free decay applies whenever
`key.held || sustain_`; released decay applies otherwise. `note_off` clears only
that key's held flag, and zero-intensity `note_on` delegates to it. Neither release
nor pedal changes modal displacement or velocity. Pedal-up therefore leaves
physically held keys freely decaying. `all_notes_off` clears every held flag while
respecting sustain; it can leave audible motion. Hard `reset` clears all modal
states, held flags, and sustain, restores released damping, and retains sample
rate. Successful `prepare` also clears mechanics and controls. No inconsistency
was found in these paths by inspection.

**Host boundary.** Each key has one held boolean, not a channel or press-count
ledger: the first release clears it even after repeated strikes. A future adapter
must define overlapping-note/channel aggregation. Route musical all-notes-off to
`all_notes_off`, explicit hard panic/recovery to `reset`, and clear matching host
tracking on panic. Freeze event ordering and pedal interpretation; no adapter
currently supplies those policies.

**Missing fixtures.** Existing [tests](../../../tests/cpp/research_engine_test.cpp)
exercise release continuity, pedal loss, and reset silence;
[regressions](../../../tests/cpp/review_regression.cpp) compare zero-intensity and
all-notes-off under sustain. Add a two-key fixture: strike both, depress pedal,
release only one, then lift pedal. Verify all modes retain both coordinates at
each event and only the released key gains damping. Test repeated releases and
pedal values for idempotence. Reset while pedal and a key are held; verify all
219 states are zero, rate unchanged, and a subsequent strike/release trajectory
matches a freshly prepared engine. This detects stale control state that silence
alone cannot expose.

**Physical boundary and verification.** Current switching is a viscous-loss
surrogate. Half-pedal, damper clearance, contact/recontact, and release-velocity
effects remain future physical work. Verification used source/document inspection;
no tests executed. Only this report changed. Next: implement the focused fixtures.
