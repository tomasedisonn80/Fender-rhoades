# A035 — Persistent retriggers and strike work

**Inspected behavior.** In the [implementation](../../../src/research_engine.cpp),
`note_on` copies the existing physical-key slot, updates damping, adds each modal
impulse, and commits only after all additions succeed. `add_impulse` retains
displacement and adds `J/m` to existing velocity. Release retains both state
coordinates. The fixed 73-slot array provides physical-key identity; repeated
strikes do not allocate replacement voices. No retrigger-reset defect was found
by inspection.

**Coverage gap.** The [retrigger test](../../../tests/cpp/research_engine_test.cpp)
checks one engine mode at one phase. Add opposite-velocity fixtures and all-mode,
unrelated-key checks. For `m=0.001 kg`, `J=0.00002 N·s`, equal displacement and
initial velocities `+0.03/-0.03 m/s`, the independent work identity
`Delta E=J*v_before+J*J/(2*m)` predicts `+8e-7/-4e-7 J`. Negative strike work is
valid for this prescribed impulse. For an uninterrupted same-timestamp burst
from rest, total impulse is `N*J`, so kinetic energy scales as `N*N`, not `N`.
Freeze a finite burst length and compare cumulative work against every actual
pre-strike velocity; bounded individual intensity does not bound cumulative
excitation. Check state continuity through intervening releases and pedal events,
and preserve physical-key identity throughout.

the relative impact velocity `v_h-b_h^T*v`. Freeze the relaunch operator and event
ordering before implementation. Exercise equal-speed launches against opposite
tine velocities during separation, compression, force clamping, and recontact,
including simultaneous event ties and repeated bursts. Preserve resonator `q,v`;
account for every imposed hammer-state change, including kinetic/contact-storage
changes and action work. Require nonnegative contact force, branch-specific loss,
and convergent event times, impulse, rebound and cumulative energy residual under
`h,h/2,h/4`, with predeclared SI tolerances and positive energy scales.
