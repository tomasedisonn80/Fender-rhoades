# A080 — Sanitizer coverage and limits

**Coverage.** [CMake](../../../CMakeLists.txt) applies ASan/UBSan compilation
flags and frame pointers to the core, renderer, benchmark, and both test
executables; all four executable links request sanitizer runtimes. The
[sanitize preset](../../../CMakePresets.json) enables Debug/testing. Its 22
CTests exercise analytic/boundary, state, CLI, and benchmark-smoke paths,
without exhaustive execution coverage. [A078](A078.md) corroborates generated
flags but configured only; it did not run instrumented binaries.

**Failure policy.** [CI](../../../.github/workflows/ci.yml) sets
`UBSAN_OPTIONS=halt_on_error=1:print_stacktrace=1` and runs
`ctest --preset sanitize --no-tests=error`, making detected UB and an empty
suite failures. Local preset invocation alone lacks both policies. The
[CLI rejection helper](../../../tests/cpp/expect_cli_failure.cmake) requires
status 2 plus `rhodes_render:` diagnostics, preventing generic crashes from
passing. C++ test failures throw and return status 1.

**Observed boundary.** The integrator reports hosted Linux ASan/UBSan success
at `b66bd5ce2e8b1df5d43db03330b6b9a08629cb61`; I did not execute or independently
inspect that hosted run. Compiler-family guards do not probe runtime
availability. Windows disables the preset; MSVC/clang-cl opt-in is rejected;
macOS has no sanitizer job. Clang, AppleClang, minimum-version combinations,
and actual unsupported-driver rejection remain unverified here. Remaining
external matrix jobs require their own commit-specific conclusions.

**Limits and handoff.** No explicit leak option or leak self-test establishes
leak coverage independently of runtime defaults. A clean sanitizer result
does not establish allocation-free callbacks, race/lock freedom, real-time
deadlines, or physical fidelity. Sanitized benchmark smoke is not release
performance evidence. Next: standardize local failure policy, record leak
behavior, validate missing toolchains, and measure allocation/locking/timing
separately, following [development guidance](../../DEVELOPMENT.md).

**Work performed.** Read-only source/document inspection; no build, test,
state, or Git commands. Only this report changed.
