# A081 — Independent integrated modal pickup and network regression

**Result.** Added `review.engine_combined_pickup` to close the specific engine-output
oracle gap identified in [A079](A079.md). The regression exercises
`ResearchEngine::process` in [review_regression.cpp](../../../tests/cpp/review_regression.cpp).
It does not change the production implementation or establish physical fidelity.
[CMakeLists.txt](../../../CMakeLists.txt) registers one additional case; the
[A078](A078.md) sanitizer compiler guard remains unchanged.

**Independent contract and fixture.** At 48 kHz, keys 0, 3, 4, 37, and 72 receive
initial intensities 0.81, 0.57, 0.69, 0.93, and 0.76. These include two sources in
the first four-branch group, the first key beyond that group, and two later
three-branch groups. Warmups of 31, 113, and 257 samples provide distinct phases.
After each warmup, one sample is checked, keys 3/4/72 are retriggered at
intensities 0.23/0.31/0.17, and the immediately following sample is checked.
The six observation indices are 31, 32, 146, 147, 405, and 406. Every excited
mode must have nonzero displacement and velocity above explicit fixture floors.

For each observation, the test snapshots all 219 modal states **before** processing
one output sample. It independently reconstructs local displacement and velocity
using the documented weights `(1, 0.3, 0.08)` and evaluates the expanded derivative
of `lambda(x) = 0.4*x + 800*x^2 + 400000*x^3`, including its negative EMF sign.
These synthetic constants come from [NUMERICS](../../NUMERICS.md); the oracle
does not call `PolynomialPickup` or `SyntheticResistiveHarp`. It solves each
parallel group by conductance/KCL, adds the 24 equivalent sources and series
resistances, and applies the 1 Mohm load. All 73 branches contribute their
200 ohm resistances, including the 68 silent branches and wholly silent groups.

The output tolerance is `2e-14 + 2e-12*abs(expected)` volts. A deliberately wrong
prediction applies the nonlinear conversion separately to each weighted mode
and then sums the results. Every observation must distinguish this alternative
by more than 1 microvolt and one million times the comparison tolerance.

**Observed verification.** The existing `build/release` configuration uses GNU
C++ 14.2.0 on Linux, Release `-O3 -DNDEBUG`, warnings as errors, and no sanitizers.
The following commands succeeded:

```sh
cmake --build build/release --target rhodes_review_tests --parallel 2
ctest --test-dir build/release -R '^review\.engine_combined_pickup$' --output-on-failure --no-tests=error --verbose
```

The selected CTest case passed **1/1**, with six observations. Its diagnostic
reported maximum absolute output error `1.00323e-17 V` and minimum separation
from the separately converted prediction `0.000258287 V` (about 258 microvolts).
No broad suite, sanitizer execution, other-platform build, or production-source
mutation was performed. The alternate prediction demonstrates fixture sensitivity
without modifying the shared engine.

**Scope and handoff.** This is a numerical integration regression for the current
synthetic polynomial, observation weights, and resistive topology at one sample
rate. It neither validates the state-query implementation independently nor
establishes measured pickup parameters, specimen wiring, contact mechanics,
reciprocal electromagnetic forces, or antialiasing. It does not by itself complete
all PHY-001 acceptance criteria. The integrator can register this evidence with
its stated scope and include the new case in subsequent normal verification.
Changed paths are this report, the regression source, and `CMakeLists.txt`;
this work did not modify headers, production source, or canonical state, and
no Git commands were run.
