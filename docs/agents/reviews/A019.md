# A019 — Pickup topology and branch membership

**Finding:** The [implementation](../../../src/research_engine.cpp), [header](../../../include/rhodes/research_engine.hpp), and [numerical contract](../../NUMERICS.md) consistently reduce the synthetic 4+23×3 series/parallel candidate with equal branch resistances. Zero-source branches retain impedance. However, the coefficients distinguish only keys 0–3 from the remaining keys; regrouping those remaining keys into different triples leaves this equal-impedance output unchanged. Voltage agreement therefore cannot establish actual membership. The [research brief](../../research/USER_RESEARCH.txt) supplies a documentary candidate, while the [inventory](../../../profiles/mark-i-stage-73/components.json) leaves wiring and coil parameters unknown. The pickup derivative's global minus sign establishes a numerical convention, not measured terminal polarity.

**Required metadata:** Add a versioned specimen netlist containing every pickup's unique ID, physical-key mapping, both terminal nodes, group membership and series orientation, source-voltage reference direction, winding/magnet polarity evidence, and connected/fault status independent of mechanical activity. Attach configuration revision, photographs/continuity records, impedance measurement IDs, frequency/temperature range, uncertainty, and specified cable/load boundary. Require complete, nonduplicated membership for all 73 pickups; retain stationary sources as connected branches. Verify the graph on the specimen before promoting the candidate to identified topology.

**Hand-computable asymmetric fixture:** Use three parallel synthetic branches with signed sources $(3,-3,0)$ V and resistances $(100,200,300)$ Ω, driving $R_L=600/11$ Ω. Conductance summation gives

$$R_g=600/11\ \Omega,\qquad E_g=R_g(3/100-3/200)=9/11\ \mathrm V,$$

so $V_L=9/22$ V. Removing the stationary third branch incorrectly changes output to $9/20$ V. Unweighted averaging incorrectly predicts zero. Reversing the second source to +3 V gives $27/22$ V, exposing polarity mistakes. Even open-circuit terminal loading permits internal branch currents.

**Handoff:** Implement this independent reference fixture when unequal impedances/netlists are introduced, then extend to measured complex impedances. Review used file reads and analytic derivation only; no executable tests or physical verification were performed.
