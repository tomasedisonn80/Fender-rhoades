## Format and numerical bounds

The writer correctly describes mono IEEE binary32: tag 3, 18-byte `fmt`,
`cbSize=0`, four-byte block alignment, byte-rate `4Fs`, and four-byte `fact=N`.
Fields and bit-cast samples are explicitly little-endian. RIFF size `50+4N`
equals file length minus eight; every chunk has even length. This matches
[Microsoft's format fields](https://learn.microsoft.com/en-us/windows/win32/api/mmreg/ns-mmreg-waveformatex),
[RIFF size rules](https://learn.microsoft.com/en-us/windows/win32/xaudio2/resource-interchange-file-format--riff-),
and [ITU-R BS.1352-4](https://www.itu.int/dms_pubrec/itu-r/rec/bs/R-REC-BS.1352-4-202305-I!!PDF-E.pdf),
Annex 1, Attachment 1, sections 3.1–3.2, on extended formats and sample counts.
Reader acceptance was not used as compliance evidence.

Finite seconds are restricted to 0.01–60 and rates to 32,000–192,000 Hz.
`llround(seconds*Fs)` quantizes duration within half a frame; the maximum
11,520,000 frames occupies 46,080,058 bytes, safely within 32-bit chunk limits.
Nonfinite/out-of-binary32-range samples are rejected before conversion.

## Confirmed defect and minimal correction

`exists(output)` followed by truncating `ofstream` opening (lines 123–136)
does not enforce exclusive creation. A dangling symlink passes the existence
check and its target is created without `--force`; a concurrent file creation
can also be overwritten. `--force` follows existing symlinks. Rendering directly
into the destination exposes partial files and destroys prior contents before
success. Flush is checked, but close failure is not.

Use exclusive, no-follow creation for new outputs; preferably stage in an
exclusively created sibling temporary file, explicitly close/check it, and publish
with atomic no-replace semantics unless `--force` authorizes replacement. Reject
symlink destinations, clean temporary files on failure, and avoid check/open races.

One temporary probe ran `build/release/rhodes_render --output link.wav --seconds
0.01 --sample-rate 48000`, with `link.wav` dangling: exit 0, target created.
Independent byte parsing found 1,978 bytes, RIFF 1,970, `fact=480`, data 1,920,
and 480 finite floats. Temporary files were removed. Existing CLI tests lack
header, symlink, preservation, and write-failure assertions; add these focused
regressions. These are serialization/safety findings, not voltage calibration or
hardware-fidelity evidence; monitoring gain and synthetic parameters remain explicit.
