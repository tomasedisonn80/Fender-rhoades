# A069 — Generated documentation and integrity review

Reviewed `AGENTS.md`, canonical state and overview documents, `tools/project.py`,
`tools/campaign.py`, `tools/check_docs.py`, related Python tests, and CI configuration.

**Determinism and authority.** Canonical JSON owns status and evidence;
`PROJECT_STATE.md` is a projection. `render_state()` calls
`ready_tasks(include_claimed=True)`, avoiding current-clock lease filtering.
Consequently, passing a lease deadline does not invalidate the generated document
or complete a task; `next` determines current availability. State generation sorts
tasks and preserves recorded timestamps. Existing tests cover stale-document
rejection and recovery after state commits but document generation fails.

**Campaign consistency and recovery.** Completed reports must remain regular,
nonsymlink files with matching SHA-256 digests. Validation precedes rendering, so
`sync` cannot silently bless changed report content. Ledger and Markdown replacement
are individually atomic, not one transaction. After interrupted generation, validate
canonical inputs and run the corresponding `sync`; inspect any project lock first.
For report corruption, restore the recorded bytes and publish a separate correction,
rather than changing its registered hash.

**Specific gap.** At inspection, CI runs campaign validation without
`--require-complete`, and no campaign-specific unit tests existed. A partial ledger
therefore passes CI. This is intentional during setup checkpoints; final closure
should require all requested assignments and add regressions for changed hashes,
missing reports, deterministic rendering, and stale-index recovery. The integrator
has scheduled that follow-up; it is not completed by this review.

**Checker boundary.** Markdown checks cover supported local destinations, containment,
ordinary fences, and final newlines. They do not verify heading fragments, reference
label resolution, HTML/multiline links, remote availability, or example execution.
A green result cannot establish those properties.

**Actual verification.** One `python3 -B` isolated fixture passed: current state
Markdown matched rendering without lease evaluation; partial-campaign acceptance,
strict-completion rejection, hash-change rejection, and unchecked fragments were
confirmed. No full suite or remote CI was run. Only this report was changed.
