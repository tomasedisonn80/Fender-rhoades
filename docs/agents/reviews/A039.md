# A039 — Determinism and future persistence

**Current boundary.** The [API](../../../include/rhodes/research_engine.hpp) has no serialization or engine-state restore; `prepare` resets mechanics and pedal. [Numerics](../../NUMERICS.md) defines observation-before-advance and caller-split event boundaries. Fixed iteration order supports repeatable processing; transcendental libraries, compiler contraction/reassociation, floating-point environment and subnormal handling prevent assuming cross-platform bit identity. [Architecture](../../ARCHITECTURE.md) correctly calls for justified tolerances and independently versioned states.

**Persistence contract, proposed.** Distinguish session recall from ringing checkpoints. Session recall saves configuration and initializes its declared resting equilibrium. A checkpoint additionally retains every modal displacement/velocity, held-key flags, sustain, next-sample index and sample rate; future contact, circuit, oversampling/filter histories and random-generator state must join that inventory when implemented. Equilibrium origin and modal normalization belong to parameter identity: restoring coordinates against changed definitions is invalid.

Specify independent schema/model versions, stable key/mode/parameter IDs, configuration/asset hashes, field lengths, IEEE-754 numeric encoding and explicit byte order; never serialize C++ object memory. Validate finite values, dimensions, compatibility and integrity before atomic publication outside processing. Reject unsupported checkpoint rates without changing live state; any later rate migration needs its own validated mapping. Rebuild derived coefficients before installing dynamic state, without a subsequent reset.

**Continuation gate, proposed.** At 48 kHz, use a fixed integer-timestamp event script containing a held note, pedal-held released note and retrigger. Checkpoint immediately after 4,097 successful samples, before events/observation at sample 4,097. Restore into a fresh instance; replay identical remaining events with documented tie order. Require the next 96,000 output samples and all modal states to match uninterrupted execution bitwise under the same executable/floating-point environment, across block sizes 1, 64 and 257. Cross-platform runs require preregistered waveform/state tolerances and toolchain records. Corrupt, unknown-version, wrong-profile and wrong-rate checkpoints must reject atomically.
