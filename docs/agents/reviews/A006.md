No Git or canonical-state mutation was performed.

## Finding and resolution

Confirmed a real divider defect: `configure(1e300, 1e-20)` succeeded, but a source
array with index zero equal to `1e100` returned successful voltage zero. The
representable reference result is approximately `3.1578947368421053e-222` volts;
the resistance ratio overflowed. The integrator patched the core using bounded
mantissas and `frexp`/`scalbn`. The regression requires accurate nonnull results
for both polarities and a second case whose naive reciprocal ratio underflows.

Other checks cover 36 oscillator parameter combinations, including near-critical
damping and frequency/rate boundaries, against an independent scalar closed form.
Checks use absolute-plus-relative tolerances of `2e-14 + 3e-12*abs(q)` and
`2e-11 + 3e-12*abs(v)`. Rejected changes preserve subsequent trajectories exactly;
empty processing, zero-intensity release, all-notes-off, and pedal controls agree
with equivalent control trajectories. No undefined-behavior diagnostic occurred.
