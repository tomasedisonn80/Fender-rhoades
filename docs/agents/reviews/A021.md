# A021 — Connected passive Stage controls

**Finding:** The [architecture](../../ARCHITECTURE.md#pickup-network-and-passive-stage-circuit) requires connected controls, but the [inventory](../../../profiles/mark-i-stage-73/components.json) contains unknown `VOLUME`/`BASS-CONTROL` mechanisms assigned to `CIR-001`. [Roadmap Phase 3](../../ROADMAP.md#phase-3--keyboard-and-passive-stage-completeness) requires Stage controls without explicit control acceptance criteria. Assign a Stage-jack gate and preserve the separate loaded-harp configuration. The current mechanism inventory cannot establish a revision-specific circuit.

**Circuit-graph acceptance checklist:**

- Identify specimen and circuit revision; reconcile schematic designators against photographs and continuity records. Name harp, ground, jack, cable, and receiver nodes; record modifications and unresolved discrepancies.
- Record every volume/bass pot terminal, wiper connection, tied terminals, rotation direction, total resistance, measured taper versus knob position, endpoint residuals, and contact resistance where material. Declare whether each pot operates as divider or rheostat; handle ideal endpoint shorts without numerical singularities.
- Keep all pickup impedances connected. Solve controls, cable capacitance, and receiver impedance together; validate complex transfer and input impedance over combined control settings, including endpoints and held-out loads.
- Give each resistor, capacitor, and pot its own ID, nodes, SI values or explicit unknowns, uncertainty, provenance class, source locator/hash, measurement conditions, and evidence. Documentary values remain distinct from specimen measurements.

**Analytical test proposed, not executed:** Use a synthetic fixture with source impedance $Z_s$, series bass element $Z_b=R_b/(1+sR_bC_b)$, volume resistance $R_p$, and load $Z_L=(1/R_L+sC_L)^{-1}$. Let measured taper $a=g(x)$ select lower segment $aR_p$ and upper segment $(1-a)R_p$. Then

$$Z_p=(aR_p)\parallel Z_L,\qquad V_o/V_s=\frac{Z_p}{Z_s+Z_b+(1-a)R_p+Z_p}.$$

Compare the connected solver with this expression across frequency, taper positions, bass resistance, and loads. The lower endpoint gives zero; the upper endpoint retains source/bass loading, generally below unity at DC. This fixture specifies no historical values or specimen topology. Review used file reads and analytic derivation only.
