# A043 — Leases, file ownership, and handoff

Reviewed required project context, [workflow](../WORKFLOW.md),
[state format](../STATE_FORMAT.md), and
[project.py](../../../tools/project.py). Baseline: canonical revision 2;
`FND-001` belongs to `integration-root`. Owned output: this report only.

**Finding.** Claims coordinate task records; `paths` are validated scope hints,
without overlap detection or filesystem enforcement. `active_claim()` uses strict expiry:
at the expiry instant the lease is inactive. Renewal requires an active matching
owner/token and sets expiry from the current clock; an expired worker must
reclaim, receiving a new token. Expiry itself leaves canonical records unchanged.
The old token cannot update the task after replacement; neither expiry nor
replacement stops an editor, subprocess, or outstanding write.

`locked()` serializes cooperative CLI operations within one checkout using
`project/.project.lock`; it does not cover source edits or Git operations.
Separate checkouts have independent state and lock directories, so both can
claim the same task locally. Their tokens provide no distributed fencing.

**Concrete transition risk:** worker A pauses past expiry, B reclaims and edits
A's files, then A resumes and overwrites B despite rejection of A's state update.

**Safe handoff protocol.** The integrator should:

1. Obtain A's explicit stopped acknowledgment and confirm its writers/subprocesses
   have drained; expiry alone is insufficient.
2. Preserve A's diff and immutable report, record exact paths and baseline, and
   reconcile existing uncommitted changes before assigning B disjoint ownership.
3. Renew before expiry when retaining ownership; otherwise reclaim through one
   designated canonical checkout only after step 1. Give B the reconciled baseline.
4. Serialize canonical updates, staging, commits, and pushes; other checkouts
   submit reviewed changes instead of independently advancing authoritative state.

**Verification:** `python3 -B -` with in-memory module loading/assertions exited 0:
active immediately before expiry, inactive exactly at expiry, expired owner
rejected. No broad tests, concurrent-process experiment, or Git/canonical edits.
Next action: adopt this explicit reassignment handshake in integrator operations.
