# A047 — Units and provenance ingestion audit

**Scope.** Reviewed component inventory/schema, specimen fixture, acquisition schema,
validator, and measurement plan. Only this review was added.

**Sound boundaries.** Current component unknowns retain null value/uncertainty;
null denotes missing knowledge, never zero. Assumed, synthetic, documentary,
measured, and fitted entries require numbers. Documentary values require registered
sources; measured/fitted values require an identified specimen, same-specimen
fit-session references, and nonnegative uncertainty. Unknown mechanism source
links do not establish parameter values. `mixed_SI` is a null mechanism placeholder,
not a numerical container; COIL-RLC and TINE need separate unit-bearing scalars or
a new typed container contract before numerical ingestion. These boundaries agree
between the [component schema](../../../schemas/components.schema.json) and
[validator](../../../tools/validate_data.py).

**Mismatch: stale calibration cannot be checked.** The
[measurement plan, §2](../../MEASUREMENT_PLAN.md) requires calibration record/date,
but the [session schema](../../../schemas/measurement-session.schema.json) accepts
only calibration ID, method, reference, uncertainty, and unit. References are
nonempty text without record resolution, hash, instrument identity, or validity
interval. Additional date fields are rejected. A syntactically valid session can
therefore reuse expired or unrelated calibration metadata.

**Isolated reproduction.** Ran `python3 -B -` with
`tests/python/test_data.py` loaded through `runpy`, using its explicitly test-only
`measured_pair()`. Replacing the calibration reference with
`TEST-ONLY-expired-1990-no-resolved-record` passed; adding `valid_until` failed as
an unknown field. Unknown-with-zero, assumed-with-null, and numeric-`mixed_SI`
mutations were correctly rejected. No measurement files or broad suite were run.

**Next ingestion contract.** Add immutable calibration references/hashes, equipment
and configuration identity, calibration date, and validity at acquisition. Define
uncertainty interpretation and coverage, rather than only a nonnegative scalar;
retain its unit and derivation. Distinguish fitted parameters with method/version,
input hashes, objective, and covariance where relevant. Revalidate dependent fits
when calibration or configuration changes. These are future acquisition gates;
the present synthetic fixture establishes no physical calibration.
