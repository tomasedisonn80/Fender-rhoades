# A048 — Raw artifact verification boundary

**Assignment:** Audit raw integrity and import boundaries; owned path:
`docs/agents/reviews/A048.md`. Baseline: assigned working-tree files read directly,
without claiming a committed snapshot.

**Observed:** `tools/validate_data.py` explicitly never opens manifest payloads.
`validate_session` checks unique artifact paths, 64 lowercase hexadecimal SHA-256
characters, and positive integer byte counts. `validate_splits` compares declared
digests across provenance kinds/splits. These checks cannot detect missing files,
wrong sizes, corruption, or false digests. `safe_relative` rejects lexical traversal,
absolute paths, `.git`, backslashes, colons, and control characters; it does not
resolve paths or inspect symlinks.

`data/README.md` permits ignored `data/raw/` or approved immutable external storage.
`docs/MEASUREMENT_PLAN.md` requires storage locators, but artifact records contain
only `path`, `sha256`, and `bytes`; external location/root semantics need an explicit
contract. `docs/agents/STATE_FORMAT.md` distinguishes hashing local evidence
reports/manifests from fetching their referenced external payloads.

**Recommendation, not implemented:** Add optional
`validate_data.py --verify-payloads --payload-root DIR --report REPORT`. Define paths
relative to that explicit root; preserve existing metadata-only operation. Require
regular files, reject every symlink component, enforce root containment, and stream
SHA-256 plus actual byte counts from the same opened descriptor. Detect concurrent
mutation. Record manifest digest, verifier version, resolved location, observed
size/hash, and each failure in a new immutable report. Introduce storage-locator
metadata through a reviewed schema revision.

A future `import_raw.py --manifest MANIFEST --payload-root DIR --destination DIR`
must perform verification while staging bytes, then publish atomically without
overwriting existing observations. Missing, unreadable, changed, truncated, or
digest-mismatched files must return nonzero and prevent import/completion. Derived
files retain input hashes and processing provenance; clipped takes remain intact.

**Checks:** `cat`, `sed`, and `rg` inspection commands exited 0. No raw payloads
were inspected; no measurements or tests were run. Next: implement the opt-in verifier
and corruption/missing-file rejection fixtures under integrator ownership.
