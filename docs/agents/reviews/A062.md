# A062 — Absolute level, timing, and transient integrity

## Inspected

[NUMERICS](../../NUMERICS.md) defines loaded modeled volts, pickup polarity,
and observation at `t_n`; a strike can affect that timestamp's first sample.
[render.cpp](../../../apps/render.cpp) multiplies samples by `--gain` (default
8), writes float WAV without normalization or clipping, and reports gain to
stdout. The WAV header does not retain gain. This is a synthetic monitoring
convention, not calibrated instrument voltage. [VALIDATION](../../VALIDATION.md)
separates absolute level, timbre, and timing; [MEASUREMENT_PLAN](../../MEASUREMENT_PLAN.md)
requires calibration, polarity, synchronization, and immutable raw records.

## Proposed evaluator contract

Require specimen/configuration, output reference plane, load, input hashes,
channel calibration/polarity, clock mapping, bandwidth, and uncertainty. Compare
calibrated measured volts against engine volts or a render with recorded,
nonzero gain divided out; reject missing gain provenance and zero-gain renders
for quantitative recovery. Unit-labelled synthetic output cannot satisfy
hardware calibration.

Use a common physical trigger timeline. Permit only independently measured
acquisition offset/drift and declared filter latency corrections, frozen before
evaluation, with their uncertainty and transformations recorded. Do not optimize
per-note shifts, polarity inversions, phase rotations, or time warps against the
held-out waveform. Preserve uncorrected traces and report musical onset error
separately from transport delay.

Predeclare event-relative attack, sustain, retrigger, and release windows. Report
signed residual traces, voltage RMSE, peak/RMS level differences, and onset/release
timing errors per condition, retaining failed transients and noise-floor limits.
Set thresholds from acquisition uncertainty and repeatability.

Create separate timbre/listening copies using one documented positive gain per
comparison over a frozen window. Retain the same timeline and complete attacks;
prohibit envelope matching or transient trimming. A timbre pass cannot override
an absolute-level or timing failure.
