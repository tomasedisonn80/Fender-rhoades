# A045 — Stable data schema agreement

**Scope:** Independent audit of the specimen, measurement-session and components
schemas against `tools/validate_data.py`, committed fixtures and
`tests/python/test_data.py`. Project-state/evidence schemas were excluded.

**Finding:** A reproducible lexical mismatch remains. Appending one LF (`\n`) to
the committed fixture's `profile_id`, `session_id`, or first component `id`
passes its JSON Schema but is rejected by the corresponding Python validator.
The measured test-only fixture's SHA-256 value, `"a" * 64 + "\n"`, similarly
passes the session schema while Python reports `artifact: invalid SHA-256`.
Schema patterns end in `$`, which permits a match before a final newline in the
tested engine; Python uses `fullmatch`. This affects schema-only producers and
editor validation, although the repository validator rejects these records.

**Scoped fix:** Tighten identifier and digest patterns to require the absolute
end of input, for example replacing the final `$` with `(?![\s\S])`, then add
final-newline negative fixtures. Existing `test_schema_documents_have_exact_field_contracts`
checks top-level field sets, not schema execution or semantic agreement. A
small optional schema-conformance check would expose this drift without adding
a runtime dependency.

**Verification performed:** One `python3 -B -` here-document used the already
installed `jsonschema` 4.26.0, `Draft202012Validator`, `FormatChecker`, and existing
test fixture helpers. All three schema documents passed `check_schema`; their
unchanged fixtures passed both schema and executable checks. The four mutations
above reproduced disagreement. A separate timestamp-offset mutation within that
same invocation was accepted by both and established no parity counterexample.
No full suite was run and no dependency was added.

**Semantics and limits:** Schema comments correctly reserve repository references,
unique IDs, calibration-unit agreement, same-specimen fit-only parameter sources,
and condition/hash split checks for Python. Relevant negative tests exist; this
audit inspected them without claiming execution. Null unknown parameters,
synthetic-only development data, and scalar uncertainty agree across contracts.
As documented in the validator and measurement plan, manifests do not verify
artifact bytes, authenticity, or physical accuracy; the mechanism inventory is
not a circuit BOM. Passing these checks cannot complete actual acquisition.

**Changed path:** This report only. **Next action:** Integrator schedules the
pattern correction and focused regression coverage.
