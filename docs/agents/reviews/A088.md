# A088 — Malformed metadata and path boundaries

**Scope.** Inspected `tools/project.py`, `validate_data.py`, `verify_payloads.py`,
`campaign.py`, related Python tests, and the documented trust boundary. This is a
bounded robustness review, not an authenticity or hardware-validation claim.

**Confirmed defects.** Three small cases used one disposable temporary root;
canonical files were only read. With `project/state.json` containing the single
byte `0xff` and an empty valid evidence registry,
`python3 tools/project.py --root TEMP validate` exits 1 with an uncaught
`UnicodeDecodeError`. Replacing the state with a valid copy whose first task has
`paths: ["bad\u0000path"]` produces an uncaught `ValueError` from `Path.resolve()`.
Both should become the CLI's normal diagnostic and exit 2. Both removed their
temporary lock; the invalid UTF-8 input remained unchanged.

The isolated campaign validator accepted
`{"schema_version":1,"requested_agents":1,"requested_agents":2,"agents":[],"extra":NaN}`,
returning 0 and reporting two requested agents. Its plain `json.loads` silently
chooses the last duplicate key and permits nonfinite constants in extra fields.
Use strict duplicate/nonfinite rejection consistently across the tools; this is
an ambiguous-input acceptance defect, not evidence of fabricated assignments.

**Existing protections.** Project artifacts resolve within the checkout, exclude
mutable state/dashboard/registry files and locks, and are rehashed. Campaign
reports have fixed names, containment checks, and stored hashes. Data and payload
parsers reject duplicate keys, nonfinite values, and invalid object/artifact
shapes; existing tests cover these cases, but were inspected rather than rerun.
The payload verifier rejects symlink/reparse components, checks descriptor and
pathname identity, and publishes without overwriting an existing report.

**Limits and next step.** Standalone metadata discovery trusts checkout parents;
the payload verifier explicitly requires trusted, quiescent directories and does
not promise protection against adversarial directory races. Metadata and recorded
commands remain data: no supplied command execution or raw-payload fetching was
found. Authorized editors can rewrite reports and matching hashes; that is outside
the attestation guarantees claimed here. Add focused regressions for the three
observed cases, normalize parser/path exceptions, and retain these trust limits.
No broad suite, fuzzing, code change, canonical-state edit, or Git operation ran.
