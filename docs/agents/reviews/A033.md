# A033 — Long tails and subnormal-state policy

**Finding.** The [oscillator and sample loop](../../../src/research_engine.cpp) advance every mode indefinitely; no silence threshold or floating-point environment guard exists. Squaring velocity and frequency-scaled displacement can underflow before either state vanishes, so `energy_joules()==0` cannot establish mechanical rest. Tiny state increments can also disappear through rounding. These limits are acknowledged in [NUMERICS](../../NUMERICS.md), but uninterrupted tails remain uncharacterized. The [benchmark](../../BENCHMARKING.md) retriggers roughly every half-second; its silent baseline starts at exact zero. Neither workload specifically measures entry into subnormal arithmetic. [CMake](../../../CMakeLists.txt) specifies MSVC `/fp:precise`, but no equivalent explicit GNU/Clang floating-point contract or runtime flush-mode control.

**Recommended policy.** Keep a gradual-underflow reference with finite-value checks preserved; disallow fast-math assumptions there. Record effective compiler flags, contraction/rounding settings, and runtime flush-to-zero/denormals-are-zero modes. Any runtime mode change must be deliberate, scoped, and restore the caller's environment. Treat flushing, truncation, and sleeping as separate approximations. For the current synthetic engine, propose an initial gate of maximum absolute loaded-voltage error **≤10⁻¹² V** against that reference, including wake/retrigger samples; this is an engineering proposal, not an audibility result. Derive conservative state/envelope bounds through the polynomial pickup and complete harp weights before selecting thresholds. Retain state and elapsed time for phase-preserving advancement on wake; never use zero reported energy as a sleep predicate or remove silent pickup branches. Future coupling requires renewed bounds.

**Targeted follow-up.** Add a single-strike, no-retrigger tail workload covering held/sustained and released damping. Derive duration from the analytic envelope beyond predicted subnormal entry, then observe a bounded additional interval rather than assuming eventual exact zero. Record state classifications, zero-energy/nonzero-state cases, output error, and callback distributions by tail interval. Seed normal/subnormal boundary states for focused regression and wake/retrigger checks.

Source inspection only; no tests or timing experiments ran. No CPU penalty is asserted.
