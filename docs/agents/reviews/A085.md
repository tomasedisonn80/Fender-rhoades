# A085 — Benchmark reproducibility audit

Scope: source/document inspection only; no build, benchmark, or platform execution.

**Measurement boundary.** [Harness](../../../apps/benchmark.cpp) and
[method](../../BENCHMARKING.md) agree: 32 warmup blocks precede a mechanical reset;
deterministic held impulses retrigger about every 0.5 simulated seconds.
`steady_clock` brackets `process()` only. Preparation, strikes (including
damping-coefficient recomputation), checksum/peak scans, sorting and JSON are
excluded. Release/pedal/event bursts are absent. Inference: warm caches,
uninterrupted offline execution and intervening output scans can shape timings;
timer/scheduler overhead remains included. No measured overhead calibration,
cold-start distribution or host wake-up jitter is supplied.

**Work and optimization.** [Engine](../../../src/research_engine.cpp) traverses all
73 slots, three modes each, and the pickup network regardless of active count;
zero active keys tests silence, not zero processing. Active-key comparisons
cannot establish voice-count scaling. Observable sum-of-squares/peak consumption
resists dead-code removal, but does not establish correctness or portable bit
identity. Release/NDEBUG/compiler labels omit effective optimization,
architecture, LTO, floating-point and sanitizer flags.

**Inputs and repeats.** [CMake](../../../CMakeLists.txt)/[presets](../../../CMakePresets.json)
require C++20/CMake ≥3.24 and select configurations, not exact toolchains. Capture
source revision plus changes, compiler/linker commands, CMake/Ninja versions,
standard-library/libm/runtime versions, CPU/OS/kernel, power/thermal policy,
affinity/priority, competing load and floating-point mode. Retain independent
process repeats and raw JSON for declared rate/block/active-key matrices;
callback samples within one run are correlated. A free-text machine label is
unverified; platform macros and CI definitions are not platform results.

**Pinning and RT-001.** [CI](../../../.github/workflows/ci.yml) pins
checkout/setup-python action commits; `*-latest` runners, Python 3.11 patch
selection and runner compilers/tools remain floating.
[Dependabot](../../../.github/dependabot.yml) covers monthly action updates only.
No downloaded core packages removes one dependency boundary, not system-runtime
variability. [RT-001](../../../project/state.json) still needs representative
stressed workload timing/maxima/misses, allocation/locking verification,
independent optimized/reference errors and timestep/antialiasing convergence.
Observed maxima are samples, never worst-case bounds.
