# A038 — Reduced-model asset contract

**Finding.** [Architecture](../../ARCHITECTURE.md) separates offline compilation from immutable runtime configuration; [transduction](../../specs/TRANSDUCTION_NETWORK.md) requires smooth derivatives, validity cells and preparation validation. These remain requirements: the [component schema](../../../schemas/components.schema.json) describes mechanism requirements, the [profile](../../../profiles/mark-i-stage-73/specimen.json) remains unidentified, and [prepare](../../../include/rhodes/research_engine.hpp) accepts only sample rate. The [acquisition schema](../../../schemas/measurement-session.schema.json) explicitly leaves payload hashes unverified. No compiled-asset manifest currently closes this gap.

**Proposed manifest.** Require `schema_version`, `asset_id`, `asset_revision`, `asset_kind`, `payload_sha256`, `payload_bytes`, `payload_encoding`, `specimen_profile_sha256`, `configuration_sha256`, `source_records[{id,sha256,provenance,rights}]`, `compiler_commit`, `toolchain`, `solver_settings`, `fit_seed`, and `runtime_abi`. Hash canonical configuration including key mapping, circuit connectivity/polarities, load, output boundary, equilibrium and embedded magnetic contributions. Preserve synthetic/fitted/measured distinctions.

Add `coordinates` with frames, origins, SI units, axis scales, transform Jacobians, modal masses/normalization and participation/observation conventions; record whether winding turns are included. Add `domain` with supported cells, excluded regions, geometry/current/temperature ranges and explicit failure policy. A bounding box cannot certify holes. Add `reduction_validation` containing reference/configuration hashes, independent validation conditions, observable-specific absolute/relative limits, nonzero scales, achieved worst errors and evidence hashes. Separate reduction error from reference numerical error and measurement uncertainty; include derivative/reciprocity checks.

**Export and rejection.** Pin encoding, numeric precision, byte order, stable ordering and seed; exclude volatile timestamps from content identity. Two exports in the declared toolchain must match bytes; other toolchains require stated numerical tolerances. Preparation verifies actual bytes, finite coefficients, dimensions, versions, configuration compatibility, domain coverage and error budgets before atomically publishing an immutable configuration.

**Proposed gate.** Prepare a valid synthetic asset; then attempt replacement with (a) one payload byte changed and (b) an intact asset compiled for a different load. Both must return explicit rejection before publication, preserving existing state/output. No callback parsing or silent fallback.

**Verification:** source inspection and six local links checked; no runtime tests run. Next: implement the manifest and loader gate.
