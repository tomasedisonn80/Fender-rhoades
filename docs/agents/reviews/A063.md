# A063 — Frequency and decay evaluation

**Observed boundary.** [NUMERICS](../../NUMERICS.md) defines undamped natural frequency and amplitude decay coefficient; [VALIDATION](../../VALIDATION.md) requires condition-level errors. The [acquisition contract](../../specs/DATA_INGESTION.md) leaves calibrated measurements pending. These documents establish conventions, not observed evaluator performance.

**Proposed evaluator contract.** Accept immutable signal/configuration hashes, condition/partition IDs, calibrated units, output boundary, clock uncertainty, event times and estimator version. Freeze mode matching, event-relative windows, taper/normalization, noise estimator and censoring rules before final comparisons. Jointly estimate overlapping modes: beating minima are not additional damping. Report unresolved modes explicitly. Segment attacks, retriggers and damping switches; use time-local trajectories for nonstationarity rather than forcing one exponential. Record retained samples, fit residuals and censoring reasons; never fit logarithms below the estimated noise floor or extrapolate a censored tail silently.

Return signed frequency errors in Hz and cents, `1200 log2(f_prediction/f_reference)`, using positive frequencies with the same convention. Report damped frequency separately from inferred natural frequency, with conversion assumptions. Return decay coefficient β in s⁻¹ and amplitude T60 = ln(1000)/β, including infinity at zero damping. Squared-amplitude energy envelopes decay at 2β; instantaneous mechanical energy need not be exponential. Use 20 log10 amplitude and 10 log10 energy ratios for dB. Propagate clock, calibration and estimator uncertainty/covariance separately from repeatability. Report intervals, failures and errors for every condition; derive physical acceptance limits from the pilot, never a pooled score.

**Proposed reference fixture.** Independently synthesize eight seconds at 48 kHz:
`q(t)=10⁻⁴ exp(−0.5t) cos(2π440t)+8×10⁻⁵ exp(−0.8t) cos(2π442t+π/3)` metres.
Known damped frequencies and coefficients expose overlap, beating and late-tail censoring. Add Gaussian noise (PCG64, seed 63, σ=10⁻⁶ m) and a separate variant chirping the first mode at 1 Hz/s. Freeze generator/version, hashes and numerical recovery tolerances. Next step: implement this evaluator/fixture pair. This review used document inspection only; no experiment was executed.
