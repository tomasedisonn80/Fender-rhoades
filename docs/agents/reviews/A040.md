# A040 — Offline, runtime and host interface boundaries

**Finding.** [Architecture](../../ARCHITECTURE.md) assigns offline references and compilation separate responsibilities; hosts depend on the runtime API. [CMake](../../../CMakeLists.txt) keeps renderer I/O outside `rhodes_core`. The [API](../../../include/rhodes/research_engine.hpp) owns fixed mechanical state and borrows output storage, but `prepare(rate)` constructs synthetic parameters and `process()` exposes only Boolean failure. [NUMERICS](../../NUMERICS.md) documents partial advancement on failure; a host cannot identify its sample or subsystem.

**Missing artifact.** Add `docs/specs/RUNTIME_BOUNDARY.md`: a versioned interface contract for `PreparedModel`, `EngineState`, bounded events and fixed-size processing diagnostics. Declare source-record ownership in offline tooling, immutable prepared-data lifetime, exclusive per-instance dynamic state, and host-owned buffers/events. Fix dimensions and indexing for modal vectors, participation maps and all 73 pickup connections. Bind SI units, normalization, winding-turn inclusion, output reference plane and configuration identity. Consistent force/velocity and voltage/current port orientations must preserve the [transduction contract](../../specs/TRANSDUCTION_NETWORK.md); omitted reciprocal coupling requires a declared error envelope.

Preparation must validate complete candidates off callback, with explicit publication, reset and migration rules. Runtime may depend on the prepared-data interface, never offline solvers, parsers or host SDKs. Diagnostics need status, first failing sample, subsystem and recovery requirement in bounded storage; the host formats/logs them outside processing. Preserve the current zero-remainder/partially-advanced-state semantics unless explicitly versioned.

**Proposed acceptance example.** Prepare a synthetic 73-key model, then reject a replacement whose pickup projection dimension mismatches its modal state, preserving the original configuration and state. Inject a numerical failure at sample 17 of 64: require an explicit diagnostic, unchanged earlier output, zero samples 17–63 and reset-required status, with no callback allocation, logging or parsing.

**Verification:** source inspection and local-link checks only; no runtime tests run. Next: specify this boundary before implementing asset loading or host adapters.
