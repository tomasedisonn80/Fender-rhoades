# A086 — Provenance and rights audit

Reviewed `AGENTS.md`, `RIGHTS.md`, the root/research READMEs, input manifest,
source registry, archive, dependency declarations, and acquisition/privacy
guidance. This is a repository consistency review, not legal advice or a grant
of permission.

The archive clearly separates supplied historical research claims, including its
earlier 100-assignment claim, from this repository's work. The input manifest
records two transformations: a context preface and removal of the private PDF
link. `sha256sum docs/research/USER_RESEARCH.txt` matched the archived digest
`a869daab3d3153c123a6165dfa16e00a7f64877858f8927604c6f66554a593dc`.
The original attachment and separate PDF were not inspected in this audit, so
the original digest and transformation history were not independently reproduced.

The registry labels five sources `reviewed` and fourteen `supplied_unreviewed`;
all are `link_only`. These labels describe prior inspection, not reuse rights or
validated measurements. **Exact tracking gap:** the archive cites David Morrin's
Stage-circuit measurements at line 216, the MNA reference at 278, PLECS at 301,
the energy-method paper at 333, and DDSP at 402, but none has a registry entry.
Add these as supplied leads with unresolved review status before relying on them.

`CMakeLists.txt` links project targets only; inspected C++ includes and Python
imports are local or standard-library references. No imported implementation or
figure was observed. This supports the declared dependency boundary without
certifying every line's origin. No project-wide license has been selected;
`RIGHTS.md` correctly reserves that decision and release identity to the owner.
Any future license must preserve separate third-party asset permissions.

Acquisition guidance requires recording/photo rights and keeping identifying
owner information private unless publication is authorized. Instrument access
alone supplies no recorded permission. Fender/Rhodes names are identification
references; independence language does not authorize logos or endorsement claims.

Only this review was written. Checks were document reads, targeted searches, and
the archive hash; no broad tests, state changes, or Git operations were run.
