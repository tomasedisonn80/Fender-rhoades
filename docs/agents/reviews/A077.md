# A077 — macOS portability review

Reviewed `AGENTS.md`, project context, `CMakeLists.txt`, `CMakePresets.json`,
`.github/workflows/ci.yml`, `docs/DEVELOPMENT.md`, CLIs, and relevant Python tests.
This is Linux-hosted static inspection; no macOS execution is claimed.

**Toolchain and architectures.** AppleClang receives the non-MSVC warning and
sanitizer options. Both CLIs use floating-point `std::from_chars`; record the
AppleClang/libc++ versions that actually build them. C++20 mode alone does not
identify that library version. Neither CMake nor CI explicitly selects
`CMAKE_OSX_ARCHITECTURES`; the single `macos-latest` job cannot establish separate
arm64 and x86_64 coverage. Test each intended architecture before claiming both.

**Filesystem and Python.** `tests/python/test_payloads.py` resolves its temporary
root specifically for macOS system symlinks; `test_docs.py` and `test_campaign.py`
also resolve theirs. Preserve this because `tools/verify_payloads.py` deliberately
rejects every symlink ancestor. Subprocess tests use `sys.executable`, and
`tools/validate_data.py` uses `PurePosixPath` for serialized paths. Static inspection
established no remaining macOS-specific Python blocker. Capability-dependent
coverage remains: `test_payloads.py` skips unavailable symlink/hard-link operations
and replacement of open files; other symlink fixtures also skip unsupported hosts.
Review skipped tests when expanding contracts CI. No tracked case-fold filename
collisions were found. Case-insensitive filesystem aliases still merit targeted
checks: `tools/project.py` excludes `.git` and mutable artifacts using path
comparisons, while `tools/check_docs.py` checks target existence without enforcing
directory-entry spelling.

**Numerics and sanitizers.** `apps/render.cpp` explicitly requires four-byte IEC
559 floats and writes little-endian bytes. Preserve numerical tolerances across
architectures. The sanitizer preset excludes Windows but does not probe compiler
or runtime availability; sanitizer CI currently targets Ubuntu only.

**Verification and handoff.** `python3 tools/project.py validate`, `sync --check`,
and `next --json` exited zero; a tracked-path case-fold scan found no collisions.
Only this report changed. Next: run the proposed Python matrix and record actual
