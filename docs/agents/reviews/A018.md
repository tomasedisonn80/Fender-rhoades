# A018 — Magnetic field-map contract review

**Finding.** [Architecture](../../ARCHITECTURE.md#magnetic-conversion-and-reciprocity),
[validation](../../VALIDATION.md#analytic-and-primitive-behavior), and the
[measurement plan](../../MEASUREMENT_PLAN.md#c-magnetic-geometry-and-electrical-conversion)
correctly distinguish linkage, reciprocal force, and measured validity. The remaining
gap is an enforceable map-asset contract. Require at least continuous first
derivatives of linkage across interpolation cells; require continuous second
derivatives when solver Jacobians depend on them. Compute derivatives from the
same interpolant, including normalization and coordinate-transform Jacobians.
Independently interpolated gradient tables can contradict the stored linkage.

**Proposed asset-domain contract.** Record version/hash, specimen/configuration,
coordinate origin, right-handed axes, winding polarity, linkage units (V·s,
turns already included), and every axis’s units and normalization. Declare
translation coordinates in metres, orientation parameterization and angular
units, and any distributed-deformation coordinates; omitted dimensions need
an error envelope. Store inclusive bounds, supported cells, excluded regions,
and applicable current/temperature/load conditions. A bounding box alone cannot
certify holes in measured support. Reject invalid assets at preparation;
out-of-domain evaluation returns a bounded status and exposes a diagnostic,
with only an explicitly named, separately evaluated fallback. Include dataset
hashes, calibration covariance, repeatability, interpolation error, derivative
uncertainty, and whole-condition holdouts. Voltage/motion data constrain linkage
gradients, not its additive constant or zero-current attraction; force observations
and compatible co-energy constraints remain separate requirements.

**One manufactured-map test.** Use synthetic scales ℓ (m), Λ (V·s), E (J), L (H),
normalized X=x/ℓ, Y=y/ℓ on [-1,1]², and θ∈[-π/6,π/6] radians. Define
λpm=Λ(X³+XY+sin θ) and co-energy W′=−EX²/2+iλpm+Li²/2.
Sample, interpolate, and refine this map. Compare analytic linkage, pose
gradients, −∇λpm·pose_velocity, and force/torque ∂W′/∂pose along trajectories
crossing cell seams. Check mixed-current reciprocity, zero-current force,
orientation sensitivity, boundary acceptance, and immediate outside-domain
rejection. Freeze numerical tolerances before execution; this proposed test
supports numerical consistency only.

**Verification and next step.** Documentation inspection only; no numerical test
was run. Implement the schema and manufactured-map fixture before compiling
measured assets.
