# W1-003 — MIDI playability audit

Scoped reviewer; baseline `20a77e8b2033d435839df594c783837befb07938` on `main`. Only this report changed; Git and canonical state remain integrator-owned.

## Findings

- Ownership is coherent: 256 fixed holders, channel-scoped identified IDs, counted anonymous notes, zero-velocity release, last-holder physical release, and transactional rejection (`include/rhodes/note_tracker.hpp:54–116`). Retrigger adds an impulse to existing motion; release changes damping (`src/research_engine.cpp:399–445`). Sustain is intentionally shared across channels.
- **Highest-value safe feature: per-channel CC123.** The helper already supports channel release, but `plugins/vst3/controller.cpp:75–83` maps only CC64. CC123/120 omission is explicit existing scope, not a broken documented promise (`docs/specs/HOST_PROTOTYPE_20261123.md`, MIDI ownership section).
- **Compatibility risk:** `plugins/vst3/processor.cpp:230–243` rejects every non-note event, including valid polyphonic pressure. Whole-block rejection at lines 335–338 consequently discards co-batched note-offs and preserves previous holders. This is source-verified, not a reproduced DAW observation. Safely accepting validated pressure as an ignored event deserves a separate regression.

## CC123 implementation requirements

Use one mapped command ParamID per channel, with every delivered point triggering release—including zero and repeated identical values. Avoid rising-edge/value-change detection. Merge commands with notes chronologically during candidate ownership preflight; retain parameter-before-note ties and declare ordering between channel queues. Emit ordinary note-offs from `release_channel`, preserving shared sustain, modal tails, and other-channel holders. Preflight expanded event capacity without truncating releases.

Exclude commands from the existing sixteen-byte gain/sustain state; no migration is needed. Do not use `kIsHidden`: pinned SDK `ivsteditcontroller.h:90–92` makes hidden parameters externally unchangeable/read-only. SDK mapping documentation does not establish that every DAW preserves repeated identical controller messages; verify actual delivery before claiming host coverage. Keep CC120 separate because channel-specific silencing conflicts with shared physical-key motion.
