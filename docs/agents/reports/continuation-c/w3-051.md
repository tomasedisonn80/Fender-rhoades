## Evidence qualification and optional coverage

Do not cite audio equality alone as proof of sustain-before-release *call order*:
`ResearchEngine::set_sustain`/`note_off` only select damping before advancement,
so reversing those equal-offset setters is observationally equivalent here.
`processor.cpp` directly establishes the required order.

Optional hardening: snapshot channel-pointer slots before processing and add
buffer canaries. Current sentinel checks cover absent storage, not pointer-slot
immutability or out-of-bounds writes. Neither is an observed defect.
