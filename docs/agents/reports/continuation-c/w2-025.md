Changed `tests/cpp/vst3_control_text_test.cpp` and this report only. One main
exercises both public `IEditController` text APIs for all 18 parameters and all
three compile-time state-model identities. No CMake, Git or project-state edits.

Coverage includes strict ASCII decimals, signs/exponents/whitespace, gain-only
`x`, parsed-binary64 bounds before canonical binary32 gain, independent literal
bit expectations, sustain threshold/labels, command binary64 round trips,
negative/positive subnormals, overflow/underflow, junk/nonfinite input, malformed
UTF-16, nulls, the 127/128 terminator boundary, invalid IDs and lifecycle states.

formatting checks the entire output buffer and guards. Final valid recalls
preserve all transient commands and the 16-byte configuration format.

Numeric formatting is checked for finite ASCII syntax and value round trips;
only sustain requires exact `Off`/`On` spelling, following the integrator's
clarification. Tests preserve and check floating-point control bits while
allowing library sticky-status changes.
