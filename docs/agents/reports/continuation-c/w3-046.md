# Worker 046 — HOST-MIDI archive integrity verifier

**PASS: retained archive byte integrity and manifest consistency.** Added
[`verify_host_midi_archive.py`](../../../../tools/verify_host_midi_archive.py),
with `verify_archive(root)` and a `--root` fixture option.

The independent readback uses bounded zlib decompression and raw 512-byte USTAR
headers. It checks exact typed inventory fields, duplicate/nonfinite JSON,
canonical content-addressed regular members, order, checksums, padding, zero
timestamps/ownership, per-blob sizes/hashes, unique original-path mappings,
aggregate/worker/suffix counts, exclusions and referenced report fingerprints.
Links, unsafe paths, unexpected members, trailing tar/gzip data and changing input
file identities are rejected. Member sizes are checked before payload reads.
Nothing is extracted or executed.

Limits: 2 MiB manifest, 16 MiB compressed archive, 32 MiB uncompressed archive,
4 MiB per blob/report, 2,048 blobs and 4,096 originals. Report reads also have
count and aggregate-byte bounds.

Actual commands, all exit zero:

```sh
python3 tools/project.py validate
python3 tools/project.py sync --check
python3 tools/project.py next --json
python3 -B tools/verify_host_midi_archive.py
```
