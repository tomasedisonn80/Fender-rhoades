**Verdict:** The qualified host-delivery conclusions are supported. No behavioral

**MIDI semantics.** The [MIDI Association table](https://midi.org/midi-1-0-control-change-messages)
identifies CC123/All Notes Off, CC120/All Sound Off, CC64/damper, and CC123's zero
data value. It does not specify sustain priority or release tails. The official
[detailed-specification landing page](https://midi.org/midi-1-0-detailed-specification)
identifies M1 v4.2.1/1996, but its Drive download did not expose PDF text through
web retrieval. Independently inspected
[Roland FA-06/07/08 MIDI Implementation](https://static.roland.com/assets/media/pdf/FA-06_07_08_MIDI_Imple_eng01_W.pdf#page=5),
version 1.01, June 1, 2017, sound-source reception pp. 4–5: CC120 silences sounding
channel notes; CC123 retains sound while Hold 1/Sostenuto remains on. This supports
the distinction as manufacturer practice, not universal normative proof. Shared
sustain, mechanical state and convolution-tail preservation remain this project's
explicit design contract.

**Mapping versus automation.** The pinned
[interface](https://github.com/steinbergmedia/vst3_pluginterfaces/blob/4f547e8e102b47de4a8b8aaf343c73b700786372/vst/ivsteditcontroller.h#L65-L95)
separates `kCanAutomate`, read-only and hidden flags; `IMidiMapping` supplies
bus/channel/controller assignments. Writable `kNoFlags` commands are consistent
with these definitions. Neither inspected host mapping path tests automation
permission.

**Repeated/default-zero delivery.** JUCE appends mapped points before cache updates,
retains same-offset duplicates, and limits conversion to 2048 messages. AudioHost
retains equal values at distinct offsets, replaces same-offset points and clears
reused queues. Neither traced path deduplicates against default/prior-block zero.
The pinned [queue contract](https://github.com/steinbergmedia/vst3_pluginterfaces/blob/4f547e8e102b47de4a8b8aaf343c73b700786372/vst/ivstparameterchanges.h#L36-L55)
permits constant-curve omission; universal per-message retention is not established.
