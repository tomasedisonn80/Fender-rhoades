## Changes

literal after a three-digit octal control escape when the next character is a
decimal digit. Adjacent string literals preserve the input bytes while avoiding
MSVC C4125 with warnings treated as errors. Regeneration changes five literal
boundaries in `tests/fixtures/control_text_vectors.hpp`, including
`"1\011" "0"` and `"\000" "1"`. No warning suppression or dependency was added.
