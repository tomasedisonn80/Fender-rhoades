# W3-059 — Callback boundary review

Static review only; no tests or timings rerun. Read the operating guidance,
HOST_MIDI contract, current implementation and existing calibrated tests.
No callback-boundary defect found.

- `control_text.hpp` uses bounded integer/fixed-array conversion (127-byte input,
  80 limbs). Its production callers are exclusively controller text methods;
  controller construction, parameter registration and SDK notifications are
  outside `process()`.
- `processor.hpp/.cpp` stages inputs in instance arrays. Raw caps are checked
  before point/event traversal: 18 queues, 8192 gain points, 8192 sustain points,
  256 aggregate commands and 256 events. Duplicate points still consume raw
  budgets. Insertion sort has at most 32,640 shifts. Ownership scans have 256
  holders/73 keys; expansion has 585 slots and a checked append. Preflight
  enforces 256 actions per sample, including sustain, before committing.
  Rendering/cleanup traverse at most 8192 frames and two channels. Local copies
  are fixed-sized; this is not a stack-budget certification.
- `BasicEventProcessor::release_key` rejects invalid keys before engine access
  without changing state; valid-release failure latches the fault and preserves
  partial state. Subsequent releases, sustain and processing remain fenced until
  reset/valid preparation. Zero-frame processor branches inspect bus metadata,
  never sample pointers, and releases do not advance mechanics/cursor/history.
- `StateMailbox` requires always-lock-free uint64 atomics and uses one-shot CAS,
  with no retry loop. Reviewed production paths contain no explicit allocation,
  blocking primitive or throw. SDK bus lookup's `at(0)` is size-guarded under the
  synchronized-lifecycle contract. Host queue/event getters remain foreign calls;
  throwing through the noexcept collectors terminates, rather than becoming
  atomic rejection.
- `vst3_host_test.cpp` calibrates eight replacement-new forms and guards only
  actual process intervals. W2-032 records 150 calls per variant, both formats,
  48/96/192 kHz; W2-022 records the separate release probe. These fixed-host
  observations do not intercept arbitrary malloc, prove foreign-call behavior,
  bound scheduling/page faults, or establish DAW/device deadlines, WCRT or RT-001.
