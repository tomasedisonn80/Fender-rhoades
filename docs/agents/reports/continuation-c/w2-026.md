# W2-026 — Portable control decimal conversion

## Changed paths

- `include/rhodes/control_text.hpp`
- `docs/agents/reports/continuation-c/w2-026.md`

Added dependency-free, bounded UI helpers in `rhodes::control_text`:
`parse_decimal(string_view)` and `format_decimal(double, span<char>)`.
No controller, core, CMake, deployment-baseline, Git or canonical-state edits.

Parsing validates complete signed ASCII decimal text of at most 127 bytes,
constructs an exact integer ratio, finds its binary exponent, and divides to
a 53-bit significand with exact remainder-based nearest-even rounding. It rejects
rounded magnitude above 32 and nonzero input rounding to zero. Negative values
and signed zero remain available for the controller's domain/canonicalization
checks. Huge exponents saturate safely; exact decimal zero remains accepted.

Formatting constructs the exact decimal coefficient using powers of five,
rounds to at most 17 significant digits, strips trailing zeros, and uses fixed
notation for decimal exponents -4 through 1. Both zeros display `0`. The returned
byte count excludes NUL; 24 bytes suffice. Staging preserves every destination
byte on failure. Eighty integer limbs cover the 2547-bit formatting maximum and
1496-bit parser intermediates. No floating arithmetic, charconv, locale, heap
or runtime floating-control changes.
