# W1-017 — Public controller text oracle

Read required project documents, [HOST_MIDI](../../../specs/HOST_MIDI_20261124.md), controller implementation, controller/FP tests. Design only; no tests run.

Exercise public text APIs across all three variants; hard-code independent expectations.

- Accept `0→0`, `+16→0.5`, `32→1`, `-0→+0`, surrounding six ASCII whitespace characters, and `16x→0.5`.
- Freeze scientific grammar: recommend `1.6e1→0.5`, `3.2E+1x→1`; reject `1e`, `1e+`, standalone/repeated signs.
- Reject `nan`, `NaN`, `inf`, `-Infinity`, `0x10`, `16junk`, `16xx`, empty/whitespace, `1,6`, NBSP, Unicode digits/minus, isolated surrogates.
- Reject `-0.0001`, `32.0000001`, `32.0000000000000001`, `1e999`, `-1e-999`; do not let rounding move out-of-range decimals inside.
- Test the declared UTF-16 scan bound: terminator at last permitted position versus entirely unterminated storage, guarded against overreads; null text pointers reject.
- Independently check numeric display endpoints/midpoint as 0/16/32; metadata retains unit `x`.
- Sustain: `Off→0`, `On→1`; display `nextafter(0.5,0)→Off`, `0.5→On`, `1→On`; malformed labels reject.
- Both APIs reject unknown IDs, pre-initialization/post-termination calls; display rejects NaN/±Inf and normalized nextafter values outside `[0,1]`. Seed numeric output and all 128 destination units; failures preserve outputs and saved 16-byte configuration.

Repeat boundaries under rounding modes/FTZ/DAZ; check caller FP environment preservation. Pin nonexact expected values independently; display precision need not support exact arbitrary roundtrips. Next: freeze grammar/bound, implement public tests, reproduce baseline failures.
