# W1-006 — Poly-pressure acceptance contract

Read AGENTS-required documents and inspected `collect_notes`, `process`, control validation, ownership, and the local SDK header at documented [pluginterfaces pin 4f547e8](https://github.com/steinbergmedia/vst3_pluginterfaces/blob/4f547e8e102b47de4a8b8aaf343c73b700786372/vst/ivstevents.h). The [official reference](https://steinbergmedia.github.io/vst3_doc/vstinterfaces/structSteinberg_1_1Vst_1_1PolyPressureEvent.html) confirms its fields.

**Finding:** `plugins/vst3/processor.cpp::collect_notes` rejects pressure, discarding co-batched note-offs while retained holders remain active.

**Minimal fix:** Add only a `kPolyPressureEvent` branch after existing common-header validation:

- Validate channel `0..15`, pitch `0..127`, including pitches outside the synthetic keyboard.
- Validate raw binary32 pressure with `control::valid_normalized`: `[0,1]`, both zeros and positive subnormals accepted; negative subnormals, NaN, infinities and out-of-range values rejected independently of DAZ/FTZ. No widening is needed.
- Accept every `int32` noteId; only `-1` is the unavailable-ID sentinel. Other negative IDs remain valid identifiers. An ignored event needs no active-owner or pitch/identity lookup.
- Keep successful getter, bus zero, finite PPQ (negative permitted), in-block sample offset and nondecreasing offsets across **all** input events. Update `previous_offset` before `continue`; equal offsets remain allowed. Preserve existing flags policy.
- Append no `HostNote`; leave ownership, mechanics and parameters untouched. Keep the original **256-input-event** count, including pressure, and reject nonempty zero-frame event lists.

Malformed pressure must still reject the complete preflight before mailbox consumption/audio mutation. Other unsupported types remain rejected. Describe pressure as validated-and-ignored; advertise no expressive synthesis.

**Integrator checks:** All three variants and both sample formats: mixed pressure/note-off matches pressure-free reference; pressure-only equivalence; 256/257 boundaries; descending offsets involving skipped pressure; malformed final pressure preserves holders, pending recall and future trajectory; signed-ID extremes and pressure endpoint/subnormal/NaN/Inf cases.

**Evidence/limits:** `cat`, `rg`, `sed` inspection and official-reference lookup only; no runtime tests. Changed only this report. Next: implement the branch and these regressions.
