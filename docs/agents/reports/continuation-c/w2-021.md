# W2-021 — Controller implementation

## Changed paths

- `plugins/vst3/controller.cpp`
- `plugins/vst3/controller.hpp`
- `docs/agents/reports/continuation-c/w2-021.md`

Appended sixteen writable, continuous, nonautomatable `kNoFlags` command
parameters with channel-specific CC123 mappings, names and empty units. CC64,
gain/sustain IDs and configuration serialization remain unchanged. Commands retain
their values and never execute through text conversion.

Both public text APIs now validate lifecycle, identity, pointers and numeric
domains before writing outputs. Parsing requires NUL within 128 UTF-16 units,
bounded ASCII decimal grammar, complete locale-independent `from_chars`
conversion and bitwise parsed-binary64 range validation. Optional lowercase `x`
belongs only to gain; sustain accepts exact `Off`/`On`. Gain text represents the
existing canonical binary32 configuration. Command text preserves binary64,
including positive subnormals; negative subnormals reject under DAZ.

The initial focused probe reproduced libstdc++ `to_chars(denorm_min)` emitting
`0` under DAZ. A bounded UI-only integer fallback now forms the exact subnormal
decimal coefficient and rounds to 17 significant digits, as authorized by the
integrator. It preserves host rounding/flush controls; sticky flags may change.
