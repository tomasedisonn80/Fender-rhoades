# W1-004 — CC123 primary-source audit

**Recommendation:** proceed with 16 stable, channel-specific command parameters, subject to the host-delivery limitation below.

- MIDI assigns CC123 value **0** to All Notes Off [1]. Each delivered queue point must invoke `release_channel(channel)`, including repeated zero; neither a rising edge nor interpolation represents this command.
- All Notes Off requests normal release and respects sustain; it must not reset mechanics, clear the pedal, or implement CC120-style immediate silence. MMA's specification explicitly gives hold precedence over All Notes Off [2]. Existing `NoteTracker::release_channel` removes only that channel's holders and returns only keys whose last holder disappeared. Forward those keys as ordinary `note_off`; `ResearchEngine::note_off` preserves modal motion and existing sustain behavior.
- Keep the documented single shared pedal. Sixteen ownership channels do not establish sixteen independent sustain domains. Other channels holding the same key must remain effective.
- `IMidiMapping` supplies bus/channel/controller-to-parameter mapping [3]. Accept only bus 0, channels 0–15, CC123. Preserve deterministic parameter-before-note ordering at equal offsets.
- Recommend **`kNoFlags`** for externally writable, nonautomatable commands. `kIsReadOnly` forbids external changes; `kIsHidden` implies read-only and no automation. `kCanAutomate` explicitly advertises automation [4]. Do not misuse hidden flags merely to remove generic controls.
- **Interoperability limitation:** VST3 queues describe automation curves and can omit unchanged values [5]. Processing every delivered zero cannot guarantee every original repeated MIDI command reaches the plug-in. Native-host verification remains necessary.
- Keep commands transient and exclude them from existing serialized state. Verify repeated zeros with intervening note-ons, shared ownership, pedal-held release, invalid input, and unchanged state bytes.
