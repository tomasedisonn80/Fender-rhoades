# Worker 063 — public controller API audit

**Verdict:** No actionable regression found for legitimate SDK arguments. Static
review only; no tests rerun or production changes. Read repository guidance,
HOST_MIDI, controller/ID/state sources, current text/mapping/FP/loaded-module
tests, and the pinned SDK's controller/parameter/component implementations.

- `controller.cpp`'s explicit lifecycle flag prevents duplicate initialization
  even with a null context, preserving parameter objects/values. Successful
  termination clears SDK parameters and their ID index; reinitialization restores
  defaults. Current lifecycle tests cover null/non-null contexts. Null-context
  acceptance is an implementation extension: SDK `IPluginBase::initialize`
  documents a mandatory host context.
- Registration preserves gain/sustain indices and IDs, then appends sixteen
  continuous `kNoFlags` commands in channel order (`0x1000..0x100f`), with empty
  units and zero defaults. MIDI assignment rejects unsupported bus/channel/CC
  without changing the output ID. Assignment itself is lifecycle-independent.
- Text methods reject unknown IDs, inactive controllers, null buffers and invalid
  normalized encodings before output writes. Parsing commits its output only
  after success; formatting stages all 128 units. Existing tests snapshot every
  parameter and the exact 16-byte state around conversions.
- Gain setter/display/parser share nearest-even binary32 canonicalization.
  Parsed binary64 range validation precedes division by 32: the documented
  rounded-to-32 decimal remains accepted; negative nonzero subnormals reject.
  Signed zeros become positive zero. Commands retain binary64 subnormals through
  bitwise storage; sustain consistently switches at 0.5. Inherited gain
  plain/normalized methods perform raw scaling, not storage quantization.
- `read_ascii` stops at the first NUL and reads at most 128 UTF-16 units; trailing
  storage after NUL is irrelevant. This validates nullness and content, **not
  arbitrary pointer accessibility**. Callers must provide readable units through
  termination/rejection (or the bound), and a writable `String128` output.
- Text conversion neither changes controls nor executes commands. Setters notify
  SDK dependents; processor command execution requires delivered parameter
  points. State save/recall excludes commands and preserves their current values.
