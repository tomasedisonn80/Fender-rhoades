## Bounded optional backend

All values use the standard library. SciPy imports occur only in the requested
timing worker. The private worker uses the frozen 128-term regularized series,
three frozen quadrature tolerance pairs, `limit=128`, and an enforced aggregate
10,000-integrand-evaluation cap. A parent `subprocess.run` timeout actively kills
and reaps the module's own worker after 10 seconds, including slow import or
startup. The command is an argument list and does not execute a supplied
candidate binary.

Missing SciPy gives `not_available`; exhausted budgets, nonfinite results,
convergence messages, invalid worker replies, and out-of-duration optional times
give `inconclusive_reference`. Optional timing failure preserves resolved value
references. Nonfinite numerical evidence is retained as JSON-safe null/text
fields. Error estimates and refinement agreement are explicitly not described
as rigorous certificates.
