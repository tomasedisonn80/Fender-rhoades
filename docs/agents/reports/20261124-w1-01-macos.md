  the SDK `base` target's link interface. This supplies the missing dependency
  transitively to the three standalone benchmark variants and retained host
  tests. The SDK source, pinned revisions, and non-Apple link interfaces remain
  untouched.
- `tests/cpp/audio_fir_test.cpp`: explicitly convert the FIR factor to
  `long double` before division. The tested factors are 1, 2, and 4; the numerical
  result, expected 48-frame delay, and tolerance are unchanged.

The official pinned
[SDK target definitions](https://github.com/steinbergmedia/vst3_cmake/blob/054c9143cbb8d47fc4694e473f2ee3b4d951a8f5/modules/SMTG_VST3_SDK.cmake)
