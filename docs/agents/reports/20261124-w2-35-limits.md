## Consuming-time bounds and accounting

The candidate reader does not use a preliminary `st_size` as the byte bound.
`_regular_reader` binds regular-file and identity checks to the opened object;
`_bounded_read` then makes a bounded `read(limit + 1)` and classifies its actual
returned length. This covers growth after those metadata checks, as exercised
below.

The collection charge is the sum of bounded candidate prefixes returned from
the reader. Charging before `_retain_raw` prevents a failed or partial output
write from reopening the input budget. The repaired CLI records that charge as
`input_bytes_charged_to_collection_limit` and each case's charge as
`bounded_input_bytes`. `retained_candidate_bytes` instead totals actual retained
sizes; failed inspection makes it explicitly unknown, with any known subtotal
reported separately. Source inspection and assignment 34's regression cover the
case where these totals differ. This worker's successful prefix-retention probe
observed equal totals of 33,554,432 bytes.

The reader deliberately consumes one lookahead byte to detect excess. That byte
is neither retained in the candidate prefix nor charged to the collection
prefix total. Across at most 64 candidate arguments, the candidate-read
mechanism therefore allows at most 64 such returned lookahead bytes beyond its
128 MiB prefix budget. The limit is not a claim of zero lookahead, total process
RSS, total output-directory size, or an absolute ceiling on all filesystem I/O.
The partial-artifact inspection path, source hashing, and output verification
have their own reads. No broader resource contract is inferred here.

requested/returned read size. No byte or file-count constants were patched.

The core executed sequence was:

```python
base = encode(payload())
limit = cli.MAX_FILE_BYTES
source.write_bytes(base)

def grow_after_descriptor_metadata(path):
    handle, metadata = original_reader(path)
    assert metadata.st_size == len(base)
    with source.open("ab") as writer:
        remaining = limit + 1 - len(base)
        while remaining:
            chunk = b" " * min(64 * 1024, remaining)
            writer.write(chunk)
            remaining -= len(chunk)
    return RecordingReader(handle), metadata

with patch.object(cli, "_regular_reader",
                  side_effect=grow_after_descriptor_metadata):
    code = cli.main(["--candidate", str(source), "--output", str(output)])
```
