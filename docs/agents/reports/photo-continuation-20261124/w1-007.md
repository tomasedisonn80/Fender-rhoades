`c186a90e423b3895347a676e07c6059accb3b9ab0c187a795d318a1f6af361be`.

rejects any additional archive-input change or missing/stale overlay.

Seven SDK archive build edges are removed from the alternate graph; their
verified real files become supplied inputs. The VSTGUI archive edge is replaced
with an explicit rule depending on the new overlay object. That rule copies

single `x11platform.cpp.o` member changed to the newly compiled object's bytes.
All other archive members must remain byte-identical. The rule then writes
`x11-overlay-provenance.json` with source, object and resulting archive hashes.
That file does not exist as an execution result until root runs the rule.

Only in the scratch graph, the overlay compile edge omits its precompiled
header dependency and forced PCH include. The historical SDK build also had
`CMAKE_DISABLE_PRECOMPILE_HEADERS=ON`. All other overlay compile flags and
includes are retained. This avoids rebuilding a large SDK PCH merely to replace
one translation unit. Three Wayland protocol objects already present in the
reused VSTGUI archive are detached from their redundant object-target aggregate;
their generated-header dependencies remain available. No tracked CMake setting
was changed by the adapter.
