# Worker 035 — Photo continuation ledger validator

## Scope and changes

Added `tools/validate_photo_continuation.py`, a read-only validator for
`project/photo-continuation-20261124.json`. It enforces exact header and row
fields/types, IDs A001–A100, derived waves, unique canonical task names,
nonempty scopes, allowed statuses, deterministic report paths, and status-specific
hash requirements. Completed report bytes must match their SHA-256 digests.
Running reports may be absent; existing path components must remain safe.
Later waves require all 20 rows in every earlier wave to be completed.
`--require-complete` requires all 100 completed rows; default mode validates
progress. `--root`, `--ledger`, and `--json` support isolated fixtures and tooling.

Reused existing strict JSON and bounded regular-file reading helpers from
`validate_continuation_b.py`. Duplicate JSON keys, nonfinite numbers, symlinks,
reparse points, and special report files are rejected. No ledger, index,
canonical state, or existing report was changed.
