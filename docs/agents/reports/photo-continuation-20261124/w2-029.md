## Encoding and retained provenance

For each byte, the delta is `(image - baseline) mod 256`; reconstruction is
`(baseline + delta) mod 256`. Pillow's modulo operations avoid clipping negative
or overflowing differences. Delta images are ordinary lossless RGB PNGs inside
an ordinary ZIP, with duplicate payloads stored once. Originals are only read.

The targeted suite independently checks modulo wraparound using explicit byte
values, PNG metadata differences, source immutability, corrupt encoded payloads,
forged reconstructed hashes, baseline dimension mismatches, changed raw bindings,
changed original files, RGB-check bypass by reclassification, path traversal,
absolute/drive/backslash paths, duplicate and unreferenced ZIP members, ZIP
symlinks, case-insensitive path collisions, file/directory conflicts, existing
outputs, symlink inputs, mismatched references, alpha inputs, a divergent
independent manifest and malformed ZIP CLI handling.

The verifier reads ZIP members directly and never calls archive extraction APIs.
Only validated relative logical paths are written into a fresh temporary
directory. A failed verification removes that temporary directory. Existing
destinations are refused; ZIP payloads must be regular files, bounded in size,
named by their hashes and fully accounted for by the manifest. These checks
support integrity and safe reconstruction; hashes do not authenticate the truth
of native-run claims.
