## Change and integration

`rhodes_patch_vstgui_win32_timer()` creates a build-directory copy of pinned
`vstgui4/vstgui/lib/platform/win32/wintimer.cpp`. It changes only the final
`return false;` in `WinTimer::start()` to `return timer != 0;`. The earlier
already-running rejection remains false. Checked `IPlatformTimer` scheduling
needs this truthful result: successful `SetTimer` registration previously
reported failure, causing a caller to reject an actually scheduled timer.

Following `VstguiX11Keyboard.cmake`, configuration verifies original and adapted
SHA-256, replaces exactly one relative or absolute target source, preserves the
original directory for header lookup, and tracks the original as a configure
dependency. Matching generated copies are not rewritten; damaged copies are
regenerated. Root must include/call the helper after SDK `add_subdirectory`,
only when `RHODES_BUILD_VST3_EDITOR AND WIN32`.
