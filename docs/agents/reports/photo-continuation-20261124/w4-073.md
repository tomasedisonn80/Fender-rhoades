# W4-073 — Parameter user-contract review

Result: one concrete documentation correction required; remaining scoped checks agree by inspection.

## Finding

`docs/VST3.md:464–465` says a double click restores “a control's default.” However, `plugins/vst3/photo_editor.cpp:157–164` handles Sustain and Vibrato switches before the double-click branch: every press toggles, including rapid clicks. Only continuous controls reset. Starting a switch On and double-clicking returns it On rather than resetting its Off default.

Recommended correction: “A double click restores a continuous control's default. Sustain and Vibrato toggle on every click.” The integrator owns this documentation edit.
