## Deliverable and scope

`tests/cpp/vst3_photo_lifecycle_test.cpp` loads the supplied actual VST3 bundle
through SDK hosting `Module`, sets its factory host context, initializes its
real controller, installs an accepting `IComponentHandler`, and attaches the
public `IPlugView` to a real XCB parent. The host implements public Linux
`IRunLoop` through the factory context and `IPlugFrame`. No production editor
classes, geometry headers, or VSTGUI implementation are linked into the test.

The host retains strong references to event/timer handlers and dispatches
generation-checked snapshots. Thus unregistering callbacks during teardown and
nested pumping do not invalidate its traversal or dispatch stale registrations.
Every polling condition has a two-second deadline; a process watchdog also
bounds synchronous X11 setup/replies and teardown to twenty seconds. Synthetic
SendEvent packets traverse the loaded editor's native X11 conversion/dispatch;
they do not represent physical XTEST input or named-DAW qualification.

CLI: `vst3_photo_lifecycle_test BUNDLE SELECTOR`.

| Selector | Retained assertions |
| --- | --- |
| `normal_close` | Mouse starts one accepted gesture; later ordinary removal balances it and destroys the child synchronously without a close timer. |
| `remove_begin` | Native mouse press triggers synchronous public removal inside accepting begin; child survives callback and dies on timer; exactly one begin/end and no perform. |
| `remove_perform` | Native wheel triggers removal inside perform; one begin/perform/end; pending view rejects additional native wheel/key gestures. |
| `remove_end` | Native Right key triggers removal inside end; one begin/perform/end and delayed child destruction. |
| `nested_pump` | At least two actual close-timer callbacks occur during the outer host callback; native child and periodic registration survive until callback unwinds. |
| `timer_refused` | Reject only a new period-1 timer while removal hook runs; removal returns false; child, parent and public size stay usable; later ordinary removal destroys the same child. |
| `repeated_remove` | Repeated successful removal while pending leaves exactly one close timer and one balanced gesture. |
| `reopen` | Attachment is rejected during pending close; same public view attaches after completion and accepts a fresh native wheel gesture. |
| `parent_destroy_after_remove` | Host destroys its parent immediately after successful removal inside begin; native event postamble and deferred completion must survive. |
| `release_host_reference_after_remove` | Host releases its sole view reference inside begin after successful removal; retained deferred work must complete and unregister itself. |
| `focus_remove` | A native mouse gesture is canceled through public `onFocus(false)`; accepting end requests removal; callback protection must defer teardown outside frame event processing too. |

A complete native mouse gesture warms up focus before hooks are armed. Button
timestamps separate independent clicks beyond the pinned converter's double-click
interval so the fixture does not accidentally substitute reset gestures for
held gestures. Native child existence is checked through XCB geometry replies,
and child disappearance plus timer retirement establish structural completion.
