## Paint observation

Every successful `attach()` now verifies that the native child is 1024 × 768
with the dedicated test display's 24-bit true-color RGB visual. The fixture
fills the drawable black through XCB and reads four 8 × 8 RGB patches to prove
that the observation starts from zero RGB. It then sends a full-window Expose
and pumps the registered native event and timer handlers until both conditions
hold: an actual 16 ms redraw callback has run, and all four patch means match
the independently sampled photograph within eight levels per RGB channel.
The existing two-second bounded host loop and twenty-second process watchdog
remain in force. Waiting a fixed duration is not accepted as paint evidence.

## Additional selectors and retained assertions

`reopen_cycles` retains the exact same public `IPlugView` pointer through ten
close/reopen cycles. Each close requires empty native registrations and absence
of the old child. Each reattachment must repaint the known photograph patches
and deliver exactly one native wheel gesture in begin/perform/end order. A
final ordinary removal repeats the teardown checks, and `finish()` verifies
that all registrations retired and host ownership returned to one reference.

`sibling_survives` creates two independent controllers/editors from one loaded
module using the same `Host`. Each editor must paint before removal begins.
It verifies that both share the same single event-handler generation and have
two native redraw timers. After removing A, A's native child must disappear
while B and its registrations remain; only A's redraw timer may retire. B then
undergoes another black-to-photo repaint and delivers one balanced native wheel
gesture. Removing B must retire all native registrations and destroy its child;
final cleanup must return host ownership to one reference.

The sibling test does not destroy A's parent to conceal an orphan child. Source
inspection found that the pinned SDK's `ChildWindow::~ChildWindow()` is empty,
so A-child retirement is a concrete additional boundary for the integrator's
guarded SDK overlay. This worker did not run that suspected failure or modify
the overlay.

The original eleven selectors remain available. A direct comparison with the
preserved pre-edit source confirmed that the normal-close branch and the entire
existing callback/removal/refusal/reopen dispatch tail are byte-identical.
Their registration-empty checks, fresh native input after timer refusal,
pending-removal input refusal, perform counts, callback ordering, and final
host-reference checks are retained. The common child-destruction observation
was extracted into a helper that performs only XCB geometry requests and bounded
polling; it never pumps native work to complete structural teardown.
