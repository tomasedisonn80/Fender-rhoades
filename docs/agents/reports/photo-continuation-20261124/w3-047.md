# Worker 047 — Timer-refusal lifecycle source review

**Finding:** the reported immediate child-geometry failure is consistent with an
X11 server-observation race. Source review found no timer-refusal path that
strands the SDK parent association. This is a diagnosis, not a runtime pass.

## Evidence

- `plugins/vst3/photo_editor.cpp` returns from `removed()` before
  `VST3Editor::removed()` when actual timer registration fails. `defer_close()`
  clears its pending flag, timer and self-reference, then cancels the gesture.
  The SDK parent association therefore remains available for ordinary retry.
- In the pinned SDK, `vstgui/plugin-bindings/vst3editor.cpp:1162` retains a timer
  adapter only after successful host registration. A refused registration does
  not leave a stored adapter. Its handler pointer does not retain the frame.
- `VST3Editor::close()` checks the frame reference count before closing.
  `CFrame::CollectInvalidRects` retains the frame only through event processing;
  the fixture retries after `Host::pump(false)` returns. An unexpectedly retained
  native frame would still have its host event handler registered.
- SDK `vstgui/lib/platform/linux/x11utils.cpp:88` has an empty `ChildWindow`
  destructor. `x11frame.cpp:660` destroys the frame implementation, then calls
  `RunLoop::exit()`. In `x11platform.cpp:188`, that disconnects the plugin's XCB
  connection before unregistering the host event handler. Child destruction is
  therefore server-side connection cleanup. The fixture's geometry query uses
  another connection and does not order that cleanup. One passing ordinary-close
  observation does not eliminate this race.

## Smallest meaningful correction

Immediately after ordinary retry, require empty event/timer registrations in
this single-editor fixture. The event assertion proves teardown reached the
disconnect before returning; a retained frame or deferred plugin completion
fails immediately. Then observe child disappearance with a bounded geometry-only
poll, without calling `Host::pump()` or dispatching plugin timers/events. Retain
the parent-survival and balanced-gesture assertions. A fresh native gesture
between refusal and retry additionally verifies usable attachment recovery.

No production change is justified by this observation alone. Only this report
was written; no Git, state, implementation/test changes, builds or test execution.
Root owns implementation and runtime verification.
