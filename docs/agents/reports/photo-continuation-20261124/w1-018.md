## Implementation

The test uses the pinned VSTGUI headers and the linked library's actual
`X11::RunLoop` converter. A reference-counted test `IRunLoop` is installed through
`LinuxFactory::setRunLoop`, captures the backend's registered `IEventHandler`,
and pumps that handler. A real XCB window receives checked `xcb_send_event`
requests. An `IFrameEventHandler` snapshots the converted event's fields from
`getCurrentKeyEvent`; it neither constructs replacement VSTGUI keyboard events
nor includes a converter implementation.

The fixture resolves a Right key from the server's keyboard mapping. It checks
the received SendEvent bit, packet state, keycode, unique timestamp/order,
converted press/release type, exact modifiers, and Right-key translation.
Before enqueueing, after enqueueing but before dispatch, and after dispatch,
`xcb_query_pointer` verifies effective modifiers/locks are clear and
`xcb_query_keymap` verifies all physical keys are released. Thus synthetic packet
state deliberately differs from live server state for modified cases.

Coverage comprises **20 cases / 42 packets**, provided the eventual run passes:

- Press and release for bare, Shift, Control, Mod1, Mod5, and Mod4 states.
- Mod1 plus Mod5 collapsing to one Alt modifier; Shift/Control combination;
  individual Shift, Control, Mod1, and Mod5 combinations with Mod4; all five
  native modifier bits together.
- Lock, Mod2, Mod3, and all five mouse-button bits ignored, independently or
  together; supported modifiers retained when ignored bits accompany them.
- A complete Mod4 press/release followed by a plain press/release, all queued
  and synchronized before the first callback, with exact order and no retained
  Super modifier on either plain event.

Dispatch has a two-second deadline with received/expected counts. A separate
20-second process watchdog bounds blocking XCB setup/replies and the backend's
own synchronous calls. Missing DISPLAY, live held keys/locks, failed requests,
connection failures, packet mismatches, and modifier mismatches report specific
failures. The test restores the factory run loop and unregisters its window
before VSTGUI shutdown.
