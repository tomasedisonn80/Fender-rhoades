# W1-005 — Synchronous callback audit

Actual worker 5/100, wave1. Integrator reconstruction after the runtime reset,
from the worker’s completed tool-message handoff. The original report file was
lost before publication; this is a reconstruction, not the original bytes.

Static inspection found pending beginEdit cancellation can reactivate an edit, note-on delivery can outlive focus cancellation, and rejected performEdit rollback can overwrite a newer synchronous host parameter update. Each requires a production-PhotoView regression. Ordinary nonfinite handling and nonreentrant gestures appeared sound. Combined-button behavior was not established as a native defect because VSTGUI cancels the captured child before a new mouse-down. No tests/builds ran.

No result beyond the worker’s actual stated observations is claimed.
