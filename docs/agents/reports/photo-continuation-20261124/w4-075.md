# W4-075 — Loaded panel audio wiring fixture

Added `tests/cpp/vst3_loaded_panel_audio_test.cpp` (346 lines). The SDK-only
host accepts `BUNDLE [BUNDLE...]`; it links only `rhodes_vst3_loader_support`,
never the production core, processor or direct-component test support.

Each supplied module receives float32 and float64 stereo runs at 48 kHz.
Sixteen fresh factory instances per format each render the same deterministic
two-second, three-note fixture, except the explicit held-note sustain reference.
All three modules therefore require 96 renders / 36,000 callbacks.

Assertions cover saved-neutral bit identity; 8x versus default 16x gain;
sustain preserving released notes exactly like held notes; separate +12 dB
Bass/Treble changes; depth/rate changes with Vibrato enabled; exact neutral
output with modulation disabled or zero intensity; and an enabled-to-disabled
transition returning exactly to neutral after the documented 480-frame ramp.

Every output sample must be finite. Reference RMS must exceed `1e-5` and peak
`1e-4`. Changed waveforms require RMS difference above both `1e-6` and 2% of
reference RMS, plus peak difference above 1% of reference peak. These are
functional significance thresholds, not listening or physical-fidelity results.
The conservative `32B` peak bound uses the matching neutral peak `B`: convex
low-pass history, shelf gain below 4, bass bound `4B`, treble factor below 7,
and modulation gains in `[0,1]` give a combined bound below `28B` before
roundoff margin. Audio is monitored synthetic harp voltage, not assumed
normalized `[-1,1]` full scale. Sustain uses its held-note reference bound.
