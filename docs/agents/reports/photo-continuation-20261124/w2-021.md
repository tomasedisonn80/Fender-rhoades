## Implemented matrix and required outcomes

There are **18 scenarios**: three actual loaded model identities, two lifecycles,
and three zero-frame bus forms. The lifecycles are initialization without any
`setupProcessing`, and setup/start followed by one audible 128-frame callback,
`setProcessing(false)`, and `setActive(false)`. The bus forms are no output bus,
a zero-channel output bus, and the negotiated stereo output bus. Existing guard
pages make forbidden sample-pointer access fault in these zero-frame cases.

Each scenario requires:

1. Public controller edits set all eight values. An accepted empty host flush
   deliberately withholds every parameter queue. Processor saving must still
   produce the original 16-byte default v1 state; controller saving must produce
   the independent 40-byte edited v3 state.
2. Host delivery supplies all eight queues in order `4,0,7,2,5,1,3,6`. Each queue
   has two offset-zero points with different effective values. Both points must
   be read, and the final duplicate endpoint must win. The accepted zero-frame
   flush must publish the entire literal v3 packet immediately.
3. After both objects are destroyed, fresh connected objects restore the two
   withheld-delivery streams. The processor must remain at default v1 even
   after the separate edited controller state is restored and an empty flush
   succeeds. Controller state does not repair undelivered processor edits.
4. Another fresh pair restores the accepted component stream through
   `IComponent::setState`, the controller's component stream through
   `setComponentState`, and its separately saved stream through controller
   `setState`. All eight normalized controller values and both saved byte
   streams must exactly match the independent v3 oracle before setup.
5. Returning only panel IDs 3–7 to defaults must retain Gain 0.75, Sustain 1,
   and Expression 0.3125 and downgrade both saved streams to exact 20-byte v2.
   This state is saved, destroyed, and restored into another fresh pair.
6. Returning Expression to unity must retain Gain 0.75 and Sustain 1 and
   downgrade both streams to exact 16-byte v1. That state is also saved,
   destroyed, and restored into another fresh pair with neutral panel values.

The source asserts **9 no-setup cases, 9 stopped cases, and 72 fresh pair
reopens**. These are expected execution counts, not a claim that the matrix was
run by this worker.

## Atomicity and model isolation

Three faults affect the second point of the final Speed queue: an offset of 1
in a zero-frame callback, NaN, and a failing point getter. Seven complete queues
and the first Speed point precede the fault. All tentative values differ from
the accepted nondefault configuration. Point-read counters must show two reads
for every queue. Rejection must preserve all 40 saved bytes and every controller
value. A subsequent accepted empty flush must preserve the same configuration,
detecting leaked staging values.

These checks run once against published v3 state and once with a newly requested
v3 recall before each malformed call: **108 expected rejected flushes**. The
pending-state checks establish preservation of the complete pending snapshot
and the subsequent accepted empty-flush result; they do not inspect private
mailbox flags or prove internal recall-consumption timing independently.

Every restored v3 case also rejects each other model's literal v3 packet through
the component and both controller state entry points, preserving the pending
configuration. This gives **36 expected foreign-v3 packet cases / 108 state
entry-point rejections**, covering all six ordered model pairs. The earlier
v1/v2 foreign-model tests remain intact.
