## What the new verifier observes

`tools/verify_photo_interactions.py` imports the existing native attachment,
XTEST input, RGB capture and callback parser from
`tools/verify_native_photo_editor.py`; that existing tool was preserved.

- Both pedal and Vibrato receive rapid double/triple presses starting from
  observed On and Off states. Each press must produce exactly one balanced
  begin/perform/end gesture with the expected alternating value. All eight
  rapid cases passed in both runs; every measured inter-press interval was
  below the pinned 250 ms native click threshold.
- Ctrl, Alt and Super are each tested with all four arrows, both alone and with
  Shift: 24 combinations. The actual native modifier mask/keycodes are retained.
  Positive plain-arrow probes bracket the no-edit tests, avoiding a vacuous
  pass from a nonlogging host. All combinations passed in run 02.
- Plain Up/Down changes Volume by 0.01; Shift-Up/Down changes it by 0.001.
  The observed sequence includes `0.5 → 0.51 → 0.511 → 0.51 → 0.5`.
- All 43 white keys are held, with a saved screenshot for each. A separate
  eight-by-eight white-front patch must visibly change from hover to press.
  Every held white patch passed that observation in both runs. Each screenshot
  is compared against all 30 black-face interiors: 1,290 key/region pairs and
  818,978 pixel instances per run. The masks contain 19,046 pixels and erode
  each photographed black polygon by three source pixels, excluding its outer
  antialiased boundary. Native seam pixels still inside these masks fail exact
  equality.
- Both Volume and white-key hover must disappear after a 2.2-second wait and
  reappear after movement within the same target. Both cases passed.
- Full-size idle screenshots before and after the interactions exactly equal
  all 1,769,472 decoded reference pixels. Both runs passed both comparisons.
- Minimum/default/maximum sizes are captured. Native close during a held Volume
  gesture must produce a balanced end callback and a zero host exit status.

Run 01 exposed an observation-window defect in the new verifier: its initial
pedal callbacks arrived at about 3.4925 s, after the fixed action interval closed
at 3.3915 s. The action was correctly retained as incomplete. The raw log
contains its complete transition. The verifier now waits up to two seconds for
the expected callback count before closing that action's evidence interval and
waits for observed pressed-patch change before held capture. Run 02 has no
incomplete callbacks. Run 01 was not rewritten or reclassified.
