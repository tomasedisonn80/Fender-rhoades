## Finding and recommended repair

`include/rhodes/control_value.hpp` classifies representations through integer
bit operations, including masked zero tests. Its contract explicitly promises
independence from host floating-point modes. However, `rhodes_target_options`
does not request Clang exception semantics. Clang's documented default precise
mode ignores exception flags; it does not promise to preserve the exception
effects of an otherwise value-equivalent transformation. Lowering an integer
zero classification to a floating comparison is therefore a plausible cause
when a signaling NaN reaches `is_zero`. This review did not inspect generated
assembly and does not claim that particular instruction was proved responsible.

Protect the public header itself, after includes and around its definitions,
with Clang-guarded `float_control(precise, on, push)` followed by
`float_control(except, on)`, and restore the previous settings with
`float_control(pop)`. This scopes strict exception semantics to the helpers and
their production uses without applying different arithmetic rules to unrelated
DSP. Retain constexpr behavior and all current assertions. A test-target-only
flag would leave other consumers of the inline header unprotected.

Also enable Clang `STDC FENV_ACCESS ON` in the test translation unit after its
includes. The test intentionally changes rounding modes and reads exception
status; those observations must be visible to optimization. A volatile-only
workaround does not express the complete semantic requirement.

The official [Clang user manual](https://clang.llvm.org/docs/UsersManual.html#controlling-floating-point-behavior)
defines the default exception-ignore behavior and strict preservation. The
[language extensions](https://clang.llvm.org/docs/LanguageExtensions.html#extensions-to-specify-floating-point-flags)
document scoped exception pragmas and push/pop. Reviewed 24 November 2026.
These are compiler contracts, not evidence that AppleClang already passes.

signaling NaNs, random representations, exact nearest-even conversions and
