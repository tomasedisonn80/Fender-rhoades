# W3-045 — Expression audio sample-rate matrix

## Scope and implementation

Assignment 45, wave 3. Changed only `tests/cpp/vst3_expression_audio_test.cpp`
and this report. Read AGENTS, README, project state/roadmap, continuation-D
instructions/ledger, frozen Expression contract and the relevant host/core code.
No production, shared build, SDK, Git publication or canonical-state mutation.
The integrator added the new CMake selector registration.

Added one `rate_matrix` selector. `Fixture` now forwards an optional sample
rate to its target and both possible peers; its default remains 48000 Hz and
the seven existing selectors retain their bodies and invocation behavior.
Public setup checks a continuous finite 32000–192000 Hz range, allowing the
fractional case below without changing production validation.

Each of 32000, 44100, 88200, 96000, 96000.5, 176400 and 192000 Hz runs in float
and double on direct/model 1, filtered/model 2 and quadrature/model 3. The rates
include both public bounds and all three filtered oversampling branches;
96000.5 lies just above the 96000 Hz branch boundary. Each case checks:

- Non-unity ramps ending at 0.25 and 0.75, with audible endpoint witnesses.
- Zero Expression with held ownership and continuing mechanical evolution;
  an audible unity peer makes both muted blocks discriminate real muting.
- Note-on, two note-offs and sustain release while muted, followed by unity
  recovery and another audible callback with no surviving note owners.
- Exact future engine/filter continuation from matched copied engines.
- Recall of gain 0.625/Expression 0.25, followed by a ramp to 0.75; audible
  samples distinguish the recalled anchor from stale live Expression 1.0.
- Requested sample-rate retention through recall and an audible continuation.

Reused the existing independently interpolated `Curve` and unity-Expression
double peer; no DSP oracle was reimplemented. Every accepted callback retains
the original checks for scalar output, exact stereo duplication, buffer extent,
silence flags, mechanics, ownership, cursor, live/published state and saved bytes.
