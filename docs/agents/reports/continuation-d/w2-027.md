The scalar oracle selects `ResearchEngine`, `AudioEngine`, or
`QuadratureEngine` explicitly by the test variant. It drives that core directly
and uses a separate map of identified MIDI owners, direct key release calls,
literal control IDs, and barycentric gain/expression curves. It does not use
the adapter's event translation, `NoteTracker`, control interpolation, or
state encoder for expected results. The physical core itself is shared: this
tests adapter behavior, not independent physical correctness or calibration.

All exercised continuous curves have power-of-two sample spans and dyadic
anchors. Expected audio preserves `(32.0 * gain) * volts`, branches directly
to that result at expression unity, and performs one final host-format cast.
Every compared output sample uses exact bits, including sign bits of zero.
There is no numerical tolerance or broad absolute error floor. A matched
stereo adapter is also compared to the mono adapter, in addition to the
separate scalar oracle. The initial default/unity lane checks the inherited
left-scalar arithmetic; this worker did not load a historical binary.

Saved-state expectations are independently assembled little-endian RHST v1/v2
packets with literal model IDs 1/2/3. The fixture checks current and published
configuration, exact stream bytes/extent, cursor, owner total and per-key
counts, and every mechanical modal state. Rejection snapshots also render
97 subsequent scalar frames from copied engines, covering the 96-frame FIR
memory and its boundary before a pending recall can hide corruption.

The guard implementation places actual `std::array<Sample*, 1>` and
`std::array<Sample*, 2>` objects immediately before an inaccessible page.
Linux/macOS use `mmap` plus `mprotect`; Windows uses `VirtualAlloc` plus
`VirtualProtect`. A failed guard allocation/protection fails the test on those
platforms. Other platforms use exactly sized arrays and report zero guarded
arrays. In this Linux execution every requested page guard was installed:
**792 guarded arrays across the three binaries**. Sample buffers also have
leading/trailing canaries, a checked unused suffix, and a third untouched
storage channel. Each fixture checks a second unused bus's silence flag.
