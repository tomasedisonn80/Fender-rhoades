## Findings

- Exact arrangements are `SpeakerArr::kMono = kSpeakerM = 1<<19` and
  `kStereo = kSpeakerL|kSpeakerR = 3`; channel count alone is insufficient.
  Reject single-center/left and alternate two-channel arrangements
  (`pluginterfaces/vst/vstspeaker.h:41–61,123–127`).
- Accepted arrangements must update the actual `AudioBus`. Its `getInfo()`
  derives channel count from the arrangement, but name changes require
  `setName()` separately (`public.sdk/source/vst/vstbus.cpp:31–37,64–67`,
  `vstbus.h:50–55,108–112`). Retaining the previous layout on rejection is
  explicitly permitted by `ivstaudioprocessor.h:273–309`.
- Suspended negotiation is supported: stop processing, deactivate component,
  negotiate, reactivate, resume. Bus activation survives arrangement changes
  (`ivstcomponent.h:186–190`). These sources do not establish live-switch safety,
  compulsory rejection of out-of-sequence calls, or mechanical-state continuity.
- For a supplied inactive bus, the channel-pointer array remains required;
  individual sample addresses may be null. Silence flags do not excuse invalid
  active sample buffers (`ivstaudioprocessor.h:185–198`).
- **Existing interoperability gap:** `ivstcomponent.h:186–190` and the Processing
  FAQ permit omitting trailing inactive buses. Existing `processor.cpp:152–165`
  rejects nonzero `numOutputs=0`. Integrator decision: extend this case only for
  the configured inactive output; advance DSP/events/controls normally without
  accessing output pointers or flags. Active omission still rejects. This is
  pending implementation, not current compliance. The FAQ permits bufferless parameter
  flushes but does not itself require `numSamples=0`; the draft's zero-frame
  rule is a project contract.

## Required tests

Across all three variants and both sample formats, directly and loaded:

1. Default stereo; suspended stereo→mono→stereo; arrangement/name/channel-count
   coherence; unchanged activation, latency and tail; invalid counts, null output
   arrangement, and unsupported exact masks preserve metadata.
2. Mono equals legacy left exactly; stereo duplicates it. A guarded one-entry
   pointer array proves no second-entry access. Active null samples reject;
   inactive null samples retain the documented evolution policy. Independently
   compare inactive omitted-output blocks with rendered controls/events; check
   cursor, mechanics, ownership, configuration and resumed audio. Poison output
   pointers must remain unaccessed; active omission must reject atomically.
3. Zero-frame flushes with no outputs, zero channels, and negotiated width never
   inspect sample pointers. Verify silence masks `0`, `1`, `3` respectively.
4. Width mismatches clear only declared supported widths; negative/oversized
   dimensions remain untouched. Check null entries, frame boundary 8192/8193,
   real zero/nonzero audio, and partial-fault silence masks.
