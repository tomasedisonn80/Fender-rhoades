# W2-024 — Adaptive state streams

## Delivered scope

Implemented `plugins/vst3/state_stream.cpp`, updated its header comments with
integrator authorization, narrowly changed the 20-byte candidate read-count
expectation in `tests/cpp/vst3_stream_contract_test.cpp`, and added
`tests/cpp/vst3_expression_stream_test.cpp`. Read the operating/canonical context,
frozen expression/mono contract, and W1-004/009/019 reports. No Git, shared-build,
canonical-state, controller/processor, shared-fixture, or child-agent changes.

Readers accept only exact 16/20-byte candidates, retain position checks, and
validate matching length/version/model through the shared decoder. Writers select
legacy v1 at canonical unity and v2 otherwise before any transfer. Positive short
transfers are bounded by the chosen length; errors, zero/missing/negative counts,
and overreported counts stop immediately. Destination truncation remains the
host's responsibility: v1 written over an untruncated v2 stream remains invalid.

Independent literal fixtures cover models 1/2/3, chunk sizes 1–20, prefix/tail
guards, both versions' six ordered foreign-model pairs, v2-unity canonicalization,
signed zero/subnormal boundaries, malformed lengths/headers/domains, cursor errors,
every transfer failure position, and retries. New selectors are `roundtrip`,
`malformed`, `transfers`, and `overwrite`; default/`all` runs all four. The target
needs this test, `state_stream.cpp`, and repository/include/SDK include paths;
compiled SDK libraries are unnecessary.
