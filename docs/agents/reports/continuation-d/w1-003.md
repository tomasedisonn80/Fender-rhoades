## Current synthesis boundary

`src/research_engine.cpp` implements 73 persistent keys with three independent exact underdamped modes each. Retriggers add impulse without resetting displacement/velocity; release and shared sustain select cached viscous losses. Local modal motion is summed before polynomial pickup differentiation, and the resistive harp retains silent branches. These are synthetic equations, without finite-mass contact, reciprocal magnetic force, or measured calibration. Direct, sampled/FIR, and Q6 wrappers remain distinct numerical models. The host applies monitoring gain afterward and duplicates one scalar output to both channels.
