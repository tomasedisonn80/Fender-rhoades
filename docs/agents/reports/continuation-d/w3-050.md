## Reproduced findings and authorized corrections

1. **Stale passed report after invalid timeout.** Before correction, private
   calls with `--timeout` values `0`, `61`, `nan`, and `inf` raised
   `ComparisonError` before replacing a preseeded successful `report.json`.
   All four left that stale pass intact, with zero child launches. The driver
   now initializes a new incomplete attempt before validating the timeout
   inside its failure-reporting block; invalid values return 1 and publish
   `status=failed`, `summary.passed=false`, `summary.complete=false`.
   Nonfinite timeout values are recorded as text with a null numeric field,
   preserving strict JSON. Existing run directories are untouched.
2. **Retained bytes could differ from compared bytes.** A private injected
   write replaced the trace with equal-length zero bytes immediately after
   `validate_capture`, before the former post-validation file hash. The
   capture remained passed and `raw_records_match_manifest` returned true,
   although `audio_sha256` and `trace_sha256` differed. The same window applied
   to stdout JSON. The driver now hashes/counts the exact stdout/audio byte
   snapshots used for parsing/comparison and never replaces those bindings
   with a later file read. Its existing final manifest gate therefore rejects
   subsequent stdout or trace replacement and prevents a passed run report.

These were synthetic failure injections, not observed native capture corruption.
They do not rewrite or independently invalidate the historical results; W3-047
owns the separate retained-native-raw audit. No old report was edited.

## Provenance and remaining limits

`bundle_inventory` fingerprints all bundle files and requires one native binary
per variant. The baseline manifest must name the exact frozen commit and match
all three native paths/hashes. The driver fingerprints both module sets, recorder,
baseline manifest and relevant current source files before/after execution and
rejects net changes. This detects endpoint differences, not transient changes
followed by restoration; it does not attest source-to-binary compilation.

Optional SDK revision/submodule output and nearby CMake cache/settings are
recorded, not independently enforced as identical old/current toolchains.
Legacy metadata equality covers ID, title, units, flags, step count and normalized
default; `shortTitle` and `unitId` are omitted. Expression's complete descriptor
and the intentionally changed factory subcategory are outside this comparison.
Filesystem permission failures or argument parsing failures before a usable
output directory is established cannot promise a fresh report. No filesystem
immutability, native-platform, named-DAW, device-deadline or fidelity claim follows.
