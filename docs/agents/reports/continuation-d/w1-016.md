## Required current behavior wording

- Expression is an automatable continuous digital multiplier, ID `2`, normalized
  and displayed range `0..1x`, default `1x`. CC11 on any of channels 1–16 targets
  that same global control; it is not a channel mixer, velocity control, physical
  Stage volume model, or CC43/14-bit reconstruction. Keep gain/sustain IDs `0/1`,
  all 16 command IDs, six class identities, models 1/2/3 and latencies 0/48/48.
- Preserve the monitored calculation and its nonfinite check before expression.
  Exact unity takes the legacy arithmetic path. Zero expression keeps mechanics,
  note ownership, filtering, releases and fault handling running; it does not
  establish reduced CPU work or bypass behavior.
- Gain and expression independently use canonical binary32 anchors, previous
  published value at offset `-1`, last duplicate point, and held final value.
  Output interpolation is binary64; saved values are canonical binary32. A
  zero-frame flush applies recall, final gain/expression/sustain, then staged
  releases without advancing audio time. Retain full preflight atomicity and
  the existing event/command/action bounds.
- Expression text uses the bounded strict ASCII decimal grammar with optional
  lowercase `x`; examples are `0`, `0.5x`, `+5e-1 x`, and `1`. State the binary64
  parse/range-check and binary32 control round-trip distinction. Commands retain
  binary64 text semantics and no unit suffix.
- Mono is the existing scalar left-channel signal; stereo duplicates it. There
  is no stereo sum or added pan-law gain. Negotiate while suspended, preserve the
  last accepted arrangement on rejection, and update bus name/count coherently.
  Layout belongs to host configuration, not the instrument state chunk.
- For positive frames, an active output requires the negotiated one/two-channel
  bus and non-null sample pointers. A supplied inactive bus still requires its
  pointer array but permits null sample pointers. An omitted inactive bus
  (`numOutputs = 0`) advances accepted synthesis/events/automation and faults,
  touching no output pointer or silence flag; omitted active output rejects.
  Zero-frame calls allow no bus, zero channels or negotiated width and never
  dereference samples. Silence masks are 1 for mono, 3 for stereo, 0 for an empty
  zero-frame bus. Rejection cleanup recognizes declared width one or two even
  on a layout mismatch, with the existing one-bus/8192-frame bound and null-safe
  sample handling; unsupported dimensions remain untouched.

| Input/saved setting | Required plug-in-state contract |
| --- | --- |
| Own-model legacy v1 | Exact 16 bytes; decoded Expression defaults to 1. |
| Save canonical Expression 1 | Emit exact legacy v1 bytes. |
| Save non-unity Expression | Emit 20-byte v2; expression is canonical little-endian binary32 at bytes 16–19; preceding fields retain offsets, with version 2. |
| Valid own-model v2 with Expression 1 | Accept; subsequent save may canonicalize to v1. |
| Wrong length, version, model or invalid controls | Reject transactionally; preserve an already pending valid recall. |

The explicit v1 encoder must reject non-unity state rather than discard
Expression. Do not promise that old plug-ins read v2. Recall restores
configuration and resets dynamics; saving is a coherent snapshot. Neither a
host preset's size nor its UI values establish the exact chunk encoding.
