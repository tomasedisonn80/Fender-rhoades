## Root cause and fix

The shared validator resolves the repository root before calling `lstat` on
its ledger and report components. The old mock compared those resolved paths
with the unresolved temporary-directory spelling. A changed spelling misses
the synthetic parent, returns its real attributes, and never exercises the
reparse guard. The old expected ledger-read path had the same assumption.
The native log does not include the compared spellings; no particular Windows
alias or short-name expansion is asserted here.

A deterministic noncanonical `..` root reproduced the identical failure on
Linux before the change. The fixture now resolves its injection target and
expected ledger path before patching. It always supplies a `..` root, asserts
that its spelling differs while naming the same directory, and records the
synthetic reparse injection. Passing requires exactly one injection at the
intended parent, the original rejection message, and ledger-only byte reads.
No production validator, reparse protection, test skip or accepted input changed.
