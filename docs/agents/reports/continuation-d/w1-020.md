## Concise frozen execution checklist

- [ ] **Freeze oracle scope before execution:** three models, both formats,
  direct plus loaded coverage; stereo/mono where applicable; W017 exact dyadic
  and legacy-unity bit comparisons. For its non-dyadic curve use the declared
  `16 * epsilon_double * abs(monitored)` double bound and at most one float ULP,
  with finite/zero handling and no broad absolute floor. State/ownership/bytes
  remain exact. Declare any additional conditions or thresholds before running.
- [ ] **Freeze the actual candidate:** complete source/test/input manifests and
  build settings, SDK revisions, binary hashes and old-module provenance.
  A supplied commit label alone does not bind later working-tree edits. Preserve
  raw first failures and skip reasons; use a new report for later corrections.
- [ ] **Finish C01–C03:** independent control, rollback, state/concurrency and
  bus tests; retain legacy CC123, pressure, identities, model/latency and unity
  lanes. Ensure adversarial fixtures do not sanitize malformed queues first.
  Preserve exact stream extent: a v1 write does not truncate an old v2
  destination, and a trailing 20-byte v1 must still reject. An omitted bus must
  never form `outputs[0]`, including failure paths and non-null unused pointers.
  Use an explicit direct-test fault mechanism where ordinary audio cannot reach
  the fault; do not describe that as loaded-module fault coverage.
- [ ] **Finish C04:** complete each required native run on applicable candidate
  source, retain/download raw artifacts, reconcile counts and repeat only tests
  needed by subsequent source changes or a concrete unresolved risk.
- [ ] **Finish C05 and review:** update current guides, freeze exact criterion
  coverage, register numerical/documentary evidence and the immutable acceptance
  review through the integrator. Mark done only when every required clause
  passes and dependencies/evidence are satisfied; no incomplete/inconclusive
  required clause can be converted into completion by a passing total.
