## Changes

- `include/rhodes/instrument_state.hpp`: append default-unity Expression; retain
  the exact 16-byte v1 API and reject nonunity exports; add explicit 20-byte v2
  constants/type/encoder. Decode only matching exact-length versions and models.
  Both normalized fields use integer validation and signed-zero canonicalization.
- Pack Expression into unsigned mailbox bits 34–63, preserving gain, sustain,
  pending and the existing one-attempt CAS protocol. Unpack the complete triple.
- `tests/cpp/expression_state_test.cpp`: seven independently selectable cases,
  literal v1/v2 bytes for all models, literal mailbox words, 19,474-word field
  corpus, malformed length/header/version/model domains, deterministic recall
  precedence/abort sequences and FP environment preservation.
