## What the mode-sensitive checks establish

`expression_state_test.cpp:448–569` probes 24 literal binary32 encodings, including signed zero, subnormal boundaries, out-of-domain values, infinities and signaling/quiet NaNs. Each environment repeats clean/sticky-`FE_INEXACT` states, v2 validation/encode/decode, exact bytes, recall/rejection, snapshot, abort/retry, publication/consumption and ten literal mailbox-word fixtures. It checks rounding, exception flags and complete MXCSR preservation/restoration where compiled. This loop does not rerun every separate codec/model/concurrency selector under every mode.

`vst3_expression_control_test.cpp:420–790,880–965` repeats conversion and recall cases: literal nearest-even binary32 boundary oracles, subnormal/signed-zero handling, strict decimal acceptance/rejection, caller-buffer and state preservation, v1/v2 migration/canonical save, malformed stream rejection and retention of transient command values. Controls guard rounding and compiled MXCSR/x87/ARM FPCR controls; per-call sticky flags may change, while the outer fixture restores and checks the saved environment. Metadata and the dedicated lifecycle selector are not independently swept, although conversion/recall instances initialize and terminate within each mode.

`control_value_test.cpp:272–328` compares quantization/widening with prepared independent nearest-even reference bits and checks no helper FP exceptions. `control_text_test.cpp:510–601` checks literal parse oracles, stable formatted bytes, rejected formats and decimal-point independence; core text guards compiled MXCSR/x87/FPCR controls, excluding sticky flags. `vst3_control_text_test.cpp:541–643` repeats parse/format, bounds/Unicode, rejection, recall and lifecycle cases; its ARM control guard checks C rounding, not a separate FPCR flush sweep. Locale availability is a different coverage dimension from floating-point controls.

Legacy `control_fp` and `vst3.Pfp_*` clear MXCSR rounding bits to nearest for their engine/event/control/audio fixtures; `state_fp` varies flush settings without a rounding sweep. Their host checks allow arithmetic sticky flags and preserve controls. These legacy suites do not supply a new Expression interpolation sweep across all rounding modes.

`vst3_expression_audio_test.cpp:758–778` explicitly selects `FE_TONEAREST` for every current audio selector: `default_queues`, `anchor_duplicates`, `combined_curves`, `nondyadic_curve`, `muted_resume`, `flush_recall`, `partition_curves`, `rate_matrix` (24 selectors across variants). Native `19b566a` contains the first seven (21 selectors); the rate matrix is a later local addition. `vst3_expression_fault_test.cpp:937–952` also selects nearest for all six overflow/fault selectors, present only in the later local tree. Neither fixture sweeps flush controls. The control helper's own contract (`control_value.hpp:30–32`) leaves audio arithmetic native; these results establish no all-floating-environment audio proof.
