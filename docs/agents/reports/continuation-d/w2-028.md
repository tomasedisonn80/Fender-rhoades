The raw adapters intentionally do not use SDK `ParameterChanges` or
`ParameterValueQueue`: those helpers would merge duplicate IDs, sort offsets
and replace equal-offset points before adversarial input reaches the plugin.
SDK `EventList` is used only for already ordered, valid event fixtures.

The scalar oracle establishes the digital expression relationship against an
independently advanced instance of the same actual binary; it is not an
independent physical-model solver. Dyadic anchors/segment lengths avoid adding
a floating tolerance or accidentally changing the curve during partitioning.
