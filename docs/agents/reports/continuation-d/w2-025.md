## Changes and preserved boundaries

- Public inventories now expect 19 controls, with Expression at enumeration
  index 2/default 1 and commands starting at index 3. Unknown-ID negative cases
  use unused ID 3. The total-queue overflow case rejects 20 before getters.
- Controller/text and loaded-MIDI seeds explicitly retain Expression unity.
  Their independent 16-byte v1 packets and exact save extents remain intact;
  command seed values and binary64 command conversion expectations are unchanged.
  V1 recall and controller lifecycle checks include Expression unity.
- Loaded-MIDI's exact rejected-text total is now **1056**:
  `6 * (19 * (8 malformed inputs + 1 null) + 4 unknown IDs + 1 unterminated input)`.
  Its six flushes and 102 rejected blocks remain unchanged.
- Shared `ParameterChanges` remains a two-queue legacy fixture;
  `CommandChanges` and the dense legacy allocation wrapper remain 18 queues.
  Comments distinguish those capacities from the public 19-queue limit. The
  18-entry command permutation now bounds traversal by its permutation array
  and computes its reverse index from that same length, avoiding the earlier
  `values.size()`/`17 - index` coupling. New maximum-capacity tests belong to the
  separately assigned feature fixtures.
- `lifecycle` suspends processing, accepts mono, checks its one-channel metadata,
  rejects empty layout without changing mono, restores stereo/two-channel
  metadata and resumes before its original stereo render. The setup rejection
  inventory substitutes unsupported 5.1 for formerly rejected mono.
- A mono-declared block under active stereo still rejects atomically. Cleanup
  now clears only channel 0 and sets mask 1; its zero-frame counterpart has a
  null channel array and expects mask 1 without sample access.
- `inactive_buffers` retains its four supplied-bus pointer masks and adds an
  omitted inactive bus shape. The same event/control-instance continuation
  checks verify advancement, with untouched sample storage and silence flags.
  The existing omitted-active-output negative case remains rejected.
